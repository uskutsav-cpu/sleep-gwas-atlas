Lane2019 HUNT component recovery: finite scientific feasibility decision
13 October 2026

Decision: NOT ADMISSIBLE FROM AUTHENTICATED PUBLIC INPUTS IN THIS SCREEN. Stop at the indispensable dense-input scope failure. No HUNT-only or HUNT+Partners genome-wide summary statistics were reconstructed, acquired or admitted. This is a finite metadata assessment, not a claim that no public file could ever exist.

Primary evidence

Lane2019 describes UKB discovery and HUNT/Partners replication. Its Methods, “Genome-wide association analysis,” specify fixed-effects METAL with the standard-error scheme, rather than sample-size-weighted Z. The text identifies the replication meta as UKB + HUNT + Partners. UKB uses distinct frequent/any symptom definitions and BOLT-LMM discovery versus PLINK logistic effect analyses; these are not interchangeable component releases. [1,2]

Publisher Supplementary Table 2 is a genome-wide-significant-loci table containing exactly 57 unique rsID rows, with rounded OR[95%CI]/P columns for UKB and meta. It has no dense per-variant direct beta/SE input or cohort-weight manifest. Table S7 is selected-locus HUNT replication, explicitly including an updated phenotype; Table S6a supplies 14,923 cases/47,610 controls. These are locus/phenotype metadata, not a dense component release. [3]

The supplementary note documents HUNT1–3 symptom definitions, differing frequent-symptom rules, European ancestry and SAIGE sex/birth-year/batch/four-PC adjustment, MAC>=5 and imputation r2>=0.3. Partners is an EMR insomnia cohort. Thus even a recoverable non-UKB residual would pool different ascertainment, rather than identify HUNT alone. [4]

The generic download statement does not name a dense meta artifact/version/checksum or its exact UKB input. The inspected portal describes UKB participants; it does not authenticate HUNT or a dense all-three release. [1,5]

First indispensable missing contract

No exact public dense meta artifact was identified in the primary release metadata inspected here. Its identity, schema, genome-wide variant universe, component list and download rights therefore remain unverified. The known 57-row table cannot substitute for that artifact: selected discovery loci cannot support ordinary genome-wide LDSC, and rounded OR/CIs cannot uniquely recover the original beta/SE and precision contributions. No reconstruction proceeds beyond this scope failure. An unavailable old URL or a web-tool error alone is not evidence that all routes are unavailable.

Established subtraction: conditional recoverability only

For an independent-cohort, fixed-effect inverse-variance meta on one common effect scale, removing an exact component subtracts that component's weighted effect numerator and inverse-variance precision. Weights come from the exact SEs actually used after any corrections; cohort totals are not those weights. If the true meta contains UKB+HUNT+Partners, removing UKB leaves HUNT+Partners. Identifying HUNT additionally requires the exact Partners contribution or an authenticated two-cohort meta. A positive residual precision is necessary, not an authenticity test. Sample-size Z subtraction is not the method specified here. No numeric subtraction was performed.

Requirements to reopen this route

1. An exact publicly permitted dense meta file, fixed release identity/hash, schema and explicit cohort membership; independently distinguish a UKB+HUNT file from the reported three-cohort meta.
2. Its exact UKB component, rather than core Neale, Jansen, another UKB release, a BOLT result substituted for a logistic input, or a frequent/any/sensitivity/sex-specific analysis substitution. Require matched variants, allele/effect direction, genome build, statistic scale, filters and precision.
3. The exact meta script/settings and cohort-specific transformations: any effect-scale conversion, genomic-control SE/test correction, post-meta correction, variant exclusion/strand harmonisation and rounding. The method name is known; applied correction factors and full input settings are not authenticated. No correction is assumed absent from a missing document.
4. Per-variant valid SE/precision and inclusion maps for every component. The supplement's overall N or imputation r2 cannot replace these. HUNT SNP-wise analyzed/effective N remains necessary for later LDSC use and cannot be inferred from UKB/meta total N alone.
5. For HUNT-only, exact Partners removal or proof that the chosen meta excludes it. For a pooled HUNT+Partners candidate, explicitly retain the pooled phenotype/N/ancestry and overlap qualifications. Either route needs conditioning/rounding-error propagation and recomposition checks before claiming a recovered component.

Allele/build and release limitations

Table S7's footnote labels its selected positions hg19 and defines effect/alternative alleles. This does not authenticate a dense meta/UKB genome-build or allele-transformation contract. The HUNT supplementary definition spans repeated surveys and is not the same case definition as UKB's baseline question or Partners' EMR diagnoses. Published case counts describe sample ascertainment, not SNP-specific information. The Table S2 cohort-size headings are not a substitute for an executable provenance map and were not used to infer weights. No exact dense meta, dense matched UKB or dense Partners checksum, per-variant weight/N map or full genomic-control contract has been verified.

Scientific consequence

This route presently adds no free independent genome-wide sleep source and improves no validation estimate. Mathematical reversibility under hypothetical known inputs is not authenticated empirical replication. Even a future valid reconstruction would reuse the original selected discovery/meta provenance and require an independently fixed outcome source, source intersections, phenotype transport, source h2/precision and a prespecified family before any new validation. It would not calibrate existing 41 between-fit contrasts or clear reliability, independence or uncertainty holds.
