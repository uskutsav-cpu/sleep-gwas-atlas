# Public-data extensions: evidence checkpoint

This folder records the current evidence and go/no-go decisions for the eight requested research extensions. It is a bounded scientific review, not manuscript material or a new analysis controller.

- `EIGHT_EXTENSION_EVIDENCE_MATRIX.tsv`: one row for each requested extension, with existing evidence, remaining gap, and decision.
- `PUBLIC_SOURCE_LEDGER.tsv`: public prior studies and the four newly authenticated device-sleep summary-statistic records.
- `YALE_SLEEP_SUMSTATS_ENDPOINTS.tsv`: response status, byte size, last-modified date, ETag, and URL for six public Yale ancestry-stratified sleep-statistic endpoints; bodies were not downloaded.
- `DECISION_20261015.md`: scientific rationale, publication-prior-art implications, and exact critical path.
- `sources/gwas_catalog/`: small REST metadata snapshots, GWAS-SSF metadata, and Catalog checksum lists. The multi-hundred-megabyte association files were not downloaded.
- `SHA256SUMS`: hashes of all files in this checkpoint except `SHA256SUMS` itself.

The parent directory contains the existing frozen Atlas evidence and source-audit results. No original estimate, analysis family, or project data were changed by this checkpoint.
