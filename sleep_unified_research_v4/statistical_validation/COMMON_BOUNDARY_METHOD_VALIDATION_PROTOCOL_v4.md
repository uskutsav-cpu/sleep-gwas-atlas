## Required deterministic controls before real fits

1. **Exact same-input duplicate.** Evaluate the identical pair twice using the same input/reference/option hashes and genomic partition. Require point, h2/covariance/ratio deletion arrays and marginal variance identities within the tolerances below. Sampling covariance must equal the marginal variance; the paired difference and its SE must be zero to tolerance. A degenerate 0/0 Wald P value is `NOT_APPLICABLE`, not a fabricated P=1. 2. **Independent ratio/contrast arithmetic.** Using the saved full and deletion triples, an independently written implementation computes each `r=c/sqrt(a*b)`, pseudovalues, sample covariance/B and paired-difference variance. Require agreement with adapter output and with `Var(A)+Var(B)-2Cov(A,B)`. Check covariance Cauchy-Schwarz bounds and all deletion denominators. The scalar gradient finite-difference and direct/expanded contrast checks already pass in the forensic receipt; no native array control has passed yet.
3. **Independent raw-row deletion solve.** Save final full-fit weighted design/response, full Nbar/M and mask mapping on prespecified synthetic fixtures and one real source-identity control chosen by input manifest order, not favorable outcomes. Independently delete exactly each canonical interval and solve with QR/SVD; compare to the fast block sufficient-statistic implementation. The native fast deletion freezes final weights; a full-pipeline weight/Nbar refit is a separately named sensitivity. It must not be described as the same estimator.
4. **Masked first-stage control.** Use at least two different stage masks, each leaving every interval populated. Verify the same genomic deletion IDs despite different retained row counts, and verify second-stage full-row cuts independently from coordinates. The current mock fixture passes two such masks. Include a fixture where a first-stage interval empties; it must fail before any solve. The native `update_separators` result is not admissible as a substitute for explicit coordinate mapping.
5. **Failure controls.** Reversed order, duplicate IDs, missing coordinates, conflicting build, empty full/stage blocks, unsupported old-weights path, wrong block count, unexpected callback count, nonpositive ratio h2, nonpositive conditional residual variance, singular conditional covariate block and nonfinite deletes must stop the relevant experiment. Bindings/context must restore after exceptions. Do not drop failed blocks or select a different estimator after observing a result.

Fixed numerical tolerances for successful controls: point/deletion agreement `abs_error <= 1e-10 + 1e-8*abs(reference)`; variance/covariance agreement `abs_error <= 1e-14 + 1e-6*abs(reference)`. For identity delta and SE(delta), require absolute error <= `1e-12`; do not truncate a materially negative difference variance to meet this control. Near-zero variance cases are reported separately rather than scored with relative error. These are proposed double-precision implementation limits, not evidence that the estimator is calibrated.
