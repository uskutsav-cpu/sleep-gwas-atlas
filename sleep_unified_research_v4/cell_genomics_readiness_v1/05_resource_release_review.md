# Machine-readable resource release: scope and review gate

The candidate release is generated from the frozen V4 result tables using the allowlist in `scripts/build_candidate_release.py`. Its manifest records the exact source table digests and output digests. The candidate contains 396 core correlations, 1,200 extension correlations, 41 qualified external-outcome-side estimates, 158 heritability estimates, 62 prespecified sensitivities, 12 sleep-construct records, a 158-row core/extension/validation outcome definition crosswalk, and the 217-candidate class-count summary.

The 396 core and 1,200 extension families are kept separate. The 41 estimated validation rows remain linked to the full 217-candidate classification family and use its frozen Bonferroni threshold; their sleep GWAS is reused from discovery. No row is called independent two-trait replication. The sensitivity file gives marginal estimates and intervals; its deltas are descriptive because cross-fit covariance is not calibrated.

The release is deliberately a candidate for review. It includes no participant-level records, variant-level GWAS rows, protected raw sources, local file paths, or hashes of source bodies. It does contain summary estimates and source identifiers. `discovery_outcome_trait_id` joins each external estimate back to the original extension pair; `outcome_source_id` and the family-specific `trait_id` join estimates to their label/definition records. Before public deposition, accountable investigators must verify each source's redistribution and derivative-output terms, resolve the source/phenotype metadata questions in `02_source_harmonization.tsv`, approve the exact data-availability statement, and choose a repository/license. Public source links or access do not imply permission to redistribute sources.

The release builder fails closed on missing rows or source mappings. The integrity test checks family sizes, identities, field allowlists, source mapping coverage, class totals, manifest digests, absence of local paths, and the explicit non-replication status. Those checks establish package integrity and usability only; they do not establish source validity, scientific novelty or independent replication.
