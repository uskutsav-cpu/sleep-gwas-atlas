# Sleep GWAS Atlas V7: empirical resource benchmark

V7 is a new, isolated empirical evaluation of whether source-aware atlas integration improves evidence-grounded interpretation of sleep–phenome genetic questions. It leaves the V5/V6 package and all frozen estimates unchanged.

The design was preregistered before examining any V7 cross-resource matches or benchmark answers. See [`protocol/empirical_benchmark_preregistration_v1.md`](protocol/empirical_benchmark_preregistration_v1.md). Primary outputs will include source-matching annotations, a reproducible task set, blinded answer adjudications, task-level performance, uncertainty, and a figure. Comparator raw tables and publisher supplements will remain in their existing locations or temporary SSD storage; V7 will store references and newly generated annotations rather than redistribute source tables.

This benchmark tests the utility of evidence integration. It is not a new GWAS discovery analysis, does not rerun LDSC, and cannot establish that a historical association is novel.
