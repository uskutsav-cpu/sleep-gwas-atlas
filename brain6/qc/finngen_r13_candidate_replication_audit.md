# FinnGen R13 replication candidates: source-chain audit

Audit date: 2026-09-23. This is an intake/provenance audit only; these files are not admitted as replication analyses or evidence.

The four endpoint-named compressed source files, HM3 extracts, munged files, and LDSC logs are present on the external research archive. All raw, HM3, and munged gzip files pass `gzip -t`. Observed local SHA256 and byte counts are recorded in `finngen_r13_candidate_replication_audit.tsv`. The raw file header matches the FinnGen documented R13 schema (`#chrom`, `pos`, `ref`, `alt`, `rsids`, `nearest_genes`, `pval`, `mlogp`, `beta`, `sebeta`, and alternate-allele frequencies). The official release documentation states GRCh38 coordinates and effects/frequencies for the alternate allele ([FinnGen GWAS results format](https://docs.finngen.fi/finngen-data-specifics/green-library-data-aggregate-data/core-analysis-results-files/gwas-results-format); [FinnGen access results](https://www.finngen.fi/en/access_results)).

The archived LDSC logs record case/control counts and use `--N-cas`/`--N-con`, `--merge-alleles`, `--snp`, `--a1`, `--a2`, `--p`, `--frq`, and `--signed-sumstats BETA,0`. They are legacy logs whose file path, inputs, and reference are not bound by a provenance receipt. Counts in the TSV are therefore observations from those logs, not source-verified sample metadata.

**Admission decision: EXCLUDED_PENDING_SOURCE_RECEIPT.** The archive lacks the per-endpoint release-object generation/version, acquisition date, source MD5/ETag, source receipt linking the local raw file to FinnGen’s public object, and transformation receipt binding raw → HM3 → LDSC inputs to a pinned command/runtime/reference. A local SHA256 establishes the identity of the bytes inspected, not their identity as the official R13 release object. No replication estimate was computed from these candidates.

The official R13 access page says users must submit FinnGen’s access form and receive download instructions by email. Read-only GCS JSON API checks returned HTTP 403 Forbidden for all four candidate objects at the current official R13 Green Library paths. The older `finngen-public-data-r13` summary-statistics bucket returned HTTP 404 for these four endpoints and for the already-verified ADHD endpoint, so it is not a usable source for cross-checking the archived copies. No form was submitted and no credentials or access controls were bypassed. Remote generation, MD5, and acquisition date remain unverified. The manifest’s already-verified FinnGen ADHD result is separate and remains the sole replication result.
