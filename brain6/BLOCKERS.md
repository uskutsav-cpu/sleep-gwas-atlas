## PLACO LD factor-normalization diagnostic update (2026-09-25)

The read-only audit in `qc/placo_ld_factor_normalization_v1.md` and authoritative code-bound output pair `qc/placo_ld_factor_normalization_v3.tsv` / `.provenance.json` reproduce all 12,317 unique out-of-range edges from the official reference's format-14 primary eigen-decomposed factors (maximum absolute difference `5.107e-15` from the archived pinned-LAVA replay). The factor-product endpoint diagonal ranges from `0.9996841` to `1.0017013`; diagnostic unit-diagonal rescaling places all edges within `|r| <= 1`. This is consistent with a scale mismatch but does not verify corrected values against raw genotypes or establish that rescaled values are valid LD. All original raw edges remain excluded; no candidate, locus, fine-mapping, or molecular result is promoted. The root cause and downstream eligibility remain unresolved.

The subsequent block-level diagnostic (`qc/placo_ld_primary_block_psd_v1.md`; code-bound outputs `qc/placo_ld_primary_block_psd_v2.tsv` and `.provenance.json`) expands this check to all 19 affected 250-SNP primary blocks. All stored eigenvalues are positive; factor-diagonal-normalized Gram blocks are PSD within numerical tolerance, while LAVA-style blocks that set the diagonal to one without rescaling off-diagonals are non-PSD in all 19 blocks (minimum eigenvalues −0.022055 to −0.00001258). This shows the diagonal replacement is sufficient to produce the observed range/PSD problem in the stored-factor representation. It still does not establish genotype-level LD or validate normalized values for clumping; the raw edges remain excluded.

A separately versioned factor-normalized PLACO clumping sensitivity now applies that normalization to candidate edges within the official format-14 primary blocks. It preserves all 12,317 raw out-of-range exceptions in a distinct table, records 1,922 roundoff-only boundary corrections, and exactly recovers the original 21 candidate leads and 19 intervals; simply excluding the invalid edges yielded 25 leads. Its output validator checks the provenance hashes, range guards, and exact lead/interval comparison. This sensitivity narrows the numerical explanation but does not prove the normalized factor correlations match genotype-level LD. The blocker remains open: no candidate grouping can be selected as validated without an independently checkable genotype-level LD source or equivalent reference validation, and the protected fifth PLACO track remains absent.
