# Exploratory disease–eQTL single-signal colocalization at MAD1L1

Written after the linked candidate and exact QTL were selected, before extracting regional GWAS data and viewing colocalization results. The selected GRCh38 interval chr7:1,534,487–2,534,487 centers on rs28528997 and may truncate gene cis windows. Pair two dense GTEx v8 gene/tissue eQTL outputs (AC110781.3 nucleus accumbens, MRM2 caudate) with FinnGen R13 insomnia and FinnGen-derived hospital frailty (HFRS). Report all four combinations; HFRS and insomnia releases overlap, HFRS is not FI/FFS, and GTEx is a separate post-selected adult molecular source whose participant overlap is not fully established. No conclusion about a brain-specific mechanism, repaired LAVA gate, independent replication, shared sleep–ADHD genetics or causality follows.

Extract complete original regional rows from the local full source files, verifying the insomnia SHA-256 and HFRS MD5 against previously recorded values. For each pair match exact GRCh38 chr:position:REF:ALT where available. The HFRS file has effect/other alleles rather than trusted REF/ALT, so require a unique exact unordered allele pair and align signed effect and frequency to QTL ALT. Exclude palindromic SNPs, non-SNVs, duplicate chromosome-position/allele keys, malformed statistics, and minor-allele-frequency disagreement (>0.15 absolute difference); record all exclusions and coverage relative to usable QTL variants. Use the reported eQTL minor allele frequency, which must fall strictly between 0 and 1, and compare it with min(aligned GWAS ALT frequency, 1−ALT frequency); require positive sample allele counts, finite beta and positive SE. Keep source p-values as supplied, but compute ABFs from beta/SE. No missing or excluded variant is assigned a zero effect or PIP.

Apply the pinned coloc 5.2.3 original approximate BF functions to each of the four pairs only if at least 500 exact common variants survive QC and input statistics are valid. The intended single-signal model uses eQTL effect prior SD 0.15 and HFRS SD 0.15 (normalized trait assumptions), insomnia log-odds SD 0.2. Run p1=p2=1e-4 with p12=1e-5 and 1e-6; report H0–H4, the top conditional-H4 variants and the fraction of QTL eligible records matched. Results are descriptive sensitivity after post-selection, not multiple-testing-controlled discoveries. Single causal signal per trait, uncertain prior scales, source overlap, unequal variant coverage, LD and truncation can make posteriors unreliable; no statistical validation or proof of causal gene is claimed. If gates fail, output NOT_ESTIMABLE, not zero evidence.

Because the HFRS GWAS beta scale has not been confirmed as the standardized scale assumed by the default quantitative effect prior, also calculate pre-specified joint effect-prior sensitivities: SD 0.10 and 0.30 for each of the two trait effects, in addition to the defaults, at both p12 values. These do not establish a correct prior and should not be used to select a preferred conclusion.

**Before fitting:** An initial matching diagnostic treated imported GTEx `ac/an` as ALT frequency, as described for the catalogue’s general format. In both selected GTEx tissues, all 5,022 variable AC110781.3 rows had `ac/an` equal to `maf` and none exceeded 0.5, indicating this imported file stores minor-allele counts. The match code was corrected to compare minor-allele frequencies without assigning the minor allele to REF or ALT; the initial match outputs were not used for any fit. This distinction does not change the source beta allele or replace source documentation.
