# Exhaustion file allele-mismatch and repeated-ID audit

Before inspecting whole-file mismatch details, re-stream and checksum the exact exhaustion archive from the preceding audit against its published MD5 and previously observed SHA-256. Compare to the same GRCh37 HapMap map. For every reference-ID and coordinate match, track source rsIDs with matching and different unordered allele pairs; separately track repeated rsIDs. Record all source rows with a different allele pair, including frequency and original source statistics, and mark whether another source row with the same rsID has the reference pair. Summarize overlap of mismatches, repeated IDs and exact-pair rows. Do not automatically treat a repeated ID as an error or a second independent variant; do not automatically drop all alternate alleles or infer which is the causal allele. Frequency, effect, phenotype, model, ancestry and cohort assumptions are not verified by this comparison. This is a harmonization diagnostic, not GWAS, sleep–frailty association or FFS-minus-exhaustion reconstruction. Do not save the complete source file.
