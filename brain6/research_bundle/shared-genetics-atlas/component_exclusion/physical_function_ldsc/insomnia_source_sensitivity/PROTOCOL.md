# Insomnia source sensitivity for physical-function correlations

Written before preparing the shared marker support or inspecting these results. Compare the two physical-function summary files from the previous pilot with both archived original Brain6 questionnaire-insomnia and FinnGen R13 registry-insomnia inputs. Use only markers present in all four sources with unique IDs, non-palindromic SNP alleles and direct or reverse-strand allele-pair agreement. Preserve each source's own allele order and signed Z so LDSC performs its standard alignment; require all files to have identical ordered SNP lists and audit the sample-size and hash lineage. No participant-level data or sleep-item-excluded composite is created.

Run all four unconstrained-intercept LDSC correlations using the existing EUR LD scores and jackknife deletion output, with each physical measure first. Verify identical retained marker counts, physical-trait heritability and its 200 delete values for the paired comparisons. Recover each r_g delete estimate from the saved covariance and heritability deletes, and calculate a paired block-jackknife difference between the questionnaire and registry estimates separately for walking and grip. Correct the two resulting exploratory contrasts by Bonferroni; also report the four individual correlations with a separate four-test Bonferroni correction. These families are post-hoc follow-ups after previous project analyses, not corrections across the whole atlas. Do not interpret unadjusted intervals as simultaneous intervals or infer sample overlap from the intercept.

The questionnaire insomnia and both physical measures include UK Biobank, whereas registry insomnia is Finnish; their differences combine ascertainment, ancestry/reference fit, sampling and cohort dependence. Common markers do not equal common participants, matched phenotype definitions or valid LD reference. The paired jackknife estimates genome-block covariance, but does not fix upstream sample dependence or systematic bias. Neither different nor similar r_g establishes the cause, a specific causal locus or a physical-frailty-without-exhaustion effect. Preserve all failures and warnings; do not delete inputs or other files.
