# Explicit genetic physical-function index

Specified 6 November 2026 after inspecting the latent-factor and residual sensitivities; this is post-hoc. Define a fixed equal-weight index of the standardized additive genetic components of walking pace, left grip strength and moderate-activity days, all oriented toward greater function/activity. If their genetic-correlation matrix is R, define I=(Gwalking+Ggrip+Gactivity)/sqrt(1'R1). Its genetic correlation with a standardized insomnia genetic component is sum(r_sleep,indicator)/sqrt(1'R1). This is an explicitly defined genetic index rather than an inferred latent factor, so it requires no zero indicator-specific residual covariance restriction.

Use the same nine saved moments and aligned 200 block deletes; recompute both numerator and denominator in every delete. Require positive denominator, correlation bounds, and positive-semidefinite observed four-trait matrices. Report separate registry and questionnaire estimates, paired source difference, and paired block uncertainty. Give the two source estimates a clearly limited two-test correction; report the contrast separately as post-hoc, not as project-wide error control. Do not optimize weights, drop activity based on its result, train the ML model on these inspected outcomes, claim an individual-level measured score, release a factor GWAS or equate the index to Fried-minus-exhaustion. The index gives each standardized genetic component equal weight, not each raw questionnaire point or kilogram, and may capture heterogeneous biology.

This resolves only the latent model's residual-covariance identification issue. Original GWAS quality, marker selection, overlap, differing insomnia definitions and source ancestries, general-European LD fit, sampling-covariance uncertainty and the wider exploratory search remain. A matched exhaustion-deleted frailty GWAS and independent validation remain separate requirements.
