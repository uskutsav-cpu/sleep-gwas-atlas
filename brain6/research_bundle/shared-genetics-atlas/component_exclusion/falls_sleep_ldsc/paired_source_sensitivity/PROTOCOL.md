# Paired insomnia-source sensitivity for falls

Written after viewing the initial separate-support falls–insomnia results. Reuse the previously audited common 1,020,637-marker questionnaire and registry insomnia files, and the verified public falls LDSC file. Run both pairs with the same reference, unconstrained LDSC intercepts and 200 deletion blocks. Verify identical valid-marker counts and falls-heritability delete vectors; reconstruct each jackknife rg and compare its SE with the LDSC log. Calculate questionnaire minus registry rg using paired delete values; retain its unadjusted 95% interval and p as one exploratory post-hoc contrast. Also report the two correlations, but do not claim atlas-wide correction.

The shared-marker and shared-block comparison does not hold phenotype, sample, ancestry, overlap or study model constant. Questionnaire insomnia and falls both use UK Biobank; FinnGen registry insomnia has different ascertainment and uncertain LD reference fit. Interpret no contrast as a causal effect of ascertainment, a participant-overlap correction, a physical-frailty item-deletion GWAS, or independent replication. Falls remains a distinct, non-composite physical-function-related outcome. N values and outcome coding have the caveats in the parent audit.
