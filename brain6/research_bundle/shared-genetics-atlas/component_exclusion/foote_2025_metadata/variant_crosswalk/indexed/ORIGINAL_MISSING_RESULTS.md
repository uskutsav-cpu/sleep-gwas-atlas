# Partial original-file lookup for five isolated missing records

The five selected markers with a missing general-factor record but nearby harmonized records (rs60271, rs10073929, rs40465, rs4703307 and rs8085338) were sought by short byte-range queries in the original GRCh37 source. None was observed in the sampled complete rows at the target coordinate. Because the original file is not guaranteed sorted, **this is not proof of original-file absence** and does not distinguish input coverage, Q filtering, harmonization or other causes. Each per-variant receipt records the exact sampled byte ranges and HTTP metadata. No association value was imputed. The full original-file checksum streams remain separately pending.
