# Local support around absent markers

For selected markers absent in each factor's harmonized indexed release, query up to ±250,000 bp around their uniquely lifted GRCh38 coordinates, merging overlapping intervals. Count returned rows, their physical distances, and record nearest distance for each marker. A zero-row neighborhood establishes only that no rows were returned by this remote release/index for the queried interval; it cannot identify which preprocessing or coverage step caused the absence. The published Foote methods state that SNPs with Q heterogeneity p<7.14×10⁻⁹ and their ±1 Mb neighbors were removed in downstream analyses, which can produce regional gaps; exact explanations remain unverified without unfiltered factor output. Assay is post-selected and not a statistical test, fine-mapping analysis, or inference of trait specificity. Record byte hashes for selected prior lookup, code and per-factor metadata, and retain source URL. Count includes all returned variants including potential multiallelic rows; no results on individual genetic effects are inferred.
