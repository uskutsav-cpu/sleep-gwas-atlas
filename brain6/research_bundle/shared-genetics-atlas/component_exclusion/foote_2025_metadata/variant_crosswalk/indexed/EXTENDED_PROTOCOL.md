# Extended indexed selection crosswalk

Extend the indexed lookup to the fixed list of 87 selected IDs from `selected.tsv`. Apply the hg19–hg38 UCSC chain to 1-based positions and retain only uniquely mapped autosomal positions, including strand; complement the supplied alleles on negative mappings. Use merged chromosome intervals (maximum 500 kb between selected positions) to query tabix. For each target require rsID, mapped position and unordered allele pair in a single returned row, retain all other statuses, and preserve harmonized source statistics. Nonmatching IDs at a queried position and missing rows must not become negative findings. Compare the same five anchors and seven factors with the existing separate lookup, including source field equality. Record chain, selector, code and metadata SHA-256; remote tabix access does not validate whole-file MD5 and cannot establish completeness of source data or replication. Explain Q filtering, non-independence and post-selection as in the anchor protocol. No model is trained.
