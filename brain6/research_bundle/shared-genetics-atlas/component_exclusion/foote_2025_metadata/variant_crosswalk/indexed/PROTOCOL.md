# Indexed anchor lookup

As a parallel availability and context check while full unharmonized streams run, query the GRCh38 harmonized, tabix-indexed Foote release at five prior project anchors (rs62264764, rs817509, rs2431108, rs7703746, rs1476535). Lift their already documented GRCh37 coordinates with the local UCSC hg19-to-hg38 chain, require one positive-strand mapping, exact rsID, GRCh38 position and unordered allele pair. Save the returned rows and query metadata. Treat missing records as unavailable, not as null results. Store the SHA-256 of the chain, selected list, lookup script, and downloaded harmonized metadata, plus the publisher's full-file MD5; indexed remote queries do not verify the whole-file checksum, so these are provisional until checked against a complete source read. Harmonized and original files are different releases; do not substitute the original file's checksum. The general factor includes insomnia and this post-selected descriptive lookup is not independent replication or a sleep-excluded frailty analysis.
