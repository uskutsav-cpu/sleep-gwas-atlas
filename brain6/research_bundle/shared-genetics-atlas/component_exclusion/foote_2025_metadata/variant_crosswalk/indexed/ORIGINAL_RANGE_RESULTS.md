# Original versus harmonized source-row crosscheck

For four general-frailty anchors, short HTTP range queries found the exact original GRCh37 source row and compared it with the previously extracted harmonized GRCh38 row: rs62264764, rs817509, rs2431108 and rs7703746. For each, the harmonized effect allele is the other allele in the original record. After reversing the beta and complementing the effect-allele frequency, beta, frequency, standard error, association p, Q statistic and Q p agree between the two records. For example, rs62264764's original G beta +0.005357 becomes A beta −0.005357 in the harmonized file. This prevents an apparent sign discrepancy caused by changing the counted allele; it does not establish the direction of any causal effect on sleep or frailty.

The comparison verifies these **four returned records only**. The source's original metadata does not guarantee sort order, so range searches that do not find an ID cannot establish absence. The original general-factor file was subsequently fully read and passed its publisher checksum; the complete harmonized file was not checksum-verified and its index was queried remotely. Both representations derive from the same study and are not independent replication. The general factor contains insomnia and overlaps UK Biobank data.

`original_harmonized_comparison.tsv` records all allele-adjusted values; `*_original_row.tsv` and `*_range_receipt.json` preserve source rows, ranges, HTTP metadata and hashes. `compare_original.py` repeats the field checks.
