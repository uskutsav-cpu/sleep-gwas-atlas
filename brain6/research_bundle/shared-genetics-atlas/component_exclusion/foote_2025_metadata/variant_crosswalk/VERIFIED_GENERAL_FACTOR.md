# Full original general-factor file verified

The original GRCh37 Foote general-factor table was read completely in 201 ordered HTTP ranges. Its 420,712,217 bytes have MD5 `37f7f24f76a11a99e8840687ed847034`, matching the publisher's metadata, and SHA-256 `376ba5f1aa4591a8f7a08301aa6f515ff5272ae8e0a4ef366778b59965dd006b`. Every range's status and byte count were checked before assembling the hash. The full file was processed in memory rather than stored in the bundle. The publisher's original file is already filtered; the checksum establishes its byte identity, not scientific validity or completeness of the unfiltered GWAS.

Among 87 selected project markers, the original has 32 unique exact rsID, coordinate and allele matches and 55 absent IDs. The separate GRCh38 harmonized indexed query has exactly the same match/absence pattern after unique positive-strand liftovers. All 32 matched rows agree in beta and effect-allele frequency after reversing the effect allele, and agree in SE, p, Q and Q p. This verifies same-study consistency and clarifies that the 55 selected IDs are absent from the **full original filtered file**, not just missing after harmonization. It does not determine whether Q filtering, initial input coverage or another upstream step removed any specific marker; absence is not evidence of no association. No independent replication is provided.

`GCST90624046_receipt.json` contains the full-stream byte counts, hashes and source, `GCST90624046_crosswalk.tsv` the selected source rows, and `reconciliation.tsv` the comparisons. `extract_ranges.py`, [the chunk protocol](CHUNK_RETRY_PROTOCOL.md), and `reconcile.py` document reproduction.
