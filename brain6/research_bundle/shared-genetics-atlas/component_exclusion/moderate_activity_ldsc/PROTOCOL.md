# Moderate activity and insomnia: exploratory protocol

Use the Neale Lab primary, both-sexes LDSC-formatted GWAS for UK Biobank field 884 (number of days per week of moderate physical activity lasting at least 10 minutes), as listed in its public LDSC manifest. Before interpreting results, verify the full gzip stream, source hash, alleles, SNP overlap, N, phenotype coding, and LDSC diagnostics. Run exploratory LDSC with the existing questionnaire and registry insomnia files using the existing European LD reference; report both runs and failures. Account for post-hoc project-wide testing and potential UK Biobank overlap with questionnaire insomnia, and Finnish LD-reference mismatch for registry insomnia. Do not interpret direction until source phenotype coding is verified. This activity trait is not a four-component score, clinical frailty, causality, or independent replication.
