# Later NHANES physical-item and sleep pilot

Specified before fitting the model. Use the five publicly accessible 2017–March 2020 pre-pandemic CDC files verified by the parent availability audit. Stream source data into memory and pipe derived working variables to R without writing person-level rows. Age domain is 60 and over. Use self-reported weekday/main-sleep-period SLD012; its top/bottom codes are retained as numerical endpoints and it does not include all sleep. Set recreational inactivity to 1 only if both moderate and vigorous recreational-activity answers are no; if both are valid and either yes, use 0. Define low energy as DPQ040 >=2, valid 0–3. Define loss >=5% from current and one-year-prior self-reported pounds. Loss under 5% and intentional loss are coded 0, loss >=5% with WHQ060=no as 1; 5% loss without a usable intentionality answer is missing in the primary analysis. Model it as 0 and 1 in two additional sensitivity analyses.

Compare two-component physical score (unintentional loss + recreational inactivity) and three-component score (same components + low energy) against weekday sleep duration on the SAME complete sample within each assumption. Both scores are partial constructs, not validated Fried categories or matched item-excluded GWAS. Use the NHANES pre-pandemic examination weights, design strata and PSUs, keeping the full positive-weight design before domain subsetting. Estimate survey-weighted Pearson correlations and paired differences using linearization; t intervals use survey design degrees of freedom. Treat all results as exploratory, no project-wide correction or causal interpretation. The resulting pairwise differences include both score scaling and component changes; they do not isolate a causal contribution of exhaustion. Report sample sizes and missingness; do not claim independent replication or equivalence. Since the skipped-response assumptions alter the sample, compare scenarios descriptively, not as same-sample causal effects.
