# Working crosswalk for the exploratory NHANES pilot

**Correction:** The original script omitted HUQ051 code 8 (16 or more visits). A separately preserved [corrected rerun](visit_code_audit/RESULTS.md) assigns that category a score of 1. The 2013–14 category 4–5 visits also straddles the working cutoff and remains an assumption.

This table documents the code in [score_and_analyze.R](score_and_analyze.R); it is an **approximate reconstruction**, not independently validated author code. It combines the [49-item FI table](https://pmc.ncbi.nlm.nih.gov/articles/PMC11869335/) with a different [NHANES adapted Fried study](https://pmc.ncbi.nlm.nih.gov/articles/PMC6440876/). Examine the source supplement's merged cells and cycle-specific CDC codebooks before interpreting the resulting constructs as published instruments.

The full FI averages observed components and requires at least 40 of 49; both DPQ030 and DPQ040 must be present in the paired analysis. The modified FI removes both and divides by the number of remaining observed components. A separate FI-minus-sleep is computed but not a primary reported contrast. This missing-data rule and grip aggregation are working choices; actual authors' code, measure quality and construct validation remain outstanding.

The five adapted Fried components are BMI ≤22.5 or ≥5% unintentional weight loss; difficulty walking between rooms (PFQ061H); difficulty lifting/carrying (PFQ061E); difficulty walking a quarter-mile (PFQ061B, an exhaustion **proxy**); and <600 weekly MET-minutes from work, transport and recreation questions. No activity in a domain is zero; missing or invalid activity data remain missing. The modified 0–4 score drops PFQ061B. BMI and weight-loss tests use three-valued OR: a known positive is sufficient, but a negative requires both components known negative. This avoids incorrectly treating missing BMI or intentionality as no deficit. These are self-report proxies and differ from the Fried measures in the UKB GWAS.

The mobility-proxy sensitivity assigns a deficit to skipped PFQ061B/C for participants reporting difficulty walking without equipment. This is an assumption, not their observed response. `visits_low`/`visits_high` assign 0.5/1 to the ambiguous earlier-cycle visit category. Cohort size differs for the mobility sensitivity, so comparing it with the primary result mixes scoring and selection. No scenario establishes clinical causality or a physical-only latent construct.
