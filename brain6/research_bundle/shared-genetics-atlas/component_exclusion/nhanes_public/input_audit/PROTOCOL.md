# NHANES public-file readiness check

Before inspecting the public data, obtain CDC 2011–2012 and 2013–2014 demographic (DEMO), depression screener (DPQ), physical function (PFQ) and grip-strength (MGX) SAS transport files. Hash original downloaded bytes. Check file parsing, one row per participant, availability of the age, survey-design, sleep, fatigue, shared functional-question and grip variables, and the number of respondents aged 60 or older with explicit nonmissing response codes for DPQ030, DPQ040, PFQ061B and PFQ061E. Report raw unweighted file counts only; they are not population estimates, phenotype correlations, FI scores or effect tests. Do not infer that skipped PFQ items are negative responses.

This is preparation for the proposed 49-item FI and adapted Fried phenotype, not a substitute for constructing both scores. The published scoring table has ambiguous or merged cells; all remaining source variables, skip codes, missingness, cycle harmonization and survey weights need a documented crosswalk before inference. Grip is one component of the 49-item FI in the identified table but the separate adapted Fried study uses a lifting-difficulty proxy instead. The two published instruments share physical-function questions. No individual-level rows will be written into the atlas; original public source files remain on the SSD.
