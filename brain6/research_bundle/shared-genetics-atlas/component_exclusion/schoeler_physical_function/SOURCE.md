# Public baseline physical-function composite: source assessment

Schoeler, Pingault and Kutalik's [2025 study](https://pmc.ncbi.nlm.nih.gov/articles/PMC12081661/) reports an objective baseline physical-function composite from UK Biobank. Its associated [GWAS Catalog study GCST90565837](https://ftp.ebi.ac.uk/pub/databases/gwas/summary_statistics/GCST90565001-GCST90566000/GCST90565837/) supplies anonymous, CC0 summary statistics; the [metadata](https://ftp.ebi.ac.uk/pub/databases/gwas/summary_statistics/GCST90565001-GCST90566000/GCST90565837/GCST90565837.tsv-meta.yaml) lists 405,979 European-ancestry participants and GRCh37 positions. The paper's figure describes higher baseline scores as higher physical function.

The article says the baseline composite uses the same selected aging phenotypes as the longitudinal analysis. The three physical traits in the published supplementary table are forced expiratory volume, hand grip strength and height. The independently reproducible [supplementary-table receipt](supplement_receipt.json) records the source URL and file hash. The follow-up sample sizes in that table are not the baseline GWAS sample size. This composition contains no explicit sleep or exhaustion item, but the traits and their genetics may still relate to sleep.

This is a physical-function sensitivity, not a Fried frailty score, an exhaustion-deleted version of an existing frailty instrument, or a test of causation. Height and lung function contribute to the phenotype, and UK Biobank participant overlap with other datasets is possible. A matched frailty score with those items removed remains the direct test of the original question.

The [analysis protocol](PROTOCOL.md) was written before inspecting the full GWAS. The [completed comparison](RESULTS.md) records the full-source checksum, matching, results and diagnostic limitations.

## Prior insomnia analysis

The same paper already tested insomnia as an exposure against this baseline physical composite using Mendelian randomization: its supplementary table reports an inverse-variance-weighted estimate of −0.179 (95% CI −0.388 to 0.029; p = 0.092; 33 instruments), with different estimates for longitudinal decline. This is an imprecise prior estimate, not proof of no effect; instrumental-variable assumptions and sample overlap matter. Supplementary Data 6 says the insomnia GWAS was generated in UK Biobank using REGENIE, so the exposure and outcome are both UK Biobank-derived and may overlap; the exact overlap is not established here. It is a different estimand from the planned genome-wide genetic correlation, so the values should not be compared as though they measured the same thing. The [extraction receipt](prior_mr_receipt.json) and [script](prior_mr_check.py) preserve the table and exact values. The existence of this prior analysis limits any novelty claim about insomnia and this composite.
