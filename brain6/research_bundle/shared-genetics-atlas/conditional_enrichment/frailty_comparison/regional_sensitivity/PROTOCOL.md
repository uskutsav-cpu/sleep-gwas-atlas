# Regional sensitivity for common-support conditional fractions

This post-hoc check uses the already saved 5 Mb block counts from the common-support FI/FFS/HFRS analysis. Recompute all three insomnia p≤0.01 fractions within each frailty p≤0.001 set after removing each autosome in turn and, separately, after excluding the chr19:45,000,001–50,000,000 GRCh37 block (`19:9`, which contains the APOE region). Recompute the unconditional insomnia baseline on the same remaining markers; save removed marker counts, conditioning counts and paired outcome fractions. Also summarize per-block HFRS conditioned and joint counts, sorted descriptively. The APOE block is selected after seeing prior HFRS findings; it is a broad physical window containing many variants and genes, not an APOE-specific test. Chromosome removal and top-block review are post-hoc sensitivity analyses, not independent tests, genetic-correlation estimates, calibrated FDR, fine mapping or causal evidence. Frailty cohorts, ascertainment, measurement overlap, and LD remain unchanged. No individual data or model-derived variant effects are used.
