# Smoothing sensitivity across ten paired simulated datasets

In the same ten zero-overlap, linkage-block simulations from the [parent test](../RESULTS.md), the default settings reproduced **6/10 datasets with false conjunction-FDR threshold crossings**. With smoothing disabled and the other settings fixed, **0/10** had a crossing at 0.05. All 44,000 values per run were finite in both settings. The smallest unsmoothed run minimum was 0.326; the smallest default minimum was 0.00555.

These are paired reanalyses of the same data used in the original stress test, selected after inspecting one seed, not independent validation. Under the model every trait-2 effect is zero. Ten zero-event runs cannot establish control: an illustrative one-sided 95% upper bound for the probability of any crossing in this exact setting is approximately 25.9%. The test has no shared true effects and therefore does not assess power, and it does not represent realistic LD, varied architectures, uncertainty in the reference or sample overlap. It supports investigating smoothing further; it does **not** establish that smoothing is incorrectly implemented or that disabling it provides reliable real-data FDR.

The initial run stopped on a bookkeeping error in the check that selects prior rows; its log is retained. The corrected retry used a new SSD directory, reproduced every default result and completed all 20 setting–dataset combinations. Source and reference integrity, full-method validation, overlap correction and independent statistical review remain necessary before any real-data conjunction-FDR claim.
