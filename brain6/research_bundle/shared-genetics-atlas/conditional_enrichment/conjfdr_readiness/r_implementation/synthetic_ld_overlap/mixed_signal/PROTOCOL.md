# Conjunction-FDR mixed-signal stress protocol

Before running, use the parent study's fixed artificial reference: 22 chromosomes × 2,000 markers, blocks of 10 and exactly one retained marker per block in each of five pruning draws. Use ten fresh seeds 71001–71010. For each seed, generate two normally distributed LD-block residuals with within-block correlation 0.5, and then evaluate residual cross-trait correlations 0 and 0.3 on the same effects and draws. Randomly assign 4,400 blocks without replacement to 22 shared, 198 trait-1-only, 22 trait-2-only and the remainder null for both. Add a fixed mean of +4 to every marker in a block for each affected trait. Thus a marker is truly non-null for both traits only in a shared block under this synthetic definition; this is deliberately simple and not a simulation of fine-mapping or causal variants.

Run the same locally patched R implementation twice on each dataset, with smoothing enabled and disabled and otherwise identical settings, using 0.05 as a numerical cutoff. Record true and false marker-level and block-level crossings separately, false-discovery proportion V/max(R,1), fraction of shared blocks recovered, and the minimum score. As a conservative comparator calculate Bonferroni and BY corrections on marginal max-p values using all 44,000 markers. Record paired results and full marker-level score vectors, generated Z scores and block assignments on the SSD. With only ten datasets per setting, intervals and estimated FDR are highly uncertain; simulations are not real-data calibration, power estimates, or independent cohorts. Do not run real-data conjFDR on the basis of this test alone.

The parent pure-null diagnostic and smoothing reanalysis motivated this post-hoc model. The chosen block correlation, sparsity, signs, equal means, reference, five pruning draws and overlap settings are arbitrary; they do not represent realistic GWAS architecture or establish general FDR control. Treat block-level summaries as descriptive rather than a claim of formally calibrated block-level inference. AlphaGenome scores are not used.
