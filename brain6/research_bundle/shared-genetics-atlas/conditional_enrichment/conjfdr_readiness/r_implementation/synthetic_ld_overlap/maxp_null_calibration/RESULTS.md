# Max-p negative controls in 500 new simulated datasets

In each of **500 new simulated datasets**, every marker was null for trait 2, although 5% of blocks had a trait-1 effect. For both tested residual correlations, 0 and 0.3, **none of the 500 datasets had any marker crossing 0.05** after applying max-p followed by Bonferroni, Benjamini–Yekutieli (BY), or Benjamini–Hochberg (BH). The exact two-sided 95% binomial interval for each zero-event rate is 0 to 0.00735. The two correlation settings reuse the same draws and are not 1,000 independent datasets.

Here, any rejection is a false conjunction rejection by construction, so the run-level probability of any rejection equals the marker-level FDR in this all-conjunction-null scenario. This check supports the use of conservative max-p controls for further testing under the specified valid marginal-p simulation. It does **not** validate conjunction-FDR, establish real-data calibration, quantify power or shared-variant causality, or justify BH under arbitrary dependence. The different negative-control methods test joint marginal association and do not estimate the same quantity as conjunction-FDR. The earlier 6/10 default conjunction-FDR crossings used a different set of ten seeds, so these results are not a paired method comparison.

Max-p is a valid intersection–union p-value when both marginal p-values are valid, regardless of their dependence; Bonferroni controls familywise error under arbitrary marker dependence, and BY controls FDR under arbitrary dependence provided valid inputs. Real summary statistics can violate those assumptions through confounding, miscalibration or data processing. Our artificial block LD, fixed effects, pairwise residual-correlation values and sample size do not reproduce all real GWAS conditions, and this all-null conjunction setting contains no power information. It neither resolves the original LAVA quality failures nor supplies a validated overlap correction for conjunction-FDR.
