# Synthetic LD and study-correlation conjunction-FDR stress test

Before running, construct 44,000 markers in 22 chromosomes, arranged as 4,400 independent blocks of 10 markers. Within each block, simulate exchangeable sampling-error correlation r=0.5 between any pair, giving r²=0.25. The synthetic reference graph has edges between all distinct markers in each block and no edges between blocks; it is matched to this simple model, not to observed human LD. For each of ten prespecified seeds, select 5% of blocks and add mean +4 to trait 1 throughout those blocks. Trait 2 is null everywhere. Generate paired study-error correlations ρ=0 and ρ=0.3 using the same underlying errors and chosen blocks; neither ρ is an estimate of real sample overlap.

Run the locally patched `cfdr.pleio` on the synthetic data with its default genomic correction and smoothing and five pruning iterations with a fixed seed. Create a fresh dedicated SSD reference directory for each run because the initializer can overwrite its destination. Check that pruning retains exactly one marker per 10-marker block on every iteration; if not, stop and do not interpret the test. Report complete output validity, the number of conjunction values ≤0.05, the number of runs with any such value, and minima. Under this one-trait-only design every conjunction rejection is false by construction, but ten runs, simple artificial LD, one architecture and no sample-overlap correction cannot establish real-data FDR control. A zero-event run count has one-sided 95% upper bound 1−0.05^(1/10)=25.9% for the probability of any rejection in this specific simulation. The paired scenarios are not independent of each other. Do not use these outputs as real GWAS associations, gene evidence or a correction for the failed LAVA gate.
