# Small synthetic sample-overlap stress protocol

Before running, use the locally patched `cfdr.pleio` with the previously created 44,000-variant, 22-chromosome no-LD synthetic reference. For each of 10 prespecified seeds, draw independent standard-normal error vectors e1 and e2 and randomly select 5% of markers. Set trait-1 Z=e1+4 at selected markers and e1 elsewhere; set trait-2 Z=rho*e1+sqrt(1-rho²)*e2 at every marker, with rho=0 and rho=0.3 in paired runs using the same draws. Thus every marker is null for trait 2, and all markers satisfy the conjunction null in this simplified model; rho is an illustrative error correlation, not an estimated participant-overlap proportion.

Run the package's default genomic correction, smoothing, and both directional FDR fits; use one seeded pruning iteration because this reference has no edges. Report, for each run, finite output counts, number of conjunction values <=0.05, smallest value and whether any threshold crossing occurs. Treat threshold crossings under the simulation as false conjunction rejections by construction, but do not equate this scenario with the real data or use ten simulations to establish or reject FDR control. Simulations omit LD, genome-wide architecture, phenotype definitions, realistic effect distributions and uncertainty in the correlation; no real GWAS or AlphaGenome data are analyzed. Preserve logs, seeds and warnings. Each iteration uses a newly created dedicated local reference directory on the SSD.
