# Post-hoc insomnia N-convention sensitivity

Before matching or seeing the sensitivity results, compare the archived original Brain6 insomnia–ADHD correlation under two insomnia N representations on exactly the same input rows. Stream the current archived raw insomnia file and match its per-variant N to the munged insomnia file by unique rsID and exact or reversed non-palindromic A1/A2 alleles. Exclude duplicate IDs, mismatches, invalid/missing N and invalid munged statistics from both versions. Record all exclusion counts and hashes. The matched baseline retains the archived constant 313750.036 N; the alternate uses raw per-variant reported N, leaving SNP, alleles and Z unchanged. Verify both gzipped tables by paired full streaming; use the same archived ADHD input and LDSC executable, references and flags as the earlier reexecution. Compare number of SNPs after matching, r_g, SE, p and intercept. Compare the matched baseline to the full original run to reveal selection effects.

Raw source N may be total rather than effective and the correct meta-analysis sample-size convention is not established. Neither version is asserted correct, and this is a post-hoc numerical sensitivity, not independent replication, a correction of the published analysis, validation of disease-scale h2, or evidence of causality. Per-variant N alteration changes weights and may change the estimator; any agreement does not validate ancestry, alleles, source provenance, cohort overlap or local QC. Do not alter original inputs or delete files.
