# Insomnia–ADHD genome-wide LDSC: fresh same-data re-execution

A new cross-trait LDSC run using archived Brain6 insomnia and ADHD munged summary statistics and the available European LD-score reference reproduced the prior atlas values to their reported precision: **r_g = 0.4033, SE = 0.0318, z = 12.701 and p = 5.836×10⁻³⁷**. The stored 396-test BH q-value is 2.56784×10⁻³⁵; that correction was separately reconstructed over all 396 original p-values and was not recalculated as a one-pair family. The LDSC log's formatted summary table displays the tiny p as `0.0000`, but its full correlation section prints 5.836×10⁻³⁷; it is not literally zero.

The run used 1,054,978 SNPs with valid alleles after merging. LDSC printed h²=0.0571 (SE 0.0025) for insomnia and 0.1639 (SE 0.0079) for ADHD, with cross-trait intercept −0.0035 (SE 0.0072). The log labels h² observed-scale, but an [input N audit](../input_n_audit/RESULTS.md) found an effective-N convention for representative ADHD rows and an unresolved transformation of insomnia N. These values are N-dependent outputs, not validated observed- or liability-scale heritability estimates. The log reports a compression runtime warning but both files were read and the run completed. A negative near-zero intercept estimate is not proof of no participant overlap. The original rounded r_g/SE ratio need not exactly reproduce the unrounded p.

Both munged input SHA-256 values match the later Brain6 alternative-local-validation protocol freeze. `receipt.json` records the exact source hashes for these inputs, the 22-chromosome LD scores and M files, the LDSC implementation and the output log. The original atlas's full `rg_insomnia.log` and exact original run provenance remain unavailable; the new run demonstrates a numerical match, not proof that every prior software or reference byte was identical. It reuses the same candidate GWAS data, so this is not independent cohort replication, causal inference, or resolution of the failed LAVA local quality gates. Reference and ancestry fit, sample overlap, and source GWAS ascertainment still matter.

The [protocol](PROTOCOL.md), `run.sh`, `verify.py`, complete `insomnia_adhd.log`, and `receipt.json` make the check reproducible on the mounted source volume. The [original global audit](../GLOBAL_RECHECK.md) documents the 396-test correction and the separate FI–FFS uncertainty audit.

A post-hoc [same-marker insomnia N sensitivity](../input_n_audit/insomnia_n_sensitivity/RESULTS.md) produces r_g=0.4034 with raw per-variant N versus 0.4033 with the archived constant N; neither convention is validated by that stability.
