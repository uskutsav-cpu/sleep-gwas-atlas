# FI–FFS LDSC re-execution protocol

Independently re-execute standard cross-trait LDSC using the exact input paths named in the archived FI–FFS native record, the available project EUR LD scores and weights, and unconstrained intercepts, to compare printed r_g, SE, p and SNP count with the saved exact record. Hash both source files, all reference chromosomes, implementation and log; inspect for numerical/runtime warnings and compare cohort and sample support. The original archived method used its native implementation; the standard archived LDSC may differ in code version, input reading or reference, so agreement is a numerical same-data check, not proof of identical provenance or an independent cohort. Do not confuse genetic r_g with measured phenotypic correlation. Exact UKB sample overlap remains unverified, and the two frailty phenotypes include fatigue/exhaustion.
