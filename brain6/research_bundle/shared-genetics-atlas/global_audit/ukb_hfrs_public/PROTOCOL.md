# Public UK Biobank hospital-frailty source audit

Written after inspecting the source listing and first two rows, before streaming the file or examining associations. The 2026 [public release](https://figshare.com/articles/dataset/GWAS_of_Hospital_Frailty_Risk_Score_HFRS_in_FinnGen_and_UK_Biobank/31259023) provides the UKB HFRS fastGWA summary statistics underlying Mak et al. 2025. This is a same-study source comparison, not an item-excluded FI/FFS or independent replication. The first inspected rows say N=407,643, whereas the article and release description state 407,463 participants; this discrepancy must remain visible and its scope checked, not silently repaired.

Stream the complete 280,558,723-byte gzip without retaining the full file, verify its publisher MD5 `4eafec0dc6a5e07612d22873ae45bb79`, SHA-256 and gzip completion, and count all rows and observed N values. Match only the previously defined four-source common-marker set against the existing unique-ID GRCh37 HapMap map using rsID, chromosome, position and non-palindromic unordered SNP allele pair. Inspect allele and coordinate mismatches and duplicates rather than keeping an arbitrary row. Retain only one unique, matched row per ID with finite beta, positive SE and N, valid p, INFO≥0.9 and minor allele frequency≥0.01. Record all exclusions and compare beta/SE-derived p to source p as a diagnostic. Generate LDSC inputs with A1 as the fastGWA effect allele, Z=BETA/SE and per-row N as reported; document that GCTA's conventional A1 semantics and the coordinate crosswalk support but do not independently prove this source's conventions. Save only the filtered file and small receipt on the SSD. Do not delete user data.

If coverage and input checks succeed, use common markers across this UKB HFRS file, the existing Finnish HFRS, FI, FFS, questionnaire insomnia and registry insomnia. Rerun with the same EUR LD reference and unconstrained intercepts to compare HFRS–insomnia relationships across HFRS source and sleep source. Report all estimates and all missingness. Exact UKB/FinnGen overlap, cohort relatedness, source-specific N discrepancy, reference ancestry and phenotype ascertainment remain limitations. Paired block-jackknife comparisons require identical ordered support, validated delete-block alignment and appropriate correction of the planned contrasts. Differences cannot isolate a biological phenotype from source or cohort effects; no local-correlation QC rescue, shared causal variant, or sleep-item-excluded finding follows. If stream integrity or allele/build checks fail, stop before inference and report the failure.

After the whole-file audit and before inspecting any HFRS–insomnia output, the 2×2 planned analysis is specified: both UKB and Finnish HFRS against questionnaire and registry insomnia, on the exact UKB-HFRS filtered intersection (a subset of the prior FI, FFS and physical-function common set). Run four correlations with 200 deletion vectors. Test four paired contrasts: UKB-minus-Finnish HFRS within each sleep source, and questionnaire-minus-registry insomnia within each HFRS source. Report Bonferroni p over four correlations and separately over four contrasts; these post-hoc families do not cover the whole atlas. Confirm that the unchanged trait's heritability delete values are identical within each contrast and reconstructed SEs agree with the individual logs. The metadata/sample-size mismatch is retained; using the supplied constant N is an exploratory modeling choice, not confirmation of the actual cohort count.
