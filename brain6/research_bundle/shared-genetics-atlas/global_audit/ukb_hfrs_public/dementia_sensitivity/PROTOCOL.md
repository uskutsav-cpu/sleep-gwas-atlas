# HFRS without dementia: genome-wide sleep sensitivity

Written before streaming the dementia-excluded file or inspecting any of its results. The same authors' [public release](https://doi.org/10.6084/m9.figshare.31259023.v1) contains a UK Biobank HFRS with dementia weights removed. This is a dementia-component sensitivity, not a frailty index without insomnia or an FFS without exhaustion. Review the metadata, stream the full 280,547,193-byte gzip without retaining it, verify publisher MD5 `68d413550cbc2b3d7b4857ad36b7b4f7`, gzip completion and SHA-256, and record reported per-row N distribution and any difference from the published cohort count. Restrict matching to the existing UKB-HFRS common marker list and verify unique rsID, GRCh37 reference position, non-palindromic allele pairs, INFO≥0.9, MAF≥0.01, finite BETA/SE and p-value compatibility. Preserve all failures. Use conventional fastGWA A1 as the effect allele and per-row N as supplied, while flagging the original source N discrepancy and any new issues.

If source integrity, coverage and harmonization checks succeed, compare original and dementia-excluded UKB HFRS with both questionnaire and registry insomnia on their exact common marker support, using the same EUR LD scores, unconstrained intercepts and 200 LDSC delete blocks. Run all four correlations; report their four-test Bonferroni-adjusted p-values. For each insomnia source compare original minus dementia-excluded r_g using paired block jackknife and correct the two contrasts by Bonferroni. Verify identical shared-insomnia heritability delete vectors and that reconstructed individual SEs match the logs. Report any warnings, missing markers and source hashes. These post-hoc correction families do not cover the atlas as a whole.

The original and modified HFRS are same-cohort outcomes, and the UKB questionnaire insomnia and HFRS sources overlap by cohort; exact shared participants are unverified. Registry insomnia is a different phenotype and FinnGen ancestry may mismatch the general-European LD reference. An attenuation or persistence of r_g after removing dementia does not establish mediation, causation, sleep independence or independent locus replication. The modified score is not the requested sleep/exhaustion-excluded composite; no local-QC gates are rescued. Do not delete files or overwrite original inputs.

After the source scan and before inspecting dementia-excluded correlations, all 1,020,621 original-HFRS markers were retained. Reuse the two existing original-HFRS LDSC logs and delete vectors from the parent analysis, whose inputs have the same ordered support, and run the two dementia-excluded pairs on those identical insomnia inputs.
