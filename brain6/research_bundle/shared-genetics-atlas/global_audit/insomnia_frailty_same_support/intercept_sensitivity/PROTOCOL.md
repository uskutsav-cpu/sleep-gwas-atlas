# HFRS–registry-insomnia intercept sensitivity

After the main unconstrained LDSC result, repeat the same full 1,134,953-marker R13 insomnia–HFRS run with genetic-covariance intercept fixed to 0.165, 0.193 (roughly the originally estimated 0.179 ± 0.014) and 0, keeping the two univariate h² intercepts unconstrained. The zero-intercept run is an explicitly artificial stress case, not an assumption justified by overlap: both GWAS use FinnGen. The nearby fixed values do not represent independent measurements, formal confidence limits, a range of plausible corrected results, or a substitute for a validated overlap/ancestry model; the original intercept and slope estimates are correlated and are derived from the same data. The exercise demonstrates sensitivity to conditional assumptions, not calibration or causation. Keep the original unconstrained estimate as primary exploratory report and record all logs, hashes and software inputs.
