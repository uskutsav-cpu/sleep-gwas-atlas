# Coordinate-resolved support sensitivity

After inspecting the HFRS coordinate-audit status, run a post-hoc sensitivity excluding all selected markers without a unique exact HFRS source-coordinate/allele match under the pinned GRCh37→GRCh38 chain. This includes both unmapped/ambiguous and alternate-contig mapping cases, without assuming those cases are incorrect. Apply the same exclusion to FI, FFS, HFRS and insomnia, retain identical order and alleles, and verify that 537 unique selected rsIDs are excluded and 1,134,416 remain. Hash the input sets, source selection, scripts and reference. Re-run the same unconstrained LDSC models and compare their reported r_g and SE with the earlier 1,134,953-marker fit. This is not an independent cohort, a new multiplicity family or proof that removed variants are invalid. It tests whether this specific small support change materially alters the estimates; it does not address uncertainty in the LD model, per-SNP sample size, case definition or participant overlap. Report failures or count mismatches explicitly. Do not present the new sensitivity as resolving local LAVA quality gates or causal sharing.

Paired sensitivity addendum: on the same restricted inputs, repeat the three regressions with 200 delete blocks and reconstruct per-block genetic correlations from covariance and both heritability deletions. Verify identical shared-insomnia deletion values, valid positive heritabilities, completed outputs and each reconstructed SE against the reported SE. Compare HFRS−FI, HFRS−FFS and FI−FFS against the corresponding original-support paired results; use Bonferroni correction across the three restricted-support post-hoc contrasts. Because estimates and delete blocks arise from the same input data, similar contrasts are sensitivity evidence, not independent replication. Four-decimal logged point estimates are used unless exact values are available, so the contrast and p are approximate.
