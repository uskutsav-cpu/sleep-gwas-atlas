# HFRS selected-marker GRCh37-to-GRCh38 coordinate audit

For all 1,134,953 HFRS markers used in the registry-insomnia LDSC comparison, obtain unique rsID coordinates from the exact GRCh37 EUR LD-score reference. Uniquely lift each 1-based reference point to GRCh38 using the pinned UCSC hg19ToHg38 chain, recording ambiguous/unmapped status and mapping strand. Scan the original catalog-verified GRCh38 HFRS TSV and for each selected rsID compare chromosome, lifted position and nonpalindromic allele pair, complementing the selected alleles for negative-strand liftover. Require exactly one matching original record; separately count missing rsID, missing/ambiguous reference, invalid/unmapped chain result, coordinate mismatch, allele mismatch and multiple exact hits. Hash the full raw source during the scan and compare its MD5 and size with the frozen publisher metadata. Save bounded examples and the chain and inputs' hashes. Identical rsID, coordinate and allele after liftover are strong representation evidence but do not independently validate the reference genome's sequence alleles, ascertainment, original effect model, true per-variant N, participant overlap or ancestry match. This is an audit of selected markers, not a full source liftover or an independent GWAS.
