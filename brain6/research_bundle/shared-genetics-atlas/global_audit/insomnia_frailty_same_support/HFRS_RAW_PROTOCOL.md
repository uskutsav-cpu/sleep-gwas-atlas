# HFRS raw-to-filtered allele and value audit

Stream the full original GCST90707291 GRCh38 TSV and compare the project's entire 1,161,680-row HFRS_HM3 filtered table to the original by rsID, chromosome and nonpalindromic allele pair. Accept direct, allele-swapped, strand-complemented and complement-swapped representations, adjusting beta sign and EAF as appropriate; compare beta, SE, p and EAF to source within numeric precision, and verify the filtered N is the study-level 500,737, not a verified per-variant N. Record missing IDs, zero or multiple allele matches, duplicate filtered IDs and mismatches separately; do not silently accept multiple compatible source records. Hash the full original bytes while reading and compare MD5 and byte size with the project's frozen catalog metadata; hash the filtered input and compare the original project manifest. Since the filtered table lacks base-pair coordinates, this verifies chr/rsID/allele consistency but is not an exact GRCh38-to-GRCh37 coordinate-liftover audit. Missing or ambiguous matches must not be treated as validated. This is a source-transformation audit, not a reanalysis of the original HFRS GWAS, overlap assessment or evidence of causality.
