# FFS input readiness for chromosome 5

Written before checking this region. Use only the 2,337 FI–R13 matched candidate SNPs in the earlier post-selected chromosome 5 window and scan the published Ye FFS FUMA-style file for unique rsID, coordinate and unordered allele-pair matches. Record source alleles, beta, SE and p and count duplicates, invalid values and mismatches. Compare source p with the two-sided Wald p computed from beta/SE; never silently substitute one for the other. Coordinate matching to a GRCh37 file is a diagnostic, not independent authentication of the FFS genome build. The FFS file has no allele-frequency field and its source A1 convention and the exact FUMA p/BOLT mapping have not been author-confirmed.

Do **not** calculate or promote an FFS colocalization posterior until the original phenotype/effect scale, allele convention, build, model and reference allele frequencies are sufficiently established. The published 0–5 FFS distribution can inform phenotype-scale context but cannot establish whether summary betas were standardized or which BOLT statistic is reported. A genotype reference, verified source documentation and source-appropriate priors are needed. This audit is post hoc, selected and descriptive; it is not a new replication, local genetic correlation or test of a causal variant.

**Post-audit update:** an independent full-reference rerun strongly supports GRCh37, and FUMA/BOLT documentation supports an A1 effect-allele inference. The exact author column mapping, coefficient scaling and model-specific statistic remain unconfirmed. The no-posterior gate remains in force. See `RESULTS.md`.
