# Reproducibility: the two genome-wide rechecks

The [input inventory](ldsc_inputs.tsv) lists the exact processed GWAS, LD-score reference and LDSC source files used for the same-data insomnia–ADHD and FI–FFS re-executions. On 28 October 2026, the [audit script](ldsc_audit.py) compared them with the checksums in the two original run receipts: **58 of 58 matched**, including four munged GWAS files, 44 reference files and ten code files ([check](ldsc_check.json)). Files remain on the external SSD; this manifest does not include their contents or make them portable.

The inventory contains full absolute paths and SHA-256 hashes. To recheck source bytes while the SSD is mounted, from the repository root run `python3 outputs/shared-genetics-atlas/data_manifest/ldsc_audit.py`; this updates only this inventory and check, not the original receipts or GWAS files. The scripts linked from each report show the exact LDSC arguments. **They use fixed output paths and would overwrite their existing logs and output files if run unchanged**; choose a new output prefix on a writable SSD workspace for a fresh run. Preserve the original receipts and results.

The archived Python executable was accessible and reported Python 3.9.23, NumPy 1.21.5, pandas 1.3.3 and SciPy 1.7.3, matching the reported runtime. Its path is `/Volumes/Extreme SSD/Utsav-Research-Archive/Sleep-GWAS/FAILED-PARTIAL-2026-09-01-sleep_gwas_atlas/.ldsc-env/bin/python3.9`; the executable SHA-256 at this check was `7dffb088cd3027e48f0127ced6f206e06111abed3b9457e580b6ebbf593c10ba`. This is **not a lock or complete hash of the environment**, native libraries, operating system, or all transitive dependencies. The runtime was inspected, not rebuilt. The shared reference's ancestry fit remains a scientific question, not something a file hash can establish.

The inputs are already processed summary statistics. Their original publication source, phenotype construction, ancestry, participant overlap and upstream processing are not fully authenticated by a byte match; the original Brain6 LDSC log remains unavailable. Numerical re-execution is not independent replication, a phenotype correlation, or repair of failed LAVA QC. The inventory covers these two rechecks only; other analyses have separate receipts, including the [selected atlas manifest](../manifest.tsv) and [bundle inventory](../BUNDLE_INTEGRITY.md). The item-excluded frailty GWAS and a validated full conjunction-FDR analysis remain outstanding.

A broader [curated external dependency inventory](EXTERNAL_DEPENDENCIES.md) also checks raw source copies, NHANES inputs, common-support data and selected molecular inputs; it is not an exhaustive inventory or a source-authenticity audit.
