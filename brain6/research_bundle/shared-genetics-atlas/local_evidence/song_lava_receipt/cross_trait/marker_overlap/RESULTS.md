# Locus 464 marker-intersection diagnostic

We compared the saved chromosome 3 FI, insomnia and sleep-apnea input files with the saved UKB reference `.info` file over the LAVA interval 47,588,462–50,387,742. Using unique rsIDs and unordered exact reference allele pairs, the reconstructed FI–insomnia intersection contains **2,741 markers**, and FI–sleep-apnea contains **2,452**. All 2,452 sleep-apnea markers are in the insomnia set; insomnia adds **289**. The reconstructed counts match the two archived receipts' reported local SNP counts. No allele-set mismatches or duplicate matched input rows occurred within this inspected interval.

These checks support a nested marker-coverage difference, not proof that the 289 markers caused the different frailty variance outcome. Equal counts do not independently verify LAVA's exact internal SNP order, binary-trait conversion, all preprocessing, or the historical identity of these files; current file hashes are saved, but the full historical input and LD checksums are not revalidated here. The 289 IDs are in [insomnia_only_ids.tsv](insomnia_only_ids.tsv); [audit code](audit.py) and [receipt](receipt.json) record the calculation. This comparison did not run or modify LAVA.

The locally saved source snapshot for the [pinned LAVA implementation](../../../../PUBLICATION.md#external-dependencies) (external target: `../../../../../../work/sleep-gwas-atlas/brain6/results/lava_confirmatory_protocol_v1/source_docs/LAVA_input_processing_e729a245.R`) computes projected association statistics from the LD decomposition, estimates residual sampling variance, then subtracts that sampling term to form a local genetic covariance estimate. It drops a phenotype when a diagonal sampling or genetic variance is negative. Such a negative estimate can arise from sampling variability when local signal is weak, but the warning and this comparison do not identify the cause in this dataset or rule out input/reference problems. The archived runner requested `drop.failed=TRUE` and capped reported heritability estimates; capping did not prevent the separate negative variance check from dropping FI. These code semantics follow the saved snapshot and runner, not an independent replay of the installed historical runtime.

The two runs used different sleep inputs, binary-trait information and fitted LD representations. No local genetic correlation is recovered, no correction is established, and all 12 original family gates remain failed. The next defensible diagnostic would use a separately versioned, validated runtime to replay both runs, retain failed quantities for inspection, and compare exact reconstructed marker sets, projected statistics and reference-LD sensitivity; such a diagnostic would not itself authorize discovery claims.

A [subsequent retained-failure replay](replay/RESULTS.md) reproduced the archived counts and quantified the negative FI genetic-variance diagonal in the insomnia run. It confirms the nested internal marker sets but does not identify the cause or validate the family.
