# Whole-locus 1000 Genomes LD sensitivity

Before inspecting results, use the existing 2,741-marker FI–insomnia locus 464 replay and the LAVA-processed FI statistics aligned to the UKB reference's A1 allele. Stream the UCSC 1000 Genomes Phase 3 GRCh37 VCF over the locus; use the 503 European-labeled individuals from the public panel, exact rsID/coordinate/allele-pair matches, and A1 diploid dosages. Exclude ambiguous duplicates, nonmatching or polymorphism-deficient markers; for any missing dosage use the variant's sample mean. Construct the standardized genotype matrix and its in-memory LD, then apply the LAVA 99%-variance component rule and FI univariate arithmetic. Save only aggregate SNP metadata, projection summaries and numerical results, not person-level genotypes.

Verify the transformed input sum against the saved original UKB replay where possible and compare support counts and estimates. These two references differ in size, ancestry composition, marker coverage, imputation and estimation, and the 503-person panel has rank at most 502; it is not an ancestry- or study-matched replacement for the original ~100,000-person UKB reference. The test is post-selected and univariate only; do not choose a preferred result by sign, report a local correlation, or promote a discovery. A differing result cannot isolate the effect of LD from support differences unless support is also matched. The frozen family QC gates remain failed.
