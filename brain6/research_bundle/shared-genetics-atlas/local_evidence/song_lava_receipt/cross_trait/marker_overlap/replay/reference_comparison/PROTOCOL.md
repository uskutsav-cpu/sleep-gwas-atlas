# Small independent-reference LD comparison

Written before inspecting the comparison. Select 60 markers at evenly spaced indices through the existing replay's ordered 2,741-marker FI–insomnia support. Retain their GRCh37 positions and A1/A2 from the saved LAVA reference information. Extract their pairwise signed LD using the same UKB LAVA reference and its reader. Independently query the UCSC-hosted 1000 Genomes Phase 3 GRCh37 VCF at these exact positions, requiring rsID and unordered allele agreement, and calculate A1 dosage correlations among the 503 European-labeled reference participants; exclude missing calls per pair. Report marker availability, allele-frequency differences and pairwise correlation/r² differences by distance, with all exclusions. Save only aggregate pairwise correlations, not participant-level genotypes.

This is a selected, small-reference panel comparison, not a LAVA rerun or a validation of either panel. Markers and LD pairs are correlated, selection covers one post-selected locus, and panels differ in sample size, ancestry composition, genotyping and estimation. Frequency and signed-LD conventions must agree before interpretation. Large differences can indicate reference sensitivity or harmonization problems but cannot identify the correct reference or explain a negative genetic variance. Do not use the result to rescue the frozen QC gates or claim local correlation.
