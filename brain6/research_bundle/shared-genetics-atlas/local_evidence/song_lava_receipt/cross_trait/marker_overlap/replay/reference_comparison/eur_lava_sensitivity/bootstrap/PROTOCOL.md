# Reference-sample resampling diagnostic

Written before execution. Reconstruct the same 503-person 1000 Genomes dosage matrix and 2,738-marker source support as the preceding analysis, and verify the baseline FI variance against its saved result. Draw 30 bootstrap samples of 503 people, sampling people with replacement using NumPy `default_rng(46420261028)`. Recenter and rescale each marker in every resample; if a marker is invariant, exclude it from that resample and record the resulting support. Recompute the 99%-variance SVD and FI univariate quantities with the same aligned GWAS statistics and LAVA formula. Save only per-replicate numerical outputs and no genotypes or sampled individual identifiers.

The replicates are not independent cohorts. The small, related reference panel, fixed GWAS and post-selected locus, Monte Carlo uncertainty, ancestry/reference mismatch, possible invariant-marker exclusions and SVD regularization prevent interpreting the empirical range as a confidence interval for the correct study-specific value or as calibrated genetic evidence. All results, including failed or negative estimates, must be retained. No bivariate local inference or change to the original QC gates is permitted.
