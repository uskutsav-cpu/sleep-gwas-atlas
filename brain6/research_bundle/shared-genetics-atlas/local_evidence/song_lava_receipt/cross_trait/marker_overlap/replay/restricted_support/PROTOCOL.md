# Diagnostic protocol: hold FI and insomnia inputs fixed, restrict marker support

Written before the restricted replay. Read the previously retained internal SNP list from the sleep-apnea–FI replay. Reconstruct the original insomnia–FI input object using the same pinned R/LAVA installation, saved insomnia input descriptor, reference, overlap matrix, locus boundaries, seed and processing options. Restrict `input$analysis.snps` to the 2,452 sleep-apnea replay SNP IDs, and rerun locus 464 with `drop.failed=FALSE`. No summary-statistic values are replaced and no bivariate test is run.

Check exact SNP-set membership and the resulting component count, FI genetic variance and FI local heritability against both earlier replays. If the FI calculation matches sleep apnea after restriction, this supports the marker support and induced LD decomposition as sufficient to reproduce that particular difference under these software inputs; it does not establish why the wider-set estimate is negative or which marker(s) are responsible. If it does not match, investigate remaining differences. This is a post-selected single-locus diagnostic, not a prespecified scientific test, independent replication, local correlation, corrected analysis family or QC-gate rescue. The original insomnia support remains the authorized run and its failure status cannot be overwritten.
