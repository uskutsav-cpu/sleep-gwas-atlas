# Post-selected random-support stability diagnostic

Written before generating random subsets. The wide FI–insomnia LAVA locus 464 replay contained 2,741 internal markers. Generate 20 reproducible random subsets of 2,452 distinct markers from that fixed set, uniformly without replacement within each subset, using sorted rsIDs and Python's `random.Random(4642026)`; different replicates may overlap. This matches the size of the previously investigated sleep-apnea support but does not match its missingness mechanism, ancestry, allele frequency or LD structure.

For each subset, hold fixed the saved FI–insomnia inputs, sample-overlap matrix, locus, reference, software settings and seed from the earlier insomnia replay; set `drop.failed=FALSE` and recalculate the local FI variance and retained components. Report all results, the number of negative variances and their range; compare the actual post-selected sleep-apnea support's result descriptively. Verify every subset's size and inclusion in the original marker set. Do not run bivariate tests or claim that empirical ranks are calibrated p-values; 20 replicates are too few to quantify rare behavior precisely and different subsets are not independent datasets. This is a numerical robustness diagnostic for one post-selected locus, not a valid marker-selection strategy, proof of a true biological effect, or a rescue of the original failed family gate.
