# Published local signal: partition and failed-gate audit

The 3p21.31 interval reported by [Song et al.](https://www.frontiersin.org/journals/aging-neuroscience/articles/10.3389/fnagi.2024.1358996/full), chromosome 3:47,727,212–49,316,972, is an exact coordinate match to one block in the [European LD partition recommended in the ρ-HESS input documentation](https://huwenboshi.github.io/hess/input_format/). The pinned reference file contains **1,703** blocks. An exact numeric match is useful for locating the published result, but does not prove which partition version, genome build, tested blocks, or overlap settings the paper actually used.

The paper's supplementary row reports p=9.45×10⁻⁶ and states that Bonferroni correction was applied by number of regions. **Illustration only:** if all 1,703 blocks formed its exact testing family, 0.05/1,703=2.936×10⁻⁵ and p×1,703=0.0161. We could not verify that denominator from the paper's output; 0.0161 is not a recovered author-adjusted value or an independent rerun. This arithmetic does not resolve whether the underlying test is calibrated for the study's sample overlap or LD reference.

The printed `local_rhog` value is 0.00028557 (SE 0.0000645). The ρ-HESS [output documentation](https://huwenboshi.github.io/hess/local_rhog/) describes its `local_rhog` column as local genetic covariance. Song calls it local genetic correlation, but the article's normalization and local heritability inputs were not recovered. Treat the number as the reported statistic; do not compare it directly with dimensionless LDSC r_g. ρ-HESS documents an overlap correction requiring shared sample count and phenotypic correlation (or a model-derived estimate); the paper passage inspected does not establish its actual settings. A recent [same-data insomnia–FI LDSC check](../../global_audit/brain6_frailty_covariance/RESULTS.md) has a positive covariance intercept, reinforcing the need to investigate overlap rather than assuming independent statistics. The specific LDSC estimate is not a substitute for the published run's inputs or a validated local correction.

## What the saved LAVA gate says

The archived frailty LAVA gate ledger records **2,495 insomnia slots**, **1,437 flagged** (57.6%) and **351 process failures** (14.1%), including 329 negative-variance failures, 21 no-reference-SNP failures and one other failure. The flags also include 1,087 FI-not-tested and 701 insomnia-not-tested entries; these categories can overlap and must not be added. A phenotype not tested is not evidence of a null local effect. The aggregate frozen gate for insomnia failed, as did all 12 sleep-trait gates. Across the saved ledger are 29,940 slots, 5,125 negative-variance failures, 252 no-reference failures and seven other failures. This checks the saved aggregate ledger, not each original receipt or the status of a specific region.

The published ρ-HESS row and LAVA gate concern related data but different methods and partitions. The first is a previously published result using a shared FI source; it is neither independent replication nor a correction of the failed project gate. A [subsequent receipt-level coordinate lookup](../song_lava_receipt/RESULTS.md) finds one containing LAVA interval where frailty was dropped after a negative variance estimate and the bivariate test was not eligible. The build correspondence and equivalence of the tests remain unverified. A new local analysis still requires documented signed inputs, ancestry-matched LD, overlap handling, numerical quality controls and calibration; it must preserve the failed LAVA result.
