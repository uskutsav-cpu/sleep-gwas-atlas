# Exploratory conjunction screen: protocol

Written before examining the full screen on 27 October 2026. Use the exact 1,138,262-variant, three-trait common HapMap3 inputs already used for the PLACO+ diagnostic; exclude no SNPs from the correction family. Test FinnGen R13 insomnia jointly with FI and with FFS, a total of 2,276,524 trait-pair/SNP hypotheses. At each SNP, use the intersection–union p-value max(p_insomnia, p_frailty). Bonferroni threshold is 0.05/2,276,524. This is a conjunction test, not conjunction FDR or PLACO. The maximum of valid marginal p-values is a conservative test of the null that at least one trait is unassociated, regardless of cross-trait dependence; familywise correction does not assume SNP independence. It does not test a shared causal variant or direction.

Input Z-scores are stored to three decimal places. Use a conservative rounding adjustment: for each stored Z, calculate p=erfc(max(abs(Z)-0.0005,0)/sqrt(2)); this bounds the tail p under standard rounding, conditional on normal-derived Z and the other source assumptions. Require complete ordered SNP and allele matching, finite Z, uniqueness, and all support rows. Save selected SNPs with aligned alleles, both Z and both marginal p bounds. Outputs are post-hoc exploratory checks from the HapMap3 subset, not dense genome-wide discovery, because the source statistics, source-specific model calibration, ancestry, overlap and other phenotyping issues still matter. Record all threshold crossings as variants, not independent loci; do not label gene targets or claim independent replication. Compare against PLACO when the latter completes.
