# FinnGen insomnia–hospital-frailty conjunction screen

This post-hoc analysis compares registry-defined insomnia from FinnGen R13 with the hospital frailty risk score (HFRS) from FinnGen R12. The two releases have overlapping participants; this is not independent two-cohort replication. We used the existing filtered HapMap3 files and a separate conservative single-pair family, as specified in the [protocol](PROTOCOL.md).

Of 1,158,908 insomnia input rows, 1,158,555 had a unique, chromosome- and allele-compatible HFRS match with usable displayed p-values and betas. Another 353 insomnia SNPs had no HFRS match. All 1,158,908 insomnia rows remain in the correction denominator. There were **zero Bonferroni threshold crossings** at 0.05/1,158,908 = 4.31×10⁻⁸, and zero BH or BY rejections at 0.05 when missing slots were padded as p=1. The smallest max-p was 8.23×10⁻⁶ for rs10894424 (insomnia p=2.92×10⁻⁶; HFRS p=8.23×10⁻⁶); its Bonferroni-adjusted p is 1. The smallest BH-adjusted p was about 0.998 and BY-adjusted p was 1. A separately implemented source-file cross-check reproduced the eligible count, minimum and no-rejection outcome; its output is `independent_check.json`.

The p-value max(p_insomnia,p_HFRS) is an intersection–union test of association with both traits if each marginal p-value is valid, without requiring independent cohorts or variants. It is conservative and does not test whether the same causal variant affects both traits. Consequently, no corrected hit does not imply no shared architecture, and a top-ranked SNP is not an independently established locus. These results cannot be called PLACO+ or enrichment-based conjFDR. Source p-values have limited displayed precision and upstream model calibration was not rerun. Both phenotypes are registry-derived, HFRS is a different construct from FI or FFS, and no result here removes sleep or fatigue items from frailty.

`summary.json` records hashes and counts; `top100.tsv` retains both source alleles, estimates and p-values; `hits.tsv` is header-only. `screen.py` and `independent_check.py` reproduce the computations from the specified external source files. This pair was selected after earlier analyses; results should not be combined with the frozen FI/FFS two-pair family without specifying a new correction family.
