# Exploratory FinnGen insomnia–HFRS conjunction: protocol

Written before inspecting this screen's results, 27 October 2026. Use existing filtered `R13_INSOMNIA_HM3.tsv` and `HFRS_HM3.tsv`: FinnGen R13 registry insomnia and FinnGen R12 hospital-frailty-risk score, respectively. This is a distinct, post-hoc single-pair family, not an expansion or retroactive redefinition of the separate FI/FFS PLACO family. FinnGen releases have overlapping participants; exact intersection is unknown, and this is not independent two-cohort replication. HFRS and insomnia have different ascertainment and phenotype meanings. Both were assembled by the prior project; this screen does not revalidate their upstream filtering, model calibration or assembly.

Define the conservative family size as every insomnia source row, including duplicates, missing matches, invalid p-values and exclusions. For each unique insomnia rsID with exactly one HFRS row, matching chromosome and exact unordered A/C/G/T single-nucleotide allele pair, and finite source-reported p-values in (0,1], test max(p_insomnia,p_HFRS). Missing, duplicated, conflicting, non-SNP or invalid rows remain untested and count against the fixed denominator. Neither source-allele string nor matching rsID alone independently validates genomic representation or strand. Report both source alleles and effects, and align the HFRS sign only for exact direct or reversed source alleles. Bonferroni uses all insomnia rows; BH and dependence-robust BY use the same denominator by treating untested slots as p=1. BH dependence assumptions are not checked. Preserve the smallest 100 max-p rows and all nominal threshold crossings, plus aggregate exclusion counts and SHA-256 of both inputs.

Intersection–union max-p is valid under any cross-trait dependence if both marginal p-values are valid, including overlapping samples. It is not PLACO, enrichment-based conjunctional FDR, LD-aware colocalization or evidence of the same causal allele. Source p-values have finite displayed precision and no formal rounding bound is asserted. The sources and this selected pair were chosen after reviewing project data, so all results are exploratory. Do not report SNP hits as independent loci without LD and ancestry checks, or interpret a nonsignificant result as absence of shared architecture. No participant-level measurements are accessed.
