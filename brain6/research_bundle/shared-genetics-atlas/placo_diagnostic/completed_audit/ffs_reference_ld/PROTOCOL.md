# FFS post-selection LD diagnostic protocol

For the 66 FFS PLACO numerical threshold crossings, query the 1000 Genomes Phase 3 GRCh37 phased EUR panel and require exact rsID, position, and both alleles. Compute pairwise phased-haplotype Pearson r and r² between available, eligible alleles, excluding missing, unphased and third-allele genotypes pairwise. Within each of the five chromosome groups, describe LD to the smallest-PLACO-p selected marker and construct a graph connecting selected markers with r² ≥ 0.8; graph connected components are descriptive, not independent locus estimates, because LD is not transitive. Compare the selected chr22 FFS markers with three selected FI diagnostic markers on chr22. Record missing reference records, eligible sample sizes, allele choices, source URL and SHA-256 hashes for the selection and sample panel. The 503 mixed EUR samples are not a Finnish- or UKB-specific LD model. The post-selected markers and reference LD do not validate PLACO calibration, prove shared causality, or constitute replication. No formal LD clumping, conditional analysis or fine-mapping is claimed.
