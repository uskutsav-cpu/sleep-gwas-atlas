# Exploratory PLACO+ screen on aligned HapMap3 support

Written before the full scan on 27 October 2026, after examining prior project results and the small deterministic control sample. This is a post-hoc research analysis, not preregistered confirmation. Two pairs: FinnGen R13 registry insomnia vs the existing Atkins FI and vs the existing Ye FFS. Source files are the project's allele-aligned three-trait common LDSC support, 1,138,262 autosomal HapMap3 SNPs; their SHA-256 hashes and source details are in `diagnostic_parameters.json`. These are not dense complete GWAS statistics, and the printed LDSC Z-scores are rounded to three decimals. The two frailty GWAS share UKB, exact overlap unknown. FinnGen and UKB/TwinGene are distinct named cohorts; exact intersections and relatedness are not proven. No HFRS pair is part of this frozen two-pair screen. This analysis cannot resolve item overlap or establish causal variants.

Use the pinned upstream PLACO+ v0.2.0 (source SHA-256 `fb684a8ed88f27dd138f5c2e8613b092904e84f364030d036058f17db95b7124`) and `placo.plus`; estimate VarZ from SNPs excluding those with both derived two-sided p<1e-4, and CorZ from SNPs with both p>=1e-4, separately per pair, after excluding either squared Z>80. Use exact official numerical integration `AbsTol=1e-13`, preserving invalid outputs as failures. For the exact zero-product boundary return p=1, as in the Brain6 wrapper. Derived p-values from rounded Z are approximate. Record every support SNP and failure; no failed or excluded row becomes a success. Before interpreting any results, check input equality, uniqueness, output coverage and failure rate, reproduce deterministic control values and examine numerical precision and source/ancestry limitations. A result passing the arithmetic threshold remains exploratory pending calibration and source review.

Family for descriptive thresholding is two pairs × 1,138,262 support rows; Bonferroni 0.05/2,276,524 = approximately 2.196×10⁻⁸, with every input slot retained including failures and excluded extremes. This controls the defined family only if all marginal and PLACO+ p-values are valid; it does not imply genome-wide discovery across SNPs absent from the support, nor create an independent replication. Assign no shared direction unless both aligned signed estimates are separately checked. Use appropriate independent ancestry-matched LD to clump before presenting any independent-locus count; positional annotations alone cannot resolve LD. Individual hits still require dense original unrounded statistics, ancestry sensitivity, colocalization and both-trait independent replication. The deterministic SNP-hash sample tests runtime and integration behavior, not empirical type-I calibration because randomly sampled genome-wide SNPs can include true effects, LD and non-null background.

Method: [official PLACO documentation](https://github.com/RayDebashree/PLACO/blob/master/README.md) and [Park and Ray 2025](https://doi.org/10.1016/j.xhgg.2025.100501).

**Post-launch control update:** fixed-mean one-trait-only stress simulations had elevated rejection at p<0.05. See `NULL_SIMULATION_REVIEW.md` for context and model-aligned controls. The scanned values remain diagnostic; no p-value threshold is promoted as validated. The update does not change the fixed screening calculation.

**Source-statistic update:** the deterministic sample demonstrates that the stored Z corresponds to the source-reported p-value but often differs from beta/SE for FI and especially FFS. See `PRECISION_AUDIT.md`. The run remains exploratory and must be compared with source-justified full-precision statistics before interpretation.
