# PLACO+ setup and deterministic control diagnostic

The two-pair screen is defined in `PROTOCOL.md`. A deterministic rsID-hash sample selected 2,191 variants without using either trait's statistics, from 1,138,262 allele-aligned autosomal HapMap3 markers. Official PLACO+ v0.2.0 produced valid finite values at every sampled row for both comparisons. The sample gave 130 p-values below 0.05 for insomnia–FI and 108 for insomnia–FFS. These proportions are descriptive: a random genomic sample includes non-null associations, linked markers and confounding, so they are not a type-I-error calibration or proof that the method is valid for these inputs. Parameter-estimation formulas were checked against the official implementation on the control subset. Full-support nuisance estimates were calculated from all three-trait aligned rows, not just the sampled controls, and saved in `diagnostic_parameters.json`.

The source Z scores are rounded to three decimals. In the full support, 793 FI-pair rows and 5,286 FFS-pair rows have at least one printed zero, for which the wrapper returns p=1; a rounded zero is not evidence of a true exact zero. No rows exceed squared-Z 80 in these support files. The precision issue, missing dense SNPs, phenotype differences and unknown overlap remain material. Full results cannot be promoted as discoveries until all output rows, integration failures, source accuracy, overlap and calibration are reviewed. The control rows and code are provided to make the computation inspectable.
