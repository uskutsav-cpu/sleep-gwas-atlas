# Chr7 FI diagnostic and FI–insomnia coloc reference-LD check

Post-hoc comparison prepared after observing both analyses. Take the top five chr7 FI–FinnGen-insomnia single-signal conditional H4 markers from `frailty_coloc/conditional_variant_posteriors.tsv`, plus FI PLACO+ diagnostic lead rs2396766 and the previously published Song candidate rs12671330. Query unique exact rsID, GRCh37 position and allele contrasts in the phased 1000 Genomes Phase 3 European reference. Calculate pairwise LD between each diagnostic anchor and each of the five conditional H4 markers, preserving reference failures; use 1,000 individual bootstrap replicates and do not retain individual genotypes. The two anchors and the coloc model are post-selected, use the same FI and registry-insomnia sources and are not independent replication. Conditional H4 ranks apply only if the single-signal shared hypothesis is true; PP4 varies substantially with the prior, and the PLACO+ thresholds have unresolved calibration. LD in 503 broadly EUR reference individuals cannot prove the same causal variant, eliminate other signals, establish a causal gene, or guarantee LD in either cohort. Neither local QC gate is repaired.
