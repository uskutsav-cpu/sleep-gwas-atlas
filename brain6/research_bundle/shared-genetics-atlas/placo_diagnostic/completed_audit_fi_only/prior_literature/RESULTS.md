# Published-context crosswalk for FI diagnostic markers

Of the 16 FI–registry-insomnia PLACO+ diagnostic threshold crossings, **rs12671330** is an exact rsID match to a candidate in the previously published Song et al. insomnia–FI study's 124-variant table. The existing project crosswalk records it as rank 33 at chr7:114334043, assuming the Song table uses GRCh37; the current FI source independently supplies the same position and C/T allele pair. This is prior published shared-genetics context, not a new locus discovery. Song used a related UKB insomnia source and the same Atkins FI GWAS, so the current analysis is not independent two-trait replication. The Song table's build remains unverified, and matching rsID/position/alleles does not resolve causal identity.

The same marker belongs to Brain6's selected insomnia credible-set union with single-signal conditional insomnia PIP 0.0488 and ADHD PIP 0.00000183. Those conditional probabilities arise from a different trait pair and model; the much smaller ADHD PIP does not prove absence of ADHD association or establish one three-trait causal signal. The AlphaGenome pilot's selected adult DNase summary is +0.0122 (501 bp, ALT C versus REF T); it is a prediction and not evidence of target gene or disease mediation. In the [chr7 reference check](../chr7_ld/RESULTS.md), rs12671330 C and the strongest chr7 FI-diagnostic marker rs2396766 A have r²≈1.0 among 503 EUR individuals, but reference LD alone does not establish a shared causal effect.

The existing MVP-insomnia/HFRS follow-up for rs12671330 has max marginal p=0.00718 and 124-candidate Bonferroni numerical value 0.890; it does not provide a corrected cross-trait replication. It uses different phenotype definitions and retains the original selection, build and cohort-overlap caveats in the [full published-candidate audit](../../../evidence/song124_mvp_hfrs_followup.md). The other 15 diagnostic rsIDs do not exactly match this specific 124-marker table; that narrow absence is **not** proof that they are novel or absent from other studies. Distances to the nearest listed marker assume Song's build and are not LD evidence.

`song_crosswalk.tsv` includes all 16 markers and the nearest same-chromosome published candidate, and `receipt.json` records source hashes; `crosswalk.py` reproduces the comparison. No new literature-wide novelty claim is made.

A subsequent [exact-variant GTEx lookup](../rs12671330_gtex/RESULTS.md) found no returned significant single-tissue eQTL or sQTL records and no nominally significant FOXP2 dynamic test in cortex, frontal cortex or adrenal tissue. These are limited tests, not evidence of no molecular effect.

The diagnostic chr7 lead **rs2396766** was itself a prior Atkins FI lead. The [source audit](ATKINS_RS2396766.md) documents the published opposite cohort directions and an unresolved discrepancy between the article narrative and its rounded heterogeneity p-value.
