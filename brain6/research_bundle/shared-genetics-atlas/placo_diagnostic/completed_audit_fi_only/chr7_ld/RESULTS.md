# Reference LD for chromosome 7 diagnostic markers

The seven FI–insomnia PLACO+ threshold-crossing markers on chr7 were compared with the lowest-p of those seven, rs2396766, and with the previously studied Brain6 marker rs1476535 and sleep–frailty marker rs12536335. All nine variants matched a unique 1000 Genomes Phase 3 GRCh37 reference record, and all 20 requested pairs had usable phased genotypes in 503 EUR-labeled individuals. This is a post-hoc reference analysis, specified in [PROTOCOL.md](PROTOCOL.md).

Relative to rs2396766, five of the six other diagnostic markers have r²≈1.000 in this panel and one has r²≈0.914. Thus their seven marker-level threshold crossings should not be presented as seven independent loci. Against rs1476535, their r² values range from 0.085 to 0.110; against rs12536335, they range from 0.081 to 0.106. For example, rs2396766 A versus rs1476535 C has r²=0.110 (individual-bootstrap interval 0.075–0.147) and r=−0.331; rs2396766 A versus rs12536335 G has r²=0.106 (interval 0.073–0.143) and r=−0.325. The counted alleles matter for r's sign; r² does not indicate effect direction.

This reference result shows limited tagging between the selected diagnostic cluster and the two selected anchors despite their location within the same broad region. It does **not** prove independent causal signals, exclude linkage with other unexamined variants, establish shared causality, identify FOXP2 as an effector, or validate PLACO+ calibration. The 503-person reference includes FIN individuals, but it is not LD measured in the Finnish R13 or UKB/TwinGene GWAS participants; bootstrap intervals represent reference-panel resampling and do not account for source or model differences. The two anchors are highly correlated with each other in the [earlier reference check](../../../cross_project_ld/CROSS_PROJECT_LD.md), not independent replications.

`pairs.tsv` retains all alleles and pairwise estimates, `receipt.json` provides reference metadata, source hashes and matching status, and `calculate.py` reproduces the calculation. The diagnostic associations and unresolved calibration are documented in [the FI results](../RESULTS.md).
