# rs12671330 GTEx v8 follow-up

After the FI–insomnia diagnostic and its prior-study and LD crosswalk, query GTEx v8 using the exact previously reference-verified GRCh38 variant `chr7_114693988_T_C_b38` for significant single-tissue eQTL and sQTL records across tissues. Separately request dynamic FOXP2 eQTL tests for cortex, frontal cortex BA9, and adrenal gland using versioned GTEx gene ID ENSG00000128573.24. Dynamic queries are post-hoc nominal tests and are not restricted to GTEx-significant pairs. Preserve static API responses, query URLs, response hashes, tissue, gene and returned summary statistics; do not save per-participant arrays from dynamic responses. A successful empty significant-pair query is not evidence of no molecular effect, and API errors remain explicit. GTEx NES is a normalized-expression slope for ALT relative to REF, not fold change. Significant pair status is not a multiple-test correction for this project's selection, and the handful of dynamic queries does not constitute a prespecified family.

The FI diagnostic is affected by calibration, original FI sleep items, cohort overlap, and LD; an exact-variant QTL is not a GWAS–QTL colocalization and cannot assign a causal gene or cell. Associations in non-brain tissues do not establish brain effects. This lookup is an observational molecular association, not independent two-trait replication or a new AlphaGenome prediction.
