# PLACO+ model-consistent null tail calculation

Before inspecting the new results, use the FI and FFS fixed nuisance estimates and the scan's two-pair threshold already used in the parent tail check. Under the [PLACO+ model](https://pmc.ncbi.nlm.nih.gov/articles/PMC12547305/), calculate three zero-mean bivariate-normal sub-null distributions: H00 variances (1,1), H01 (1,VarZ₂), and H02 (VarZ₁,1), each with the fitted correlation parameter. Compare the rejection probabilities for the official two-sided product threshold both with and without the scan's |Z|≤√80 cap. Use deterministic one-dimensional Gaussian conditional quadrature with conditioning on each coordinate independently. Verify that the uncapped sub-null integrals reconstruct the official package's p₁+p₂−p₀ formula at the same product threshold. Check both 0.05 and the genome-wide screening alpha.

This check isolates numerical behavior under a stipulated idealized random-effect distribution with fixed nuisance parameters. It is not validation that actual single-trait effects, sampling correlation, Z-score variance, LD, cohort overlap or estimated parameters follow that model. The prior fixed-mean composite-null stress test addresses a different setting. Neither result is an empirical FDR estimate or establishes validity of real-data crossings. No SNP results are reclassified and the original local-QC gate is unchanged.
