# Composite-null cap-bound diagnostic

Written before evaluating the 82 stored crossings. Derive a bound for the product statistic using only the scan's |Z|≤sqrt(80) cap and a valid standard-normal marginal null Z: for T=|Z1 Z2|, if either phenotype is null then the event {both |Z|≤cap and T≥t} implies {|Z_null|≥t/cap}. Thus p_cap=2Φ(−T/cap) is a conservative unconditional event bound, independent of the other trait and error dependence, provided the null marginal is standard normal and the cap is applied as part of the event. Candidates are selected post hoc; calculate this bound and marginal max-p from the saved original-source p-derived Zs for all 82 and compare to 0.05/(2×1,138,262). Check the algebraic domination p_cap≥max(p1,p2) for every candidate with both Zs within cap. This is an exploratory mathematical benchmark, not PLACO+, a new discovery method, or a correction for invalid/misspecified marginal statistics. Whole-genome calibration is not inferred from selected rows.
