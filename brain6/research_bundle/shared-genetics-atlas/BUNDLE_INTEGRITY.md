# Delivery bundle verification

`bundle_manifest.tsv` records relative path, size and SHA-256 for all regular files under `shared-genetics-atlas/` and `brain6-alphagenome-pilot/` at the time it was generated. It excludes itself, Python bytecode caches, and the PLACO diagnostic's actively changing `.log` and `.partial.` files. Other manifests document original-source provenance and input checksums; this snapshot verifies delivery integrity only and does not prove source authenticity or scientific validity. Original large summary statistics and reference panels remain on the external volume specified in individual protocols and are not part of the bundle. The user-authorized JBrowse outputs are governed by the service's terms and the AVI mirror remains a third-party source with documented limitations.

From the parent `outputs` directory or any working directory, run `python3 shared-genetics-atlas/bundle_integrity.py` using the appropriate path to that script. It reports missing, changed or newly added non-transient files and returns nonzero if any are found. When the legitimate report or scan output changes, regenerate the snapshot with `python3 shared-genetics-atlas/bundle_integrity.py --write` and then verify again. Snapshot generation is not an independent external timestamp or signature. Keep the saved bundle and its cited source files together.
