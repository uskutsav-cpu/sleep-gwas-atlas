# Exploratory FI–FinnGen insomnia colocalization

These post-selected analyses do **not** establish a shared causal variant, validate a Brain6 insomnia–ADHD locus, or repair the failed local-correlation quality-control gates. FI and insomnia samples may overlap; the FI phenotype includes sleep-related items. The two source populations differ and each region may contain multiple signals. Single-signal ABF calculations cannot distinguish multiple independent signals, and no LD-aware fine mapping was performed here.

The fixed 1-Mb GRCh37 windows, selected by previous work around rs817509 (chr3) and rs12536335 (chr7), include 2,385/2,531 (94.2%) and 1,212/1,330 (91.1%) eligible FI variants matched to insomnia, respectively. Those denominators are source FI variants passing the stated filters, not all variants in the region; missing imputed variants remain a concern. Liftover correctly maps rs62264764 and rs1476535 to their expected GRCh37 positions. Full matching counts and aligned effects are in `matching_counts.json` and `matched.tsv`. FI beta and SE values are rounded; their recomputed normal-approximation p-values differ from supplied p-values by as much as 0.078 and 0.162 log10 units in these windows, respectively.

Default means p1=p2=10⁻⁴, p12=10⁻⁵, FI effect prior SD 0.15 and insomnia log-odds effect prior SD 0.2. H0 means neither trait has an association under the model; H3 means distinct associated variants; H4 means one shared associated variant. On chr3, H0 dominates and these data are uninformative about sharing; low H4 is not evidence that sharing is impossible. On chr7, support for H4 is moderate at the default prior and sensitive to the prior: with p12=10⁻⁶, H3=0.5833, H4=0.1246. The FI and insomnia minimum p-values in the matched 1-Mb window are 1.22×10⁻⁹ and 2.33×10⁻⁶, respectively. A 500-kb window centered on the marker yields H4=0.7579 or 0.2385 for the same two priors, respectively; these post hoc window comparisons are sensitivity checks, not independent tests. The 200-kb windows fell below the 500-variant gate and were not evaluated.

Within chr7, **conditional on H4 being true**, the highest SNP probabilities are rs10953765 (0.2154; chr7:114291435 GRCh37) and rs1456031 (0.2151; chr7:114296102); the conditional 95% set has 25 variants. Both are over 220 kb from rs12536335. The prior Brain6 marker rs1476535 has conditional probability 0.000000607 in this model. This difference does not disprove its involvement because the window can contain multiple signals and the posterior depends on the model and SNP coverage. Chr3's conditional 95% set contains 744 variants and is not interpretable as compelling sharing when H4 itself is so low. Variant posterior tables must be interpreted conditional on H4, not as standalone causality probabilities.

Methods and reproducibility: `PROTOCOL.md` defines selection and QC. `extract.py`, `match.py`, `run.R`, and `window_sensitivity.R` record the processing. `run.R` calls the `approx.bf.estimates` and `combine.abf` functions directly from [coloc 5.2.3's original implementation](https://github.com/chr1swallace/coloc/blob/v5.2.3/R/claudia.R), whose local source SHA-256 is `cf6af3620cef7d2599757a2b04f7677ca8a4a5211de9367cab8e9961db72c0ee`; those functions are used for default estimates and hypothesis combination, with a simple explicit effect-prior modification for the nondefault priors. The file is included under coloc's GPL license. Source file paths and extraction hashes appear in the extraction JSON files. Re-run from the workspace root with the same external volumes and hg38-to-hg19 chain. The hg38-to-hg19 chain SHA-256 is `14a712e8e147d9fc8e9d87d51977b46f6f8ddb93efbe5d0843d86b6205f587b1`; it is an analysis dependency; outputs do not include individual-level data.

Input provenance and the distinction between the current FI file and the unavailable frozen-atlas FI bytes are documented in [Regional input provenance](../source_provenance/README.md).

A subsequent [European-reference LD comparison](../cross_project_ld/CROSS_PROJECT_LD.md#chromosome-7-conditional-coloc-leaders-versus-brain6-anchors) found that the two chr7 conditional-H4 leaders are strongly linked to each other (r²=0.964) but only modestly linked to the previously highlighted Brain6 and frailty anchors (r²≈0.13–0.14). This is a prioritization clue, not a conditional test or proof of multiple causal signals; source–reference allele-frequency differences and the existing prior, ancestry and single-signal caveats remain.

A [reference subgroup sensitivity](../cross_project_ld/CROSS_PROJECT_LD.md#reference-population-sensitivity-for-the-chr7-signals) found the leaders’ frequencies closer to FinnGen in 1000 Genomes FIN and closer to FI in GBR than in pooled EUR. Small subgroup size and differences between the reference and actual cohorts prevent treating this as a study-matched LD validation.

A post-selected [common-support comparison](adhd_same_support/RESULTS.md) also pairs FI with ADHD and the two insomnia sources on 1,496 chr3 variants. It is uninformative about FI–ADHD sharing because the ADHD-only hypothesis dominates, and it is not a three-trait colocalization or independent replication.

A [chromosome 7 FI–insomnia–ADHD common-support pilot](chr7_three_trait/RESULTS.md) returned an FI–insomnia cluster under default settings and no three-trait cluster. Its model assumes independent statistics despite possible overlap, and FI includes a sleep item.
