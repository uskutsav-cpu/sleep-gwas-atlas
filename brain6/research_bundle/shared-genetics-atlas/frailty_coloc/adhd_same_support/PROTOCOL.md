# Chromosome 3 FI–ADHD comparison on common support

This exploratory cross-project comparison was selected after examining the LSAMP-region results; it is not an independent replication or a test of three-trait colocalization. Intersect the previously aligned FI–FinnGen insomnia dataset with the ADHD and original insomnia SuSiE pilot support using unique chromosome 3 GRCh37 coordinates, rsID and identical non-palindromic allele pair. Require finite effects and positive standard errors. Align pilot effects to the FI effect allele. Do not adjust effects by AlphaGenome scores. The intersection inherits the GTEx/1000 Genomes filters used to define the pilot and is not an unbiased or comprehensive set of regional GWAS variants. Output only aggregate results and code, not ADHD variant-level source records.

Compare FI with ADHD and, as a support control, FI with FinnGen insomnia and with the original Brain6 insomnia, always using this same intersection. Compute single-signal ABF coloc for FI (quantitative prior SD 0.15) and each case–control trait (log-odds prior SD 0.2), using p1=p2=1e-4 and both p12=1e-5 and 1e-6. Also report each region's marginal association minima and variant count. The priors are assumptions, region was selected post hoc, and different sleep cohort and model definitions prevent causal attribution of cross-comparison differences. No multiple-testing claims or independent replication follow. Low H4 with dominant H0/H1/H2 may indicate low power, not distinct causal variants. Single-signal assumptions and missing variants can mislead; source overlap, ancestry and phenotype differences, FI sleep items, allele/frequency limitations and the previously documented LD–Z mismatches remain. This does not repair LAVA QC or validate multi-signal fine-mapping.
