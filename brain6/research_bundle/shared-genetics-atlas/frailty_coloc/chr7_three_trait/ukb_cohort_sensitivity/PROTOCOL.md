# UK Biobank-only FI sensitivity in the selected chromosome 7 region

This post hoc sensitivity replaces the original FI meta-analysis beta and standard error with Atkins UKB1 cohort estimates for the same previously matched insomnia–ADHD variants. Select rows by rsID and GRCh37 chromosome/position, require unique exact nonambiguous allele pairs, and orient the UKB FI beta to the existing analysis effect allele. Restrict both the meta-analysis and UKB-only runs to the identical intersection. Exclude missing or invalid beta/SE values; record counts and SHA-256 hashes. UKB is part of the meta-analysis and this is not independent replication. Do not redistribute the combined restricted ADHD input.

Repeat the parent single-signal HyPrColoc settings with independent study statistics, the same trait types and priors, and pairwise ABF coloc for FI–insomnia and FI–ADHD at both parent p12 settings. Compare the two FI sources on exactly the same SNPs, and also report the prior parent result on its original support. This changes source sample composition and power as well as possible allele-adapter issues; it does not identify which causes a difference. UKB FI retains insomnia and tiredness, and both UKB FI and insomnia use UK Biobank, making independence questionable. No LD-aware multi-signal inference, local genetic correlation, correction for post-selection, or new independent validation is claimed.
