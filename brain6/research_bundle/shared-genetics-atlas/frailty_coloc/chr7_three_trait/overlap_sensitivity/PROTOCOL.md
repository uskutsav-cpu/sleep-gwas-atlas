# Illustrative cross-trait correlation sensitivity

Post hoc stress test of the previously selected chromosome 7 FI–insomnia–ADHD common-support pilot. Use the identical 1,055 matched variants and frozen input SHA-256 recorded in the parent receipt. HyPrColoc 0.0.2 commit 0348bbdd977be731d82e4efda115a9bed63cd44f is run with the parent priors and thresholds. Run the independence baseline and a grid of effective FI–insomnia statistical correlations −0.3, −0.1, −0.001, 0.001, 0.1, 0.3 and 0.5 (the near-zero values check continuity after the initial grid); leave correlations involving ADHD at zero. Supply a unit sample-overlap matrix and insert the hypothetical effective correlation in trait.cor: the implementation multiplies trait.cor by sample.overlap, so these are working products, not measured phenotypic correlations or estimates of overlap. This parameterization makes no claim that all participants overlap. Check positive definiteness and reproduce the baseline before interpreting anything. Record failures rather than replacing inputs. Use the package default identity LD and single-signal assumptions; the correlation-adjusted result is illustrative and not calibrated for this dataset. In particular FI includes sleep items, the GWAS sample overlap, phenotype residual correlation, effective sample-size weighting, and TwinGene allele convention are unresolved. Results cannot correct these issues or resolve multi-signal, GWAS–QTL or LAVA questions. No variant-level source data are redistributed.
