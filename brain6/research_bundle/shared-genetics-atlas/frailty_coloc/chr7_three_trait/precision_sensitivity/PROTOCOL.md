# Post-selected chromosome 7 FI precision stress test

Written before seeing perturbation results. On the exact 1,055-variant FI–Brain6 insomnia–ADHD input used in the preceding pilot, perturb each FI beta and SE independently by a uniform draw from −0.00005 to +0.00005, while keeping both other traits and all markers fixed. Use 200 realizations with seed 20261027. This corresponds to an illustrative half-unit interval for four-decimal rounding; the actual source rounding rule, unknown digits, correlations among errors and p-value consistency are not established. Do not interpret replicates as samples from a posterior distribution. Confirm SE remains positive.

At each realization rerun HyPrColoc with the pilot's default independent-study assumption, association prior 1e-4, conditional prior 0.02, thresholds 0.5 and branch-and-bound. Record cluster membership, posterior and candidate marker. Also recompute FI–insomnia and FI–ADHD single-signal ABF H4 at p12 1e-5 and 1e-6 with the previous effect priors. Report the baseline and full empirical ranges, cluster counts and top-marker counts, without claiming a confidence interval or model calibration. Check baseline matches the previous pilot and use a fixed seed; store output and reproducible code. The analysis is post hoc, uses the same incomplete support and source cohorts, assumes independence even with potential overlap, and does not fix rounding or validate any shared biology, LAVA, multi-signal method, replication, or sleep-item-excluded FI.
