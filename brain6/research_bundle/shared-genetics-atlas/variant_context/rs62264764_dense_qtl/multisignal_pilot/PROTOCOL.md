# Preliminary multi-signal pilot: chr3 adrenal LSAMP and insomnia/ADHD

Prepared before viewing multi-signal fits. Goal: evaluate, not assume, whether reference-LD-aware methods are usable on the previously selected chr3 region, complementing—not repairing—the failed LAVA gate. Start from the intersection of the previously recorded adrenal LSAMP–insomnia and LSAMP–ADHD exact-allele matched sets. The region was chosen after observing outcomes; the result is exploratory and cannot establish independent replication or tissue/gene causality. No AlphaGenome output is used to fit any model.

## Reference LD construction

Use 1000 Genomes Phase 3 EUR-labeled individuals (503 expected) and the publicly indexed chr3 GRCh37 VCF. Convert each selected GRCh38 SNP to GRCh37 via the pinned chain and require a unique same-chromosome positive-strand lift, matching rsID and exact REF/ALT single-nucleotide alleles to a unique VCF record. Count the source ALT allele for every diploid reference genotype. Retain variants with all 503 sample genotypes called as the specified alleles and reference MAF at least 0.01. Exclude missing, multiallelic, ambiguous, monomorphic, mismatch and duplicate keys, preserving counts and source hashes. Compute an individual-dosage Pearson LD matrix using the same allele order as both QTL and GWAS; check symmetry, diagonal, finite values, expected rank and selected pair agreement. The 503-person mixed-European panel is not study-specific LD, and the frozen GWAS inputs lack allele frequencies, so unknown ancestry/allele artifacts remain.

## Planned model and gates

If at least 500 common variants and at least 70% of the input intersection survive the reference QC, fit the pinned `susieR::susie_rss` separately to GTEx eQTL, insomnia and ADHD, using signed beta/SE, the corresponding matched alleles, GTEx sample count, and the per-trait N_AUDIT values with explicit effective-N caveats. Use external-reference default `estimate_residual_variance=FALSE`, ten effects and fixed seed, test consistency of z and LD using the available `susieR` diagnostics, capture convergence, credible-set purity, warnings, and program/package versions. Run official `coloc.susie` on compatible fits for both disease–eQTL pairs only if both converge and pass the prespecified input/fit gates; report all credible-set pairs, H3/H4 and sensitivity to p12=1e-5 and 1e-6. Numerical convergence and purity do not prove calibration. A singular reference matrix is expected because variant count exceeds reference sample count; investigate rather than silently regularize. If the package, sample-size semantics, LD consistency or source provenance cannot be justified, label results exploratory/not admitted and avoid causal claims. Compare with single-signal analysis on the same exact retained variants to distinguish changed coverage from method changes. All outputs are research hypotheses subject to expert review; no local-correlation gate is altered.

**Before fitting, sample-size clarification:** the 1,548 retained ADHD variants have N_AUDIT from 64,699 to 128,214, with median 128,214 and 291 values below the maximum; insomnia has N_AUDIT 313,750 for every retained variant. Because this installed SuSiE interface accepts one scalar sample size, use the rounded trait-specific median for the primary diagnostic, and repeat the ADHD fit with the rounded minimum as a deliberately conservative sample-size sensitivity. These are effective/audit fields, not independently verified per-variant actual cohort sizes; using either scalar is an approximation and a reason not to admit findings as validated. Use the median GTEx allele-count/2 for eQTL sample size after recording its distribution. This addition is made before any multi-signal fit is examined.
