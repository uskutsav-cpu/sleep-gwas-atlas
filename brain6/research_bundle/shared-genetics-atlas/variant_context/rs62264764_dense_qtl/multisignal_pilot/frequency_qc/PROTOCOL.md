# Source-frequency diagnostic for rs62264764 multi-signal pilot

Before inspecting frequency results, revisit the 1,548 already retained SuSiE pilot variants in the archived original ADHD and insomnia GWAS summary files. Check their compressed source SHA-256 against the existing historical harmonization QC receipts; this identifies the current bytes but does not independently verify original-run provenance. Match unique rsID, GRCh37 position and unordered allele pair and verify that log(OR) aligned to the reference ALT and SE agree with the pilot input. Record duplicate, absent, mismatched and invalid records instead of guessing.

For ADHD use the published PGC `FRQ_U_186843`, documented as A1 frequency in controls, and orient it to the retained reference ALT. For insomnia the source column is labeled `MAF`; compare it only as minor-allele frequency with min(reference ALT frequency, 1−frequency), without assuming its direction. The insomnia source MAF labeling will be treated as an assumption pending the original author's column documentation. Compare with the 503-person 1000 Genomes EUR dosage frequencies. Report descriptive absolute-difference summaries and counts >0.05, >0.10 and >0.15, including within post-hoc kriging |standardized residual|>3 groups. These thresholds describe differences, not independently calibrated QC tests; ancestry, case–control ascertainment, sampling, imputation, missingness and LD can all affect comparisons. Frequencies and kriging residuals are not independent across SNPs. Do not automatically flip or drop variants, or refit SuSiE based on these results. For ADHD calculate 4*Ncase*Ncontrol/(Ncase+Ncontrol) using its source per-variant case/control counts and compare with the stored N_AUDIT, recording exact matches and discrepancies. This does not prove that effective N is the appropriate scalar SuSiE sample size. No AlphaGenome model output is used.
