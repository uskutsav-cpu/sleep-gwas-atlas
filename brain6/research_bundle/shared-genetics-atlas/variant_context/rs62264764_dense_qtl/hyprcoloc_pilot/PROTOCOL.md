# Chromosome 3: three-trait HyPrColoc pilot

Pre-result protocol: analyze the prior 1,548-variant common support for GTEx v8 adrenal LSAMP expression and the original Brain6 insomnia and ADHD GWAS. Use allele-aligned betas and SEs from the already source-audited multi-signal pilot, require unique biallelic variants, finite effects and positive SEs; the selected support was constructed with a 503-person 1000 Genomes EUR reference, and is not the full cis/GWAS region. Use HyPrColoc 0.0.2 at pinned commit 0348bbdd977be731d82e4efda115a9bed63cd44f with the previously documented Eigen compatibility patch. Confirm the package example's cluster and SNP identities before running. Use expression as quantitative and insomnia and ADHD as binary, setting effect-prior SDs via the package to 0.15 and 0.20 respectively. The analysis uses `ind.traits=TRUE` as an unverified approximation, with prior.1=1e-4, branch-and-bound, default regional/alignment thresholds 0.5 and conditional prior 0.02; repeat at 0.01 and 0.005, and at thresholds 0.9 with conditional prior 0.02. Record all clusters, including absent traits, candidate markers, settings, full software output, code, source hashes and checks. No AlphaGenome output is a model input.

This post-selected model assumes a single causal variant per trait and uses prior and window assumptions. It is not a multi-signal fine-map, a local correlation, independent replication, or a LAVA QC rescue. Independence is not verified; sample overlap, population differences, source model, lack of dense variant coverage, the limited GTEx sample and serious LD–Z diagnostic flags remain. The method's independent-trait mode does not use study-matched LD, and therefore cannot diagnose or cure those LD–Z issues. Adrenal expression is not a brain-cell assay. Posterior support and SNP scores are conditional on the model and do not establish gene mediation, pathway or variant causation. Sensitivity differences or missing expression cluster do not demonstrate absence of a biological effect or a secondary signal. Report this pilot as not validated.
