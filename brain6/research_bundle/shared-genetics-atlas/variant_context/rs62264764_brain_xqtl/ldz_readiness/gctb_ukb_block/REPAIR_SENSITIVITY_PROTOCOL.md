# Post-failure numerical-repair sensitivity protocol

The extracted GCTB matrix did not pass the original PSD gate. This is a post-hoc diagnostic experiment, not a revision of that gate and not a validated replacement LD reference. The cause of negative eigenvalues is unknown. GCTB's currently published source uses single-precision calculations and stores floats, but we cannot establish that this exact archive was produced by that version or that numerical precision explains the observed eigenvalues.

On the same 1,547 allele-aligned variants, compare two independently specified transforms of the normalized matrix: (1) set negative eigenvalues to zero and renormalize the diagonal; (2) shrink correlations toward identity with weight 0.001, `0.999 R + 0.001 I`. The latter exceeds the approximately 0.000348 minimum diagonal shift required for this matrix. Record eigenvalues, maximum entrywise and Frobenius changes, and verify symmetry and diagonal after each transform. If either is not PSD to numerical tolerance, stop. Never claim that either transform reconstructs study LD.

Compare SuSiE RSS LD–Z inconsistency and kriging residual summaries for both repaired matrices and the earlier 503-person 1000 Genomes matrix, using the same variants and the same sample-size assumptions (737 for each brain QTL, 313,750 for insomnia, 128,214 for ADHD). These are the previous scalar assumptions, not verified effective sample sizes; the ADHD source has variable N. Report errors as errors, and report all references and trait combinations. The residual cutoffs 3 and 5 are descriptive, not calibrated gate thresholds; the experiment is selected after seeing the original problem. No new fine-mapping, colocalization, causal claims, LAVA rescue or AlphaGenome-guided selection follows from improvement in these statistics. Include source/reference differences, possible UKB overlap and the lack of study-specific LD when interpreting results.
