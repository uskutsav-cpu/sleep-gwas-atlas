# ADHD sample-size and source-alignment sensitivity

The original ADHD source has variant-dependent case and control counts, so a single sample size cannot represent every marker. Before evaluating these results, repeat the GCTB eigenvalue-clipped, GCTB identity-shrunk and 1000 Genomes LD–Z diagnostics on the same 1,547 variants using the existing minimum `N_AUDIT` of 64,699, rather than the earlier median 128,214. Keep everything else unchanged. Compare maximum absolute residual and counts above 3 and 5 with the earlier median-N results; these cutoffs are post-hoc descriptive flags, not calibrated hypothesis tests. This changes a scalar approximation and does not implement per-variant sample sizes or fix LD differences.

For the 10 largest absolute ADHD residuals from the median-N GCTB eigen-clipped diagnostic, compare original source chromosome, build-37 position, allele set, ALT-aligned effect and source control allele frequency against the stored pilot and both LD references, and report the audited per-variant effective N range. Recheck original file SHA-256 and require unique matching rsIDs. This source-alignment check is post-selected and descriptive: close frequencies do not prove correct LD, allele orientation, calibration or independent replication. Source data are restricted to noncommercial research, and the original ADHD rows are not to be redistributed. Do not remove or flip variants in response to these results. Neither sensitivity justifies a new fine-mapping, colocalization, LAVA or AlphaGenome causality claim.
