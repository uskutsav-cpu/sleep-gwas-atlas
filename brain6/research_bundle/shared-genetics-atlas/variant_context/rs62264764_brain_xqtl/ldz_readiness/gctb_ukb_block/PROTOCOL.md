# Public GCTB UKB full-LD block feasibility

Before reading block associations or evaluating model outputs, inspect the public GCTB archive via verified-length HTTP ranges. Use its GRCh37 partition file to identify the block containing rs62264764 and check block metadata; extract only that block's SNP metadata and, if resource limits allow, the necessary matrix subset. Require ZIP member CRC checks, source version/length and payload hashes; the 206 GB full ZIP will not be downloaded or authenticated. Record requested ranges and data lineage. Do not fill absent pairs from the thresholded ADSP file.

The reference comes from 10,000 unrelated UKB European-ancestry participants, not the brain-QTL, ADHD or Finnish insomnia cohorts, and may overlap a discovery cohort. The archive's exact variant QC, LD calculation, allele orientation and reference selection remain to be checked; block membership may truncate the earlier 1-Mb region and variant coverage. Require exact position, alleles and strand-safe orientation; report unmatched and duplicates. Check finite entries, diagonal, range, symmetry and eigenvalues before any statistical use. A passing numerical matrix is not proof of study compatibility. Before interpreting a multi-signal model, examine LD–Z diagnostics, correct sample sizes, model assumptions and existing failures. This does not automatically rescue the LAVA gate or establish gene causation; no AlphaGenome output is used.
