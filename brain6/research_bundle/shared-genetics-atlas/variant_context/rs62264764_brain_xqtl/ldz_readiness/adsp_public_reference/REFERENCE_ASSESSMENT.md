# ADSP LD references: accessibility and matrix suitability

NIAGADS provides open-access **R4 and R5 pairwise LD files** in [NG00067](https://dss.niagads.org/datasets/ng00067/) and its [public file portal](https://dss.niagads.org/open-access-data-portal/). The release manifest lists an R5 chromosome 3 file for 26,042 individuals in its NHW/European-labeled group. This is a much larger reference than the 503-person panel previously used for Brain6, but it is not the study-matched LD of the sleep, ADHD or brain-expression GWAS.

The publisher's R5 README (section 4.3) states that pairs must have minor allele count ≥ 5, be within 5 Mb, and have **|R| ≥ 0.2** to be included. The R4 README likewise reports a |R| threshold of 0.2. Consequently an absent pair can represent low correlation, absent or filtered variants, or other data limitations. It must not be treated as an observed zero. These files do not directly provide the full signed correlation matrix required for the existing SuSiE-RSS fit; zero-filling missing pairs would impose unsupported values and can invalidate matrix properties. A [three-variant numerical example](threshold_example/RESULTS.md) demonstrates how zero-filling can make a valid correlation matrix indefinite.

A separate [FunGen LD resource page](https://statfungen.github.io/xqtl-resources/) describes large dense or sketched ADSP references in the AD Knowledge Portal, but states that those folders require a Synapse account and approved data access. The user has said they have no Synapse account and requested public data; we did not attempt controlled access. The public NIAGADS xQTL summary files and portal remain distinct from those controlled LD resources. The site descriptions use different ADSP cohorts and sample counts across releases, so these panels should not be conflated.

A [completed pairwise lookup](RESULTS.md) in the open R5 chromosome file reports r² = 0.99919 for rs62264764 and rs62264767; the full source stream passed its checksum. A pairwise correlation would be a population-specific reference observation, not an independently replicated disease association, a causal-variant assignment, a validated full LD matrix or a repair of the failed local-QC gates.
