# Public ADSP R5 LD check for two rs62264764-region markers

Written before reading the marker pair. The publisher's R5 README says only variant pairs with |R| ≥ 0.2 and within 5 Mb are included, subject to MAC ≥ 5. Stream the complete compressed file without saving it; compute and verify byte count and MD5 against the manifest, compute SHA-256, and require successful full gzip decompression. Extract all rows where the two GRCh38 positions are 117920728 and 117923158 in either order. Check alleles before interpreting signed R. Report missing or duplicate rows and use no absent pairs as zero correlation.

This is an external reference-LD observation for a selected pair, not study-specific LD, fine-mapping, disease replication, proof of a causal SNP, or a LAVA gate repair. The cohort includes Alzheimer disease cases and controls, ancestry labels are broad, the samples are not the exact sleep/ADHD or xQTL donors, and possible relatedness and ascertainment may affect generalizability. The pairwise file is thresholded; filling missing matrix entries with zero would not recreate the unthresholded LD matrix required for SuSiE and is not attempted. No AlphaGenome output is used.
