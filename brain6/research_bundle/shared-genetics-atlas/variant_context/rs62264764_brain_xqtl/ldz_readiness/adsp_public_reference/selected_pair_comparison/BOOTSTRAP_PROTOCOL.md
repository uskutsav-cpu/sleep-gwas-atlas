# Post-selected 1000 Genomes reference-resampling sensitivity

After viewing the pair discrepancies, take the three largest absolute r² differences among the previously matched pairs. This is an explicitly post-selected follow-up. Fetch the 1000 Genomes Phase 3 chr3 VCF at the original GRCh37 positions, requiring unique position and REF/ALT matches to the original marker table and the same 503 European-labeled IDs and panel hash. Recompute dosage r² and require agreement with the archived LD matrix. Bootstrap individuals jointly with replacement 5,000 times using a fixed seed, recompute each pair's r², and summarize percentile intervals and how often the bootstrap r² is at or below the ADSP reported value. Report sample count and monomorphic replicates, not a p-value.

These intervals describe only resampling variability in the 503-person reference, condition on selected pairs, and do not account for reference relatedness, population admixture, LD metric differences, ADSP sampling uncertainty, selection, or disease-study mismatch. ADSP r² may use a different genotype/phase definition, and its recorded value is rounded and threshold-selected. Do not call nonoverlap of the bootstrap interval an ancestry effect, statistical significance, causal evidence, proof of any panel error or a validated LD matrix. Missing pairs remain missing; no AlphaGenome scores enter the analysis.
