# Post-selected within-European reference sensitivity

For the three LD pairs chosen after observing large between-panel differences, query the same uniquely matched 1000 Genomes Phase 3 variants used in the previous resampling audit. Retain the five population labels in the 503-person European superpopulation, compute the two ALT allele frequencies and dosage r² for each pair and group, and bootstrap individuals within each group 3,000 times using a fixed seed. Record group sizes, monomorphic samples, undefined replicate counts, 2.5%–97.5% percentile intervals and ADSP values. Validate that the pooled dosage results agree with the earlier saved matrix and panel hash.

This sensitivity is post-selected and groups have approximately 100 participants, so allele counts and r² estimates can be unstable. Do not compare group intervals as independent significance tests, infer a biological or ancestry-specific cause, represent these populations as populations of the GWAS studies, or treat the ADSP panel as either a simple average or an independent individual-level validation. ADSP and 1000 Genomes LD calculations may differ. Record remote VCF/index limitations. No AlphaGenome outputs are used.
