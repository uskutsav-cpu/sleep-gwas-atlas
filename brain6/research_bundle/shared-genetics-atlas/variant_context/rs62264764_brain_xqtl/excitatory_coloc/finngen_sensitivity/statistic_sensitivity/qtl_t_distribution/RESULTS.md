# Why the QTL p-values differ from normal beta/SE p-values

The discrepancy is **strongly consistent with a Student's t reference distribution**, rather than evidence of an allele error. Fitting the degrees of freedom using only the strongest selected QTL marker gives 672.9993, which rounds to 673. With that fixed value, the other 2,440 matched markers' reconstructed two-sided t p-values agree with the reported p-values to a maximum absolute difference of **0.00000383 on the log₁₀ p scale**. The corresponding maximum discrepancy using a normal reference is 2.615 log₁₀ units.

This is consistent with the published [FunGen xQTL atlas methods](https://pmc.ncbi.nlm.nih.gov/articles/PMC13308301/), which report TensorQTL 1.0.10, and with [TensorQTL's nominal association implementation](https://github.com/broadinstitute/tensorqtl/blob/master/tensorqtl/cis.py), which computes p-values from a t statistic and degrees of freedom. The fitting was post hoc, and nearby variants are correlated; the close match is not an independent validation of all source rows. The source run's actual covariates and degrees of freedom were not independently recovered. In particular, **673 is not an inferred donor count**.

The earlier coloc ABF uses beta/SE in a normal-approximation model. The [p-derived-Z hybrid sensitivity](../RESULTS.md) was useful for diagnosing dependence on statistic representation but is not a replacement likelihood. Knowing a plausible reason for the discrepancy does not prove normal-approximation calibration, establish a shared causal variant or gene, eliminate ancestry and multi-signal limitations, or repair the failed LAVA gates.
