# LaDDR insomnia–RNA colocalization: source-code review

The published LINC03051 insomnia results provide a useful prior hypothesis, but their PP4 values are outputs of a specific **selected, single-signal analysis**, not direct evidence that rs62264764 changes LINC03051 or mediates ADHD. A review on 28 October 2026 of the author's publicly linked code clarifies several assumptions that were previously unresolved in the atlas.

The [published paper](https://doi.org/10.1016/j.ajhg.2026.06.005) describes FUSION xTWAS, followed by coloc for hits with xTWAS p<5×10⁻⁸; it labels PP4>0.8 as colocalizing for that study. In the public [workflow at commit 262444e](https://github.com/daniel-munro/laddr-cluster/blob/262444ecbeeddef1cf4a43ebbfe9727e720a9be9/twas/Snakefile), the named reference is `1000G.EUR`, and the coloc trigger is 5×10⁻⁸. The accompanying [FUSION script at that commit](https://github.com/daniel-munro/laddr-cluster/blob/262444ecbeeddef1cf4a43ebbfe9727e720a9be9/twas/scripts/FUSION.assoc_test.R) calls `coloc.abf` without explicit prior arguments. It uses gene-model SNPs retained in that reference, and can impute missing GWAS Z scores using reference LD. The script specifies both input traits as quantitative and constructs approximate effects and variances from Z scores and the respective supplied sample sizes, with sdY=1. The code rounds posterior probabilities to three decimals.

The standard coloc ABF model considers at most one causal variant per trait in the supplied region. The reference's filename is evidence of the workflow's intended ancestry panel, not an independent validation of its actual sample composition, completeness or suitability for each dataset. We did not establish the fraction of imputed or excluded SNPs for the LINC03051 rows. The exact coloc package version, actual default priors in the executed environment, software provenance of the published run and sensitivity to priors have not been verified; do not assign numeric prior values based solely on this script. Likewise, approximate Z-based inputs are not a reconstruction from the original variant-level betas and standard errors.

Multiple RNA features and tissues were tested, and colocalization was applied after xTWAS selection. The paper notes that its TWAS approach does not enforce conditional independence across phenotypes and modalities. The eight selected LINC03051 results therefore should not be counted as eight independent confirmations. Their features also measure different RNA coverage patterns from the atlas's single-nucleus total-expression comparisons; differing results need not be contradictory. The public source tables' PP4 values and local calculations should not be treated as a formal joint analysis of insomnia, ADHD and RNA, nor as independent replication of Brain6's UK Biobank-containing insomnia signal.

This review reads the repository and article, not the original execution environment or underlying input matrices. It does not rerun LaDDR or prove why its estimates differ from the atlas. A better follow-up would obtain the exact feature-level full summary statistics and executed dependencies, audit sample overlap and allele coverage, and test prior and multi-signal sensitivities with suitably matched LD. Experimental perturbation and independent trait cohorts remain needed for gene and disease interpretation.
