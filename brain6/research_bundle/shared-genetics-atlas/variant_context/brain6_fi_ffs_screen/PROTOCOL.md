# Post-selected Brain6 candidate FI and FFS screen

Written after identifying the already-reviewed 425 Brain6 variant rows, prior chr5 FFS findings and HFRS results, and before the full FI/FFS screen. Read exactly the frozen AlphaGenome pilot 425-row set, preserving all rows and documenting any repeated rsID or coordinate. Stream the archived full Atkins FI and Ye FFS sources; verify their compressed or plain SHA-256 against the earlier whole-file receipts. Match unique rows using exact GRCh37 chromosome, position, rsID and unordered source A1/A2 allele pair; label missing, duplicates, mismatches and invalid values. Exclude palindromic pairs for signed comparisons and align source effect beta to the frozen Brain6 source A1 only under the documented source conventions; FI has named effect_allele and FFS A1 convention is supported by the 37-COJO-row audit, not directly verified for every SNP. Use reported p-values rather than beta/SE derived p-values.

For descriptive cross-phenotype patterns, Bonferroni-adjust 850 slots (425 variants × two FI/FFS outcomes), counting unavailable rows in the denominator, and report all source p values and whether each crosses the numerical threshold. Exact marker overlap does not imply a shared causal variant. Record groups by known chromosome/region but do not count correlated SNPs as independent loci. These candidates and sources were repeatedly selected and examined before this screen, so the 850-slot benchmark is not confirmatory FWER control of the broader project. FI includes insomnia/fatigue and FFS includes exhaustion, both include UKB; no independent two-trait replication, item-excluded association, causal mechanism, AlphaGenome validation or LAVA QC rescue is implied. Do not change or duplicate the large source files.

After the FI/FFS screen and before the three-score join, add the previously checksum-verified UKB HFRS original-score rows for the same 425 IDs. Require unique ID, identical GRCh37 coordinate and matched allele pair; retain all 425 slots. Report HFRS source statuses and max(p_FI,p_FFS,p_HFRS) × 425 as a separate descriptive three-trait intersection–union benchmark, with all three marginal p-values valid under their source assumptions. This is not a test of common causal variants, independent replication or an atlas-wide correction. Selection and prior HFRS results are already known; UKB cohort overlap is unverified and these are correlated SNPs. This post-hoc family differs from the separate FI/FFS 850-slot screen; do not mix its thresholds or error claims.
