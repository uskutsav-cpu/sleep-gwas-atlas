# rs6874138 raw barcode consistency diagnostic

Before inspecting totals, use only rs6874138's previously mapped REF and ALT labels to count exact matching barcode reads in each of the 44 released compressed raw-count files, streaming the tar archive without extraction. Compare these counts descriptively with the corresponding row of the 22-column-per-allele DNA and RNA aggregated matrices using tar order as a provisional replicate alignment. Record per-file names and counts, compare sums and correlations, and check the files' DNA/RNA labels. This assumes rather than proves that tar order matches matrix columns, and the selected mapped labels need not represent the publisher's complete filtered barcode set. Counts greater or smaller than the published matrix values do not alone establish a processing error, orientation, sample crosswalk or activity effect. Preserve source hashes and report mismatches. This is a post-selected diagnostic, not a replication of the assay or a new GWAS or AlphaGenome inference.
