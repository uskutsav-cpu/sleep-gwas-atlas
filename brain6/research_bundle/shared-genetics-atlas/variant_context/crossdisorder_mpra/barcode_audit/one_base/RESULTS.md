# One-base barcode diagnostic for four Brain6 candidates

Single-base differences do **not** explain the observed mismatch in the examined files. For rs185260, rs325485, rs4916723 and rs62369151, none of the mapped labels for either allele had a raw label exactly one nucleotide substitution away among the 44 released count files. The earlier audit also found no exact matches for these four variants. For rs4916723 specifically, that includes 121 reference and 147 alternate mapped labels.

The two independent implementations agree: the main scan generated all single-substitution neighbors of coordinate-and-allele-matched labels; the [check](verify.py) used deletion masks against **892 unique labels** selected by rsID, a superset of the main search, and examined 7,293,680 raw rows. Both found zero one-substitution pairs. The raw archive and mapping hashes matched the prior audit, and all 44 compressed count streams were read through completion. [Protocol](PROTOCOL.md), [results](results.tsv), [source receipt](receipt.json), and [verification](verification.json) preserve the checks.

This narrows one explanation only. Different libraries, construct mappings, preprocessing, sample files or larger barcode transformations remain possible. It does **not** show that the variants were untested, inactive, or had no allele effect, and it cannot validate the provisional allele model or the published study's QC. rs62264764 itself was not among the 42 matrix matches, so no accessibility or reporter result is assigned to it.

The [paper's Table S1](https://pmc.ncbi.nlm.nih.gov/articles/PMC11890967/) is described as containing the desired published enhancer and allelic statistics. As a separate access check, NCBI's [public S3 article prefix](https://pmc-oa-opendata.s3.amazonaws.com/?list-type=2&prefix=PMC11890967) listed only metadata, text and XML for this manuscript version on 28 October 2026; it did not list the spreadsheet. That does not prove the file is unavailable through all routes. The original discrepancy between the released barcode mapping and counts remains unresolved.
