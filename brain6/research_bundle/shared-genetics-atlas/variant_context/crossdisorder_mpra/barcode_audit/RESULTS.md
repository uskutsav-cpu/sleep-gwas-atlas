# Targeted raw-barcode reconciliation

The public [GEO GSE244011](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE244011) release includes 44 compressed barcode-count files inside `GSE244011_RAW.tar`, a barcode-to-variant mapping, and aggregated count matrices. This post-hoc audit checked rs4916723 and rs11242522; the latter is present in the released exclusion list. File order was used as a tentative mapping to the 22 DNA and 22 RNA replicates, not an independently verified sample crosswalk.

The mapping file lists 121 REF and 147 ALT barcode labels for rs4916723. **None of those exact labels appeared in any of the 44 released barcode-count files**, even though the aggregate DNA and RNA matrices contain nonzero counts for the same coordinate and alleles. This was checked by streaming all 44 files without extracting the archive. We have not identified why the mapping and raw counts do not reconcile. The zero label overlap is an observation about these specific released files and this exact matching procedure; it is not evidence that the experiment lacked the variant or that the allele has no activity.

For rs11242522 the mapping file lists 162 REF and 136 ALT labels, and some are found in all 44 barcode-count files. In the first listed DNA file the raw matched labels total 823 REF reads and 362 ALT reads; the first aggregated DNA-matrix columns contain 835 REF and 861 ALT reads. In the first listed RNA file the raw matched labels total 836 REF reads and 375 ALT reads; the first aggregated RNA-matrix columns contain 858 REF and 1,165 ALT reads. Sample-order assumptions, mapping conventions, and preprocessing may explain differences; no cause has been established, and this comparison is not a reproduction of the authors' barcode filters.

The mismatch means raw mapped barcode counts cannot yet reconstruct the 13,311-variant post-QC set or confirm the publication's results for rs4916723. Results from the [prior model pilot](../RESULTS.md) remain exploratory and should not be treated as validated measurements. [Raw matched totals](raw_barcode_totals.tsv), [script](audit.py), and [receipt](receipt.json) record the source filenames, barcode counts and SHA-256 hashes. The 60.4-MB source archive remains on the SSD; no extraction or deletion was performed.

## Coverage across the 42 prioritized matrix variants

A subsequent scan used the full 42-candidate set and matched mapping entries by GRCh37 chromosome, position and listed REF/ALT alleles, rather than relying solely on rsID. Of 42 matrix variants, **27** had mapping labels for both alleles under that rule. Of those 27, **23** had at least one exact mapped label for each allele somewhere in the 44 raw files; four had neither allele represented by an exact mapped label in those files: rs185260, rs325485, rs4916723 and rs62369151. The other **15** had no mapping labels matching the coordinate-and-allele pattern in this particular mapping file. All 42 are present in both aggregated count matrices. No reverse-complement barcode matches were found in this targeted scan, which does not test other transformations or alternative mappings.

The absence of a mapping entry or raw-label match is a limitation of these particular files and matching rules. It is not evidence that a variant was untested, failed publication QC, or lacked an effect. Having at least one observed label for each allele likewise does not establish the paper's minimum-five-barcode rule after all filtering. The complete [coverage table](coverage_42.tsv), [script](audit_all.py) and [receipt](coverage_receipt.json) retain per-allele mapping and file counts. Resolving the mismatch requires a verified sample/construct crosswalk or the authors' complete processed results, and the current pilot remains unvalidated.

A [one-base substitution diagnostic](one_base/RESULTS.md) found no raw barcode one nucleotide away from the mapping labels of the four candidates with no exact matches. Other transformations and file or library differences remain possible; the discrepancy is not resolved.
