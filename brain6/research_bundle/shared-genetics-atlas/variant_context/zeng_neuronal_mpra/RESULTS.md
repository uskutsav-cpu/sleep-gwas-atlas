# Zeng neuronal MPRA: candidate evidence and access receipt

[Zeng et al., Science 2024](https://pubmed.ncbi.nlm.nih.gov/38781378/) report testing 19,893 brain QTL variants in an induced-excitatory-neuron reporter assay and 476 variants with detected allelic effects. Their associated [preprint data statement](https://pmc.ncbi.nlm.nih.gov/articles/PMC10120699/) links to the [Brain neuron/glia caQTL project](https://www.synapse.org/Synapse:syn25955362). Within its public-release MPRA folder, the Synapse metadata catalog lists [allelic_effect_results.tsv (syn51132130)](https://www.synapse.org/Synapse:syn51132130), version 1, created 2023-02-24. This is a promising independent functional-assay table to check for the previously selected Brain6 variants; its contents, tested variant set, genome assembly, and relationship to the final publication have not been verified.

On 2026-10-27 the anonymous metadata API returned HTTP 200, but the file download endpoint returned HTTP 403: “Anonymous users have only READ access permission.” No data file was downloaded, and no variant result can be claimed. The [PsychENCODE portal guidance](https://help.psychencode.synapse.org/docs/getting-started) says downloads require a registered Synapse account and agreement to its terms; some datasets can have additional access requirements. Account registration alone has not been verified as sufficient for this file.

Once legitimately available, record version, checksum, assay design and build; match rs62264764, rs62264767, rs2431108, rs77960, rs416223, rs1476535 and rs4916723 by coordinates and alleles, distinguish absent variants from tested nonsignificant variants, and report the original effect allele, uncertainty and source-adjusted p-values. Treat the selected set as post hoc; any correction for that family is descriptive. Reporter activity in isolated constructs is not a measurement of endogenous chromatin accessibility, evidence of gene mediation, or independent replication of the two-trait GWAS signal.
