# Selected Brain6 variants: cross-source hospital-frailty comparison

This post-hoc comparison joins the existing 425-candidate UK Biobank original-HFRS screen to the Finnish HFRS lookup by rsID and the exact previously mapped GRCh38 position and allele string. Retain only uniquely matched records from each source and align both signed effects to the candidate ALT allele as recorded in the existing files. Report source p-values, effect directions and max(p_UKB, p_Finnish), with Bonferroni adjustment over all 425 candidate slots, including unavailable variants. Summarize source agreement and selected candidate rows; count SNPs, not independent loci. This correction is descriptive within this post-selected family, not project-wide confirmation.

The max-p intersection–union test requires valid marginal p-values, not independent samples; it tests marginal association with both source phenotypes, not directional consistency, causal sharing, or insomnia or ADHD replication. Direction concordance is descriptive, not a separate significance test. HFRS source definitions, ancestry, ascertainment, sample relatedness, effect scales and processing differ or are incompletely verified, so do not pool raw effects or label this an independent replication without cohort checks. The earlier UKB source N discrepancy and the reference-based build/allele mapping remain open. The dementia-excluded UKB score is outside this comparison.
