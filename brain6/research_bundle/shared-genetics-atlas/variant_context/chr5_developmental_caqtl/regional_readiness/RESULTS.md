# Readiness of the developmental chromosome 5 peak for regional analysis

For the post-selected progenitor peak `chr5_104610871_104612270` containing rs2431108 under the assumed peak convention, the complete selected Model1A chromosome file contains **866 variant–peak rows**. Of these, 778 have unique two-base A/C/G/T variant keys; 88 rows do not meet that single-nucleotide representation rule. No eligible exact key was duplicated. This is a format filter, not a judgment that excluded variants are biologically unimportant.

On exact GRCh38 position and unordered allele pairs, **378 of the 778 eligible keys** occur in the existing insomnia–testis-QTL matched file and **371** in the ADHD–testis-QTL matched file. Those files are themselves filtered subsets of the Brain6 GWAS, so these are intersections with a particular prior analysis, not total overlap with the full GWAS or estimates of all causal variants covered. Neither intersection proves correct effect orientation or ancestry matching for a new developmental QTL model.

The developmental file reports variant, beta coefficient, p-value, peak and effect allele, but **no standard error or allele frequency**. Its Model1A test family was selected for a mediation analysis and may not provide an unselected complete cis-QTL set. Recovering an SE from beta and p without verifying the source test statistic and degrees of freedom would introduce an unvalidated approximation. Thus this input is **not admitted for a new regional colocalization**. The prior [three-candidate lookup](../RESULTS.md) remains the appropriate bounded observation.

The [pre-result protocol](PROTOCOL.md), [audit code](audit.py) and [receipt](receipt.json) record source hashes, counts and exact-key rules. A suitable follow-up requires complete, signed nominal peak-QTL statistics with documented SE/test model, build, alleles, sample and ancestry details; coverage and LD checks; and predeclared model and selection controls. It would still not validate AlphaGenome predictions, establish a causal gene or repair failed LAVA QC by itself. See the [source study](https://link.springer.com/article/10.1186/s13059-023-02959-0).
