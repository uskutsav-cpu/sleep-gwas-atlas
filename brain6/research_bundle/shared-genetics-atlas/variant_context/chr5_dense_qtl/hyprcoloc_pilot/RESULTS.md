# Chromosome 5: exploratory three-trait HyPrColoc pilot

Using a model that **assumes independent study statistics and at most one causal variant per trait**, the default HyPrColoc settings grouped testis RP11-6N13.1 expression, insomnia and ADHD, with a reported model-conditional cluster posterior of **0.7312**. That grouping was sensitive to the prior and threshold choices: in two alternative settings the algorithm returned an insomnia–ADHD cluster without expression. The pilot does not establish a three-trait causal variant or a brain mechanism.

| Setting | Returned cluster | Cluster posterior | Candidate variant | Fraction of cluster posterior attributed to candidate |
|---|---|---:|---|---:|
| Default conditional prior 0.02; thresholds 0.5 | Expression, insomnia, ADHD | 0.7312 | rs416223 | 0.8890 |
| Conditional prior 0.01; thresholds 0.5 | Expression, insomnia, ADHD | 0.5775 | rs416223 | 0.8890 |
| Conditional prior 0.005; thresholds 0.5 | Insomnia, ADHD | 0.9174 | rs77960 | 0.3303 |
| Conditional prior 0.02; thresholds 0.9 | Insomnia, ADHD | 0.9780 | rs77960 | 0.3303 |

The package uses an association prior of 10⁻⁴ per variant and its branch-and-bound procedure; the thresholds are for its regional and alignment probabilities. The conditional prior is the model's specified probability of an additional trait sharing a variant, not an empirically observed rate. The reported probabilities and candidate contributions are conditional on the model, inputs and prior assumptions; they are not corrected p-values or proof of causality. When expression is not returned in a cluster, that is not proof of no sharing or no expression effect. Regional and alignment thresholds affect which cluster is returned, and the two-trait and three-trait posteriors answer different model questions.

The input is the same post-selected 1,633-variant intersection used in the [common-support pairwise analysis](../common_support/RESULTS.md). It is not comprehensive regional variant coverage. The two GWAS sources can overlap and their exact overlap is not established; GTEx testis donors are not necessarily representative of the disease cohorts. The independence setting is an **unverified approximation**. GTEx testis is not brain, and no frontal-cortex rows for this gene were available. Single-signal assumptions, LD and population differences, missing source allele frequencies, restricted QTL coverage, effect-prior assumptions and the selected window remain important. Model sensitivity reinforces the need for multi-signal analysis with appropriate LD, cohort-overlap information, independent replication, relevant brain/developmental molecular data and experimental follow-up. No AlphaGenome prediction was used as a model input, and this pilot does not resolve the failed LAVA quality-control gate.

## Reproducibility and software check

The official [HyPrColoc source](https://github.com/jrs95/hyprcoloc) was pinned to commit `0348bbdd977be731d82e4efda115a9bed63cd44f`, package version 0.0.2. To compile against the current RcppEigen, a [recorded compatibility patch](eigen-compatibility.patch) converts numerical SNP indices to integer Eigen indices in two two-causal-variant C++ routines; the pilot invokes the single-causal independent-trait path. The package's documented test dataset reproduced the three published example cluster memberships and candidate SNPs. That is a software smoke test, not proof of statistical calibration or validation of the source patch in all modes.

The [protocol](PROTOCOL.md) was written before inspecting the results. [Settings](settings.tsv), [cluster results](clusters.tsv), [run log](run.log), [serialized full results](pilot_results.rds), [input and output hashes](receipt.json), [code](run.R), [software session](session_info.txt) and [verification](verify.R) preserve the calculation. The verification checks the documented example, setting coverage and output ranges, not independent replication. Package dependencies and a fixed-size build volume were created on the user's external SSD; no additional user files were deleted. The method is described by [Foley et al.](https://doi.org/10.1038/s41467-020-20885-8).
