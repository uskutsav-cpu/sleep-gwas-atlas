# Post-selected three-trait HyPrColoc pilot

Before inspecting results: evaluate the previously selected 1,633-variant chromosome 5 common support for GTEx testis RP11-6N13.1 expression, Brain6 insomnia and ADHD, with no AlphaGenome predictions as inputs. Use HyPrColoc commit 0348bbdd977be731d82e4efda115a9bed63cd44f. Require identical GRCh38 variant keys and alleles, equal QTL beta/SE between matched files, finite effects, positive SEs and at least 500 variants. Use expression as quantitative and the two GWAS as binary, which the package models using effect-prior SD 0.15 and 0.20 respectively. Run a documented package example as a smoke test. Treat trait statistics as independent (`ind.traits=TRUE`) as an explicit *untested assumption*, not a claim of known sample independence. Sources can share participants and cohort overlap is not fully known.

Run the package's branch-and-bound algorithm and default regional and alignment thresholds with prior.1=1e-4 and default conditional prior.c=0.02; repeat at 0.01 and 0.005. Also test more stringent fixed regional and alignment thresholds 0.9 at prior.c=0.02. Save every result, including unavailable/empty clusters, package version, executable code, input hashes and console output. Package cluster posterior and SNP scores are model-dependent and not empirical validation; no hypothesis test or multiplicity-adjusted discovery is claimed. Inspect cluster membership rather than treating a two-trait cluster as all-three sharing. Caution that the package's algorithm assumes one causal variant per trait, adequate variant coverage, and independence in this run. The analysis is post-selected and is a sensitivity to the earlier pairwise results, not an independent replication, LAVA rescue, multiple-signal fine-mapping, brain-tissue mechanism, or three-phenotype causality. Testis is not brain; cohort overlap, reference/ancestry differences and missing allele-frequency verification remain limitations.
