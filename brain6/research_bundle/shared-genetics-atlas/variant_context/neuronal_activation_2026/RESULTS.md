# Potential independent neuronal chromatin source

The original [Liang et al. 2021 developmental caQTL study](https://pubmed.ncbi.nlm.nih.gov/34017130/) points to [dbGaP phs001958](https://www.ncbi.nlm.nih.gov/projects/gap/cgi-bin/study.cgi?study_id=phs001958.v1.p1) for generated data and metadata. The study page describes an authorized-access route. The 2023 Model1A subset used in this atlas is not the complete nominal cis-QTL resource; access to the appropriate data and permission to use them would need to be established before generating fuller results.

A distinct [2026 Science study](https://pubmed.ncbi.nlm.nih.gov/42348686/) and its [Dryad data catalog](https://datadryad.org/dataset/doi:10.5061/dryad.0zpc8677w) describe iPSC-derived excitatory and inhibitory neurons from 100 donors, including stimulated conditions. This is a candidate source for independently measured allele-specific chromatin context, not automatically an independent sleep–ADHD replication. The public catalog describes two especially relevant version-2 files:

- Table S23, approximately 8.1 MB: peak-level caQTL summary rows, including variant, slope, standard error, allele frequency and corrected values. Its selection and the availability of full nominal regional results must be verified before colocalization.
- Table S24, approximately 70.9 MB: allele-specific chromatin SNP records with ref/alt counts and corrected values. The catalog's version history says the second version changed the sequencing-depth cutoff. It is not clear from the catalog alone that every variant was tested or that negative results are included.

The Dryad metadata API returned file sizes and SHA-256 digests, but this execution context received HTTP 403 from the public file-stream endpoint and HTTP 401 from the API download endpoint. No table was downloaded or searched, so **no result for rs62264764, rs2431108, rs77960 or rs416223 is claimed**. These status codes do not prove the files are generally unavailable. The [receipt](metadata_receipt.json) records exact file identifiers and publisher digests. Genome build, genotype/allele convention, cell-specific sample sizes, donor overlap and whether the release contains all tests remain to be verified when the files are accessible.

If access is available, first match exact build, coordinates and alleles; inspect all sheets and cell/time-point labels; then distinguish a published filtered association from a complete nominal regional dataset. An allele-specific observation would test chromatin effects in this model, not establish the effector gene, disease causality or a validated AlphaGenome prediction on its own. A well-powered, ancestry-matched multi-signal comparison and independent perturbation are still required.

## GEO mirror assessment

The study's [GEO series GSE289522](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE289522) is public and lists 24 sample records and a 57.5 GB sample-level archive for this subset. A [representative sample record](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM8793270) labels its processed files GRCh38 and describes Cell Ranger output without BAM files. That establishes the build for that sample record, **not necessarily the variant representation or build of Dryad Tables S23/S24**. The inspected GEO series is one subset of the larger study and does not expose the needed allele-specific or caQTL summary table in its listed series supplement. Its 57.5 GB archive was not downloaded; the SSD did not have sufficient reported free space, and raw/sample-level files are not a substitute for verified summary statistics or genotype access. This is a bounded check of one series, not a claim that all study resources have been searched.
