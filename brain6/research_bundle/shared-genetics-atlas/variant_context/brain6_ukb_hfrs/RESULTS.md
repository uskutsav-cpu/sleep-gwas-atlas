# Brain6 candidates in public UK Biobank hospital-frailty GWAS

We checked all **425 previously ranked Brain6 variants** against the authors' complete [UK Biobank HFRS and dementia-excluded HFRS files](https://doi.org/10.6084/m9.figshare.31259023.v1). All 425 matched each file by rsID, previously mapped GRCh37 position and non-palindromic allele pair and passed the stated MAF and INFO filters. This is a selected, same-cohort candidate screen, not an independent sleep–ADHD–frailty replication or a test of one shared causal variant.

For this exploratory screen the numerical Bonferroni threshold is 0.05/850 ≈ 5.88×10⁻⁵, counting both score versions for all 425 candidates. **72 candidate–score rows**, comprising **37 distinct variants**, cross it: 35 chromosome 7 variants in both score files and two chromosome 3 variants only in the dementia-excluded file. These are counts of correlated SNP records, not independent loci or confirmed shared causal variants. The two HFRS scores use the same cohort, and a difference in whether p-values cross a threshold is not a statistical test of a difference between scores. The screening family was chosen after previous results, so the benchmark does not guarantee post-selection error control.

The chr7 result supports follow-up of a region already implicated by prior sleep–ADHD and sleep–frailty analyses. The [earlier reference-LD review](../../cross_project_ld/CROSS_PROJECT_LD.md) found rs1476535 and the published sleep–frailty candidate rs12536335 in strong LD in a small European reference; that does not prove that the traits share a causal variant or establish FOXP2 as the effector gene. Likewise, the nominal rs62264764 HFRS associations do not validate its AlphaGenome prediction or establish LSAMP/LINC03051 mediation. Absence of threshold crossing for a candidate does not prove absence of an effect. The same-source results cannot resolve failed local-correlation gates.

The two source files were each streamed to completion and passed their full published MD5 checks; source hashes, selection counts, exact p-values, alleles, INFO, effect directions and all 850 rows are retained on the external SSD at `/Volumes/Extreme SSD/brain6-hfrs-candidate-results-20261028.tsv`. The script is `/Volumes/Extreme SSD/brain6-hfrs-candidate-screen-20261028.py` and the checksum receipt is `/Volumes/Extreme SSD/brain6-hfrs-candidate-receipt-20261028.json`. The [pre-result protocol](PROTOCOL.md) specifies matching and thresholds. Maximum absolute log10 difference between source p and BETA/SE-derived p across the retained rows was 0.000114; this confirms numerical consistency, not model calibration. Candidate alleles were carried from the earlier GRCh38-to-GRCh37 mapping and conventional fastGWA A1 effect semantics; source-specific build and allele orientation require further independent verification. Both files report N=407,643, whereas the publication and release description state 407,463; the reason remains unresolved. Exact UKB participant overlap with the sleep–ADHD inputs is unverified.
