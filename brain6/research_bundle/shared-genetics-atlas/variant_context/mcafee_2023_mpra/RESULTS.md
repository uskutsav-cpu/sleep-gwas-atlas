# Public schizophrenia neural-progenitor reporter library: candidate coverage

The [McAfee et al. 2023 assay](https://doi.org/10.1016/j.xgen.2023.100404) tested schizophrenia-associated variants in primary human neural progenitors with a massively parallel reporter assay. It is a distinct public functional resource, not a sleep–ADHD disease replication. The [GEO release GSE211045](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE211045) provides construct sequences and count matrices.

We read the complete public construct-sequence file and found **5,173 unique rsIDs**, each with a reference- and an alternate-labeled construct. None of the **425 unique ranked AlphaGenome candidate rsIDs**, including rs62264764 and rs62264767, matched a construct name. A subsequent exploratory check also found no exact rsID match among the **1,548 variants** in the existing rs62264764 regional pilot. Thus this library cannot provide a direct assay result for those named markers; absence from a schizophrenia-selected library is not evidence that the variants lack function. This is not an exhaustive search of all possible LD proxies, rsID aliases, assays or regulatory contexts.

Construct presence would not by itself establish an allelic effect, and a significant reporter effect would still be measured outside native chromatin. Neural progenitors and schizophrenia-selected loci differ from the target phenotype and developmental context, so no gene, pathway, AlphaGenome accuracy or disease mechanism is validated here. Existing LSAMP/LINC03051 hypotheses and failed local-QC limitations remain unchanged.

The [protocol](PROTOCOL.md), [lookup](lookup.py), [receipt](lookup_receipt.json), [complete downloaded member](../../PUBLICATION.md#external-dependencies) (external target: `cre_sequences.tsv.gz`), and [independent coverage verification](verification.json) document the file and checks. The full gzip member was read to completion and its internal CRC checked; its SHA-256 is recorded, but no publisher hash was available for independent authentication. The regional extension was performed after the ranked-candidate lookup.
