# MVP insomnia–frailty paired contrasts

Before calculating contrasts, reuse the existing 200-block LDSC delete values from the common-marker MVP insomnia run for FI, FFS and HFRS. Reconstruct each r_g delete value from its covariance and two h² delete values; require finite positive h², the previously verified identical MVP h² deletion vectors, matching logged jackknife SEs and the same 991,707 valid markers for every comparison. Calculate FI−FFS, FI−HFRS and FFS−HFRS differences from the logged point estimates and use paired delete-block jackknife standard errors, normal-approximation intervals and p-values. Apply Bonferroni over these three post-hoc comparisons; this does not account for the broader atlas search. No inference should be made if alignment checks fail. Report all three contrasts and relevant LDSC diagnostics. Different score definitions, cohort designs and overlap, ancestry, approximate sample sizes, and shared symptom content prevent attributing differences to physical frailty or item overlap alone. This is not causality, proof of a shared variant, independent replication, or an FI/FFS item-deletion test. No AlphaGenome outputs are used in model training.
