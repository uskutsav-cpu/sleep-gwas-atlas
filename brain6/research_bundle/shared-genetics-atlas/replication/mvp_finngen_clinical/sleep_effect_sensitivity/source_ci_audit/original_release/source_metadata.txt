Info	Description
Title of analysis	Phe_327_4.EUR.GIA
Analysis description	GWAS of Phe_327_4 (Insomnia) in European American MVP participants as defined by GIA. The analysis contains a total of 408138 Veterans, including 78566 cases and 329572 controls. These GWAS results were created as part of the Million Veteran Program (MVP) genomewide PheWAS project. This project was a collaboration between the US Department of Veterans Affairs and the US Department of Energy.
Analysis method description	GWAS was completed, adjusting for age, sex, and first 10 principal components, using a mixed model approach in SAIGE. Results were filtered to remove variants with poor imputation quality (R2<0.3) or that were very rare (MAC<30). Variants with a p-value of zero actually had a p-value that exceeded the number of significant digits possible in R (p<1E-321) but can be recalculated using the effect size and standard error provided.
Sample population	European American Veterans from MVP (GIA)
Sample size	Total Sample Size=408138; Cases=78566; Controls=329572
Analyzed variable	Insomnia
Phenotypic trait type	Binary Trait
Covariates	age, sex, first 10 principal components
