# Archived ADHD-derived file: six-lead coverage check

A previously overlooked archived file named `track_b_finngen_r13_F5_ADHD.sumstats.gz` contains **1,156,825** rows. Among the six original Brain6 regional leads, it has one rsID and allele-pair match: **rs1476535 C/T**, with C-allele Z=−0.9015 and two-sided normal p≈0.367. The other five leads, including chr5 rs2431108 and chr3 rs62264767, were absent by ID. The separately requested AlphaGenome-prioritized **rs62264764** was also absent. Missingness in this LDSC-munged file does not imply absence from the original FinnGen release or a null association; the file is filtered and contains no coordinates.

The file name and a [historical source lock](historical_source_lock.json) point to FinnGen R13 F5_ADHD, but the raw input and ingest receipt were not found. The lock and a [historical audit](historical_source_audit.md) record a purported source generation, checksum and sample counts; they do **not** link those bytes to this derived file. Its own compressed SHA-256 is recorded in the [receipt](receipt.json). The only available candidate match is by ID and alleles, without a coordinate, effect size, standard error, imputation quality or raw-source verification. The [N audit](global_rerun/n_scale/RESULTS.md) found that the constant N matches an effective-sample-size formula applied to the historical case and control counts; the original file construction and counts remain unverified. The p-value assumes a signed, standard-normal Z as indicated by the file format. It is weak and cannot establish the sign of a true effect. A six-marker p×6 descriptive benchmark for that row is 1; five unavailable rows remain in the family. This is not an independent clinical replication or a two-trait result.

The earlier project audit claimed nonoverlap based on published cohort descriptions, but participant identity and relatedness were not independently checked. Exact ancestry, source version, source consent/terms, phenotype, data processing and cohort overlap must be verified with an authoritative raw release and ingest record before using this file for replication. The original six-lead list and its alleles are documented [here](../six_lead_joint/RESULTS.md). Neither local-correlation QC nor the chromosome 5 colocalization is altered.

The [protocol](PROTOCOL.md), [scan](lookup.py), [all six rows and statuses](results.tsv), and [receipt](receipt.json) reproduce this post-selected source-coverage check. The full gzip was streamed to completion with no malformed rows; source hash identity authenticates only this archived copy, not the publisher origin.

A [global LDSC rerun](global_rerun/RESULTS.md) reproduced an archived insomnia–ADHD correlation to the displayed r_g and SE precision, but the upstream ADHD source and cohort overlap remain unverified.

A later [systematic source-concordance check](source_concordance/RESULTS.md) matched 1,155 of 1,157 sampled archived rows to public FinnGen R13 and found beta/SE agreement to numerical precision. This supports the association-statistic lineage, but the original ingest and cohort independence remain unverified.
