# Archived insomnia–ADHD global correlation: rerun and provenance limits

A fresh LDSC calculation using the archived Brain6 insomnia input and a file labeled FinnGen R13 F5_ADHD gives **genetic correlation r_g=0.3817, SE=0.0521, p=2.3282×10⁻¹³**. It matches the historical Track B aggregate's r_g and SE to four decimals; its historical p was 2.3274296×10⁻¹³, slightly different. The historical aggregate records ADHD-side LDSC h² output=0.1892 (SE 0.0238), whereas this cross-trait run prints **0.1904 (SE 0.0250)**. The old underlying log and h² analysis are unavailable, so the reason for these differences is not established. The old record's categorical `DIRECTIONAL_REPLICATION` is an archived project label, not an independently verified conclusion of this audit.

The rerun merged **1,108,865** SNPs with valid alleles. Its phenotype-2 h²/SE is approximately 7.6, but the phenotype-2 intercept is 1.0469 (SE 0.0076) and LDSC's intercept ratio is 0.3583 (SE 0.0578). These statistics merit review of input calibration, ancestry, phenotype and model assumptions; they do not by themselves identify the cause or prove the correlation is biased. The cross-trait intercept was −0.0067 (SE 0.0049); a near-zero estimate is not proof of no participant or relative overlap. Although LDSC labels its output observed scale, the encoded N matches an effective-sample-size formula; the numerical h² is scale-dependent and is not validated as observed- or liability-scale disease heritability. See the [sample-size sensitivity](n_scale/RESULTS.md). A compression warning appeared while reading the files; the run completed and reports the input counts.

The historical record lists FinnGen register ADHD and claims no identified direct participant overlap with the discovery ADHD study. The public raw release has since been streamed and [1,155 sampled archived Z scores match its beta/SE](../source_concordance/RESULTS.md), but the original ingest receipt is still missing. The derived file's label, the separate historical source lock and its hash do not authenticate its publisher provenance or demonstrate how alleles and Z statistics were processed. The same discovery insomnia GWAS is used in both the historical and current calculations, so even a verified external ADHD source would provide an ADHD-side follow-up of a global correlation, not fully independent two-trait replication. Finnish ancestry, reference LD fit, clinical ascertainment and study overlap also need verification. This is not a locus-specific replication, a causal finding, or a repair of the failed LAVA quality gates.

[Protocol](PROTOCOL.md), [run script](run.sh), [LDSC log](insomnia_adhd.log), [console log](console.log), [historical summary](historical_summary.tsv), and [verification receipt](receipt.json) document the comparison. Sixty-four shared input, code and reference files match the earlier original-pair rerun's hashes; the ADHD-derived file's own hash is recorded, but its unverified upstream source and the old run's exact bytes remain limitations. The comparison was made after the old result was visible and no broad-family multiple-testing claim is made.

A [standalone h² recheck](single_trait/RESULTS.md) matches the historical h² and SE at displayed precision. An [explicit two-step cross-trait sensitivity](two_step/RESULTS.md) changes r_g slightly; marker support and estimation settings both differ across the h² calculations.
