# Concordance of archived ADHD Z scores and public FinnGen R13

A systematic sample provides strong **numerical consistency** between the archived file labeled FinnGen ADHD and the pinned public R13 F5_ADHD release. Of 1,157 processed rows selected by taking every 1,000th row starting at row 500, **1,155** had a unique exact rsID and nonpalindromic allele-pair match in the public source; two had the same rsID but their allele pairs differed by strand complement under the strict direct-pair rule.

For all 1,155 matched rows, the processed Z agreed with the public beta/SE, aligned to the processed effect allele, to within 5.0 × 10⁻¹² in absolute value. The median absolute difference was 3.5 × 10⁻¹³. A signed Z reconstructed from the source p-value also agreed within 1.4 × 10⁻⁵ for all matched rows; p-value rounding and test construction can affect that comparison. This supports the archived Z column's consistency with the public release much more strongly than the earlier single-marker check.

The input sample was drawn from an already filtered, ordered munged file; it is not a random sample of all source variants. The check does **not** locate the original ingest script or prove that every processed row, N value, allele, endpoint annotation or source version was generated correctly. It does not establish participant or relative independence, validate LDSC reference fit, verify an observed-scale heritability, establish a causal locus or repair the local-correlation QC gates. A source-compatible association-statistic file is not a complete provenance chain.

## Audit trail

The [pre-comparison protocol](PROTOCOL.md), [selection](select.py), [sample](sample.tsv), [selection receipt](selection_receipt.json), [streaming scan](scan.py), [raw matches](raw_matches.tsv), [comparison code](compare.py), [per-row comparison](comparison.tsv) and [summary receipt](comparison_receipt.json) preserve the check. The archived compressed input matched its previously recorded SHA-256. The entire public source stream completed as a `curl | gzip -dc | scan.py` pipeline with `pipefail` and exit status 0, reporting 21,326,959 data rows and 1,159 records containing sampled IDs; gzip successfully checked its concatenated members. The same pinned source object was separately [hashed in full](../../finngen_adhd_raw_lookup/whole_source_hash_receipt.json), matching its historical size and MD5. We did not retain the full public file. The two strict-pair failures are rs9424932 and rs2734078. A later [strand-complement sensitivity](strand_sensitivity.tsv) found a unique rsID and complement-compatible pair for each, with aligned beta/SE matching the processed Z within 2.2 × 10⁻¹². Together with the 1,155 strict matches, all 1,157 sampled rows have numerically consistent direct or complement-compatible records. This post-hoc check cannot prove identity because the archived file has no coordinates; the [code](strand_sensitivity.py) and [receipt](strand_sensitivity_receipt.json) preserve the distinction.

The [global LDSC recheck](../global_rerun/RESULTS.md) remains a same-insomnia-input analysis with unresolved source-processing, sample overlap and LD-score assumptions. It is ADHD-side follow-up, not fully independent two-trait replication.
