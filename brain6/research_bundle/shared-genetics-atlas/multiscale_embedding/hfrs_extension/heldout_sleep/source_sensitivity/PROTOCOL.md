# Source-related row-exclusion sensitivity

Prepared after the 12-trait held-out-sleep results were inspected. Re-run the identical six-feature ridge model and nested leave-one-training-row-out tuning twice: (1) exclude `longsleep` altogether because its source/model semantics remain unresolved; (2) separately exclude `sleep_apnea` because the apnea and HFRS sources involve overlapping FinnGen releases. In each scenario, evaluate only the other 11 sleep traits, holding each one's three frailty values out of training. For each target, compare with the prior full-model predictions for those same 11 outer test rows and with the new training-mean baseline. Use the same λ grid, within-inner-fold preprocessing, and larger-λ tie rule as the original. Save all per-row predictions, chosen λ and paired RMSE/MAE; verify source hashes and nested calculations. The omitted trait is not a test target in its own exclusion scenario.

This is a post-hoc stability experiment with ten training traits in each outer fold, not proof that removing a row resolves the scientific uncertainty. Omitting apnea does not eliminate all shared cohorts, and removing long sleep does not verify remaining sources, full support, ancestry or phenotype definitions. Cross-trait errors remain dependent; no independent-cohort performance, causal inference, multiple-testing or formal generalization claim is made. No AlphaGenome outputs are used as features.
