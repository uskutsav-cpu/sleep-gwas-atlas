# Training-group deletion sensitivity

For the existing post-hoc held-out-sleep-group ridge model, test how dependent each prediction is on individual remaining training groups. Use the frozen 12×9 matrix, six existing brain-trait r_g features, the same 8 group definitions, and the same grid {0.1, 1, 10, 100}. For each held-out group, target and remaining training group, drop that entire training group, reselect lambda using inner leave-one-training-group-out cross-validation with fold-specific feature standardization, then predict all rows of the held-out group. Compare each prediction against the frozen full-training group-held-out prediction and observed value. Store all deletions, per-prediction ranges, and largest absolute shift. This is a descriptive post-hoc stability diagnostic: the deletion fits overlap, groups differ in size, and the analysis does not estimate a confidence interval, independent-cohort performance, causal feature importance or an intervention effect. No AlphaGenome data are model inputs.
