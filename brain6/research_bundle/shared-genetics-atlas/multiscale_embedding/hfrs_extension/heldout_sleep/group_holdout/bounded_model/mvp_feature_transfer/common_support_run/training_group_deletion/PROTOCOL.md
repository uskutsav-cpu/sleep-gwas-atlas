# Clinical-insomnia transfer: training-group deletion sensitivity

Before computing the refits, keep the previously used MVP common-support disease correlations and three observed outcomes fixed. Exclude the original questionnaire-insomnia group from training in every fit. In turn remove one other related sleep-measure group, retune ridge lambda using the existing inner group-held-out procedure and refit the bounded model on the remaining groups. Report all target-specific predictions, change from the earlier full-training prediction, chosen lambdas and absolute errors against the already inspected MVP target estimates; do not select or promote a model based on these outcomes. The seven refits overlap strongly and are not independent replications. Their spread is a training-set stability diagnostic, not a confidence interval or causal influence estimate. Group deletion changes sample size, feature normalization, cross-validation and lambda selection; incomplete cohort separation, heterogeneous source supports, unclear overlap, elevated intercepts, and symptom-containing frailty remain. No AlphaGenome outputs enter training.
