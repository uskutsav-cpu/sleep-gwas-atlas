# Bounded correlation model: post-hoc comparator

Compare a Fisher-transform ridge model with the frozen training-mean, kNN and unbounded ridge group-held-out predictions on the same 12 sleep rows and three frailty targets. For each outer sleep group, train on the other groups, transform each training outcome with atanh and predict on that scale, then apply tanh to return values in (−1,1). Select lambda from {0.1,1,10,100} using inner leave-one-training-group-out mean squared error on the original correlation scale; refit feature standardization within each fold and break exact ties toward stronger regularization. No arbitrary clipping is needed for observed inputs, which must all be strictly within (−1,1). Compare pooled and per-target RMSE and MAE, reporting all predictions and range violations. This model and its evaluation are post-hoc on previously inspected non-independent cohorts. Bounding is a mathematical constraint, not statistical calibration, independent validation, a causal model or individual risk prediction. Do not use AlphaGenome data as inputs.
