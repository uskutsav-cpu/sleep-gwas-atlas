# Bounded model training-group sensitivity

Use the frozen data, grouping and Fisher-transformed ridge model from the earlier bounded comparison. For each of eight outer held-out sleep groups, remove one whole group from the remaining training data, reselect regularization by inner group-held-out mean squared error on the correlation scale, and predict the held-out group. Compare against the stored bounded full-training prediction, and report all 252 deletion predictions, sign changes and per-cell ranges. Use the same deletion groups as the unbounded comparison. This post-hoc diagnostic combines changes in training sample and selected regularization; groups differ in size and share GWAS cohorts. It is not a confidence interval, causal importance test, or independent validation. Verify the calculations with an independent least-squares implementation. Do not use AlphaGenome outputs for training.
