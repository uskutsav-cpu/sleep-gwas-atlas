# Nine-input common-marker feasibility

The six archived disease-feature GWAS and three frailty-target GWAS share **1,018,491 rsIDs** with finite Z, positive N and matching non-palindromic allele pairs after the audit's filtering. All nine compressed input hashes matched their earlier recorded receipts; all nine gzip streams were read to completion. The three frailty inputs began with 1,134,953 compatible rows, and the intersection narrowed as the disease files were added. Counts and exclusions are in the [receipt](receipt.json).

This is an **upper bound** for a subsequent common-marker LDSC analysis. It does not include an intersection with the MVP insomnia stream or the LD-score reference, and it does not test whether the different SNP sets changed the earlier model predictions. A proper assessment would apply the same vetted marker set to all six feature pairs and three target pairs, rerun LDSC with appropriate diagnostics, and compare the resulting predictions using a fixed model. It would still require attention to reused sources, unknown overlap, differing cohort ancestry, approximate per-variant sample sizes and source uncertainty. Equal marker support alone cannot establish independent validation or make a causal claim.

The [pre-run protocol](PROTOCOL.md) and [audit code](audit.py) define the matching. Allele pairs were accepted after strand complement or orientation swap, palindromic pairs were excluded, and repeated source IDs were excluded from the final intersection. Hashes establish identity with earlier project inputs, not upstream provenance. The scan created no large intermediate files. The MVP stream and reference were not reprocessed in this audit.
