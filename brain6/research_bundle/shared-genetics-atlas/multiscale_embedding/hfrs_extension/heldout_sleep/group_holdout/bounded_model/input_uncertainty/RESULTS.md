# Input-uncertainty stress test for bounded ridge predictions

The bounded model can be sensitive to plausible changes in its six input genetic-correlation estimates. Holding each fitted model fixed and allowing each held-out input to vary within its reported estimate ± one standard error gave a **hypothetical prediction range from −0.364 to +0.170** for sleep timing against hospital frailty. Its point prediction was −0.105. This was the widest of the 36 selected sleep–frailty cells, identified after inspecting the data.

Eleven of the 36 simultaneous one-SE input boxes included predictions on both sides of zero. Median prediction-range widths were 0.208 for FI, 0.149 for FFS and 0.209 for HFRS. All six-input box endpoints remained inside [−1,1] for the selected rows. These are dependent, post-hoc stress ranges: allowing all inputs to reach their extremes together is not equivalent to a confidence interval, a calibrated probability or a likely joint realization. The analysis does not use the unknown covariance among the original GWAS estimates, or include uncertainty in training data, fitted coefficients or lambda selection. It cannot establish that a prediction's sign is truly uncertain at a specified confidence level.

The calculation reconstructs each stored group-held-out model with the previously selected lambda and changes only that held-out row's six inputs. The analytic box extrema were checked against enumeration of all 64 corners for each row (maximum absolute discrepancy 2.22×10⁻¹⁶), and all 36 baseline predictions were reproduced. See the [protocol](PROTOCOL.md), [all ranges](ranges.tsv), [code](run.py) and [input receipt](receipt.json). The input standard errors and source identities are inherited from the saved heterogeneous matrix; different sample overlap, ancestry, SNP support and unresolved trait coding remain. No AlphaGenome outputs were used for training. The earlier [training-group deletion](../training_group_sensitivity/RESULTS.md) addresses a different sensitivity and cannot be combined with these ranges into a confidence interval.
