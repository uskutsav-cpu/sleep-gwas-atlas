# Bounded ridge model: exploratory comparison

A Fisher-transform ridge model returned predictions strictly between −1 and 1 by construction. In the same 36 post-hoc group-held-out cells, pooled RMSE was **0.1031**, compared with **0.1108** for the existing unbounded ridge, **0.1684** for three-nearest-neighbor and **0.2639** for the training mean. Per-target bounded versus unbounded ridge RMSE was 0.0796 versus 0.0908 (FI), 0.1390 versus 0.1494 (FFS), and 0.0786 versus 0.0792 (HFRS). These are descriptive results on previously inspected, dependent data, not a confirmed improvement or independent validation. All four models happened to produce in-range predictions in the original 36 outer tests; the bounded model guarantees the range on future finite inputs but does not guarantee accuracy.

Each fit transforms the training target with atanh, fits ridge regression, and transforms predictions back with tanh. Nested group-held-out lambda selection minimizes squared error on the original correlation scale; the lambda grid and training-only feature normalization match the prior model. The [protocol](PROTOCOL.md), [36 predictions](predictions.tsv), [summary](summary.tsv), [script](run.py) and [input hashes](receipt.json) document the comparison. An independent augmented least-squares implementation reproduced all 36 nested predictions with a maximum absolute difference of 8.33×10⁻¹⁶ ([verification](verification.json)). No AlphaGenome data were used for training.

The analysis uses only 12 related sleep measures, with overlapping cohorts and six observed sleep–brain r_g features needed at inference. It does not model source-estimate uncertainty or covariance, resolve long-sleep coding, test causality or predict individual outcomes. A subsequent [bounded training-group sensitivity](training_group_sensitivity/RESULTS.md) shows substantial instability remains despite the mathematical bound. Independent, prespecified cohort-level validation is still needed.
