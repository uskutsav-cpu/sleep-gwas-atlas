# Clinical-insomnia model: common-marker sensitivity

All six clinical-insomnia–disease features and all three frailty targets were re-estimated by LDSC on the same **991,707** matched, non-palindromic SNPs. The existing bounded ridge model was then applied using its previously selected training rows and hyperparameters; the MVP outcomes were not used to tune it.

| Outcome | Common-marker prediction | Common-marker observed r_g (SE) | Absolute difference | Earlier different-support prediction / observed r_g |
| --- | ---: | ---: | ---: | ---: |
| Frailty index | 0.654 | 0.543 (0.038) | 0.112 | 0.659 / 0.553 |
| Fried frailty score | 0.608 | 0.395 (0.035) | 0.213 | 0.607 / 0.400 |
| Hospital frailty risk score | 0.535 | 0.577 (0.035) | 0.041 | 0.522 / 0.570 |

The FFS gap persists on shared SNP support. This is a descriptive sensitivity, not a significance test or a fully independent evaluation: outcome and feature estimates have uncertainty and unknown covariance, the outcomes were already inspected, and the model's training rows use earlier correlations estimated on different and variable supports. Shared SNPs do not establish shared participants or independent cohorts. The common-set selection can change the estimand and LDSC behavior; the comparison does not identify a single reason for prediction error. The three-nearest-neighbor and training-mean baselines are included in the [prediction table](predictions.tsv), but three dependent targets cannot establish a general model ranking.

The [six common-marker features](features.tsv) ranged from 0.5623 for depression to −0.0200 for Parkinson's. The MVP univariate intercept was 1.1358 (SE 0.0109), HFRS 1.1895 (0.0149), and schizophrenia 1.0967 (0.0176); elevated intercepts caution against treating the estimates as fully calibrated. Several other h² ratios were negative, which LDSC says usually indicates genomic control. These diagnostics do not identify causes. Source cohort and relatedness overlap, phenotype and sample-size semantics, MVP p-derived Z and rounded odds-ratio direction, and the general-European LD reference remain important limitations. FI includes sleep and tiredness, FFS includes exhaustion, and HFRS includes a somnolence-related code; this is not a sleep- and exhaustion-excluded frailty analysis. No AlphaGenome output was used for model training.

The [pre-run protocol](PROTOCOL.md), [first-stage intersection](step1.py), [clinical-insomnia and reference matching](step2.py), [matching receipt](prepared_receipt.json), [LDSC runner](run_ldsc.sh), [full log](ldsc-20261029T055926-2702.log) and [prediction code](predict.py) preserve the procedure. The completed MVP stream receipt matched the prior source audit. An independent [verification](input_verification.json) read all ten matched files through gzip completion and confirmed identical ordered marker and allele-pair signatures and matching hashes; LDSC retained 991,707 valid-allele SNPs for every pair. The prediction code reproduces the saved questionnaire-insomnia predictions before calculating the new ones. These checks verify computation and matching, not upstream cohort independence, model calibration, clinical utility or causality.
