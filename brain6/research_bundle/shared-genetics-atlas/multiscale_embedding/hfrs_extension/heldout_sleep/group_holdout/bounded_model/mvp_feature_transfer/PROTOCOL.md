# MVP-specific disease-correlation features: post-hoc transfer experiment

Before estimating MVP feature correlations, pair the audited MVP insomnia stream with the six archived disease GWAS used as model features (ADHD, MDD, schizophrenia, bipolar disorder, Alzheimer's disease and Parkinson's disease) using the project's unconstrained European-reference LDSC. Record full compressed hashes, stream completion and diagnostics. Reuse the previously specified group-held-out, nested-tuned bounded-ridge training algorithm and remove the original questionnaire-insomnia group from all training and tuning. Supply the six new MVP–disease correlations as features; compare all three resulting frailty predictions with the already computed MVP–FI/FFS/HFRS correlations and the corresponding training-mean and three-nearest-neighbor baselines. Retain all outputs even if weak or failed, and do not select or tune the model on these MVP outcomes. Compare to the saved questionnaire-feature proxy descriptively only. The features and outcomes use partly different per-trait markers and are noisy LDSC estimates; input uncertainty, covariance, overlap, LD reference fit, archived source lineage and participant independence remain unresolved. This is a post-hoc source-transfer experiment, not independent cohort validation, individual prediction or causality. No AlphaGenome output is used as a training feature.
