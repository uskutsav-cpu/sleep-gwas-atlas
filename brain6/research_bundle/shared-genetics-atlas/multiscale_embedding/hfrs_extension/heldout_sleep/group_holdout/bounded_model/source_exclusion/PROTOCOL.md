# Bounded grouped-holdout source exclusion

Post-hoc sensitivity, using the frozen 12×9 matrix and the existing bounded Fisher-transform ridge specification. Repeat the complete nested, grouped-holdout evaluation after removing long sleep from both training and testing, because its released-model and per-variant sample-size mapping are unresolved. Separately repeat after removing FinnGen sleep apnea, whose source overlaps the hospital-frailty cohort. Each scenario has 11 test traits and three outcomes; preserve the original grouping of other related measures. For each test group, select ridge lambda using inner group-held-out squared error on the r scale and train-only standardization. Compare against the original bounded model's predictions on the same 33 cells and against the training-mean baseline refit on the exclusion data. Report per-target and pooled RMSE and all predictions. Source removal also reduces training data, can alter group sizes and changes model selection; it does not isolate the cause of any performance difference or resolve source overlap among the remaining inputs. The splits and exclusions are post hoc, the matrix is tiny and dependent, and this is not external validation, a calibrated significance test or an individual-risk model. No AlphaGenome outputs are used for training.
