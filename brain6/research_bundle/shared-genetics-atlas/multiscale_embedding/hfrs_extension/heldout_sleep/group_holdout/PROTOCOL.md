# Leave-related-sleep-measure group out: model stress test

Post hoc extension after inspecting the earlier leave-one-sleep-trait-out results. Use the same 12×9 input matrix and same six known brain correlation features and three frailty targets. Define groups before running: self-reported sleep duration, short sleep and long sleep from Dashti 2019 form one group; sleep efficiency, accelerometer sleep duration and sleep timing from Jones accelerometer measurements form another. Each remaining sleep trait is a singleton group. This grouping removes obvious related-measure leakage; UK Biobank participants and cohorts also overlap across different groups, so it is not an independent-cohort split.

For each group, hold out all its rows and all three frailty outcomes together. Fit three independent ridge models from remaining groups, using only training-row feature means/SDs; select λ separately for each target by inner leave-one-training-group-out pooled squared error across its held-out rows, with grid {0.1,1,10,100} and exact ties favoring larger λ. Refit standardization in every inner fold. Compare the training-outcome mean and equal-weight three-nearest-neighbor baselines, where distances use outer-training standardization. Evaluate every held-out row exactly once, preserve per-row predictions and inner grid scores, report per-target and pooled RMSE and MAE, and compare against the prior leave-one-row-out predictions on exactly the same 36 rows. This is an observational comparison of two splitting strategies, not a paired significance test or held-out sample validation. The groups are chosen post hoc and source metadata and covariance are incomplete. Outcome and feature samples overlap and six known brain r_g values are needed for every test row; no individual risk prediction, disease interaction or independent replication follows. The study-specific long-sleep semantics and HFRS intercept caveats remain. Preserve input hashes and provide an independent arithmetic check.
