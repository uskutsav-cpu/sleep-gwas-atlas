# Exploratory 12×9 sleep–brain–frailty embedding including HFRS

Prepared before fitting this extension. Assemble the existing 12×8 matrix from `source_matrix.tsv` and the 12 admitted sleep–HFRS associations in `NEW_VALIDATION_FAMILY_RESULTS.tsv`. Require exactly one HFRS row per sleep trait, matching recorded sleep-source dataset version and sample size against `sleep_source_crosswalk.tsv`; preserve matched metadata and uncertainty. This metadata match does not establish byte identity of the original GWAS inputs, equivalent support or ancestry, nonoverlapping samples, source-model validity, or compatibility across the LDSC analyses. Brain6 values are rounded, FI/FFS values use pair-specific matched support, and HFRS values come from separate source-specific runs. FinnGen apnea and FinnGen HFRS overlap; exact overlap elsewhere is unresolved. The long-sleep modeling caveat remains. No AlphaGenome outputs are included.

Fit a two-dimensional unweighted SVD for descriptive in-sample reconstruction, without explaining biological variance. Separately use a fixed seed to generate ten repetitions of five-fold cell masking over all 108 entries, requiring at least three training cells in every row and column. On each fold compare (1) the training mean for each outcome, (2) an additive sleep-plus-outcome least-squares model and (3) rank-two ridge alternating least squares with five predetermined random initializations, selecting only by observed-training SSE plus penalty. Use 100 iterations and penalty 0.02 as in the previous stability analysis. Save every mask, prediction, training objective, per-outcome and pooled RMSE, and out-of-range predictions. No data from a held-out cell are used to select initialization; however, hyperparameters and this model family were informed by previous work, and a new matrix and new masks make this post-hoc. The ten repetitions reuse the same observed estimates and are not independent studies. Sleep and outcome identities appear in train and test, so this evaluates entry reconstruction, not prediction for unseen traits, people or independent cohorts.

No AlphaGenome feature or output trains the model. Preserve all input hashes, software versions, source matches and exclusions. Compare the HFRS column and the three baselines; do not select a best model based on pooled RMSE as validated or claim trait-axis proximity proves a biological pathway. Measurement-error covariance, source overlap, local-region holdout and external cohort tests remain open.
