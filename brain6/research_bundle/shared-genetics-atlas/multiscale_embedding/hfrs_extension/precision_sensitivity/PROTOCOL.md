# Precision-weighted embedding sensitivity

Prepared after inspecting the unweighted 12×9 results; reuse those exact 50 saved masks for a paired, post-hoc comparison. Fit a weighted two-component ridge factorization, weighted additive sleep-plus-outcome model and weighted outcome-column means to the observed training cells only. For each fold, define weights as `(median training SE / cell SE)^2`, clipped to [0.25, 4] using that fold's training SE median; do not use held-out effect values or their SEs in fitting. The cap is a sensitivity choice, not an optimal rule. Use five predetermined factorization initializations, 100 iterations and ridge 0.02; select the smallest weighted training SSE plus ridge penalty only. Compare to the prior unweighted three predictions on the identical masks.

Report ordinary pooled and per-outcome RMSE and the descriptive root mean squared prediction error divided by each held-out SE. The standardized metric uses test SEs only for evaluation; it is not a chi-square test, likelihood, calibrated uncertainty estimate or correction for dependence. All SEs come from heterogeneous LDSC analyses, and this diagonal weighting ignores shared-cohort, cross-trait and block-jackknife covariance. The very small matrix, repeated dependent masks, post-hoc design, source/support mismatch and unresolved long-sleep model mean no result demonstrates transfer to unseen traits or people, causal interactions or biological pathways. Do not include AlphaGenome outputs as inputs. Preserve masks, weights, predictions, selected training objectives, source hashes and full evaluation results.

After an initial run used different initialization seeds from the unweighted model, the final comparison was rerun with the same five seeds for each matched fold. This post-hoc refinement controls initialization as well as the masks; results remain exploratory.
