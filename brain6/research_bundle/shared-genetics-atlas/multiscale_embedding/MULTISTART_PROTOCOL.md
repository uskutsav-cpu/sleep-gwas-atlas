# Post-hoc multi-start stability check

Written after the original masked-cell results and subgroup error audit were observed. Reuse the exact 50 saved train/test masks, original 96 cells and the same rank-two ridge objective (lambda 0.02 and 100 ALS updates). For each split fit five fixed deterministic initializations, and select the one with the smallest training objective: observed training squared error plus ridge penalties on both factor matrices. Do not use held-out outcomes for selection. Evaluate the selected model on the existing held-out cells, with the original mean and additive predictions as saved, using RMSE and counts outside [−1,1]. This is an exploratory stability check, not a new independently designed evaluation; test sets, baselines and model family were already observed and the 96 source estimates and repeated folds are dependent. These nonconvex fits still may not find a global optimum and do not enforce valid correlation matrices. Check seed/configuration and save all initialization training objectives and predictions. No AlphaGenome output is used.
