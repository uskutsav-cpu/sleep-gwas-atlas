# Code availability

The Brain6 extension is under `extensions/brain6/`; its implementation and synthetic/software tests are documented in `extensions/brain6/README.md` and `extensions/brain6/docs/IMPLEMENTATION_STATUS.md`. The current global extraction and follow-up manifest scripts are under `brain6/scripts/`. The extraction reuses the immutable atlas tables and fails if the expected 12×6 pair family or inherited FDR values do not match. No external repository or public software release was created by this run.
