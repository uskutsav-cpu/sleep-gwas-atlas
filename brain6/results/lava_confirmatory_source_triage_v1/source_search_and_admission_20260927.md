## Gate implication and next source needs

No four-trait, scientifically admitted replacement set exists in this search ledger. Long sleep remains the largest unresolved contributor (1,291 cells), followed by insomnia (671), Parkinson disease (636), and MDD (589). **Even perfect repair of all six other traits leaves long sleep's 1,291 `NOT_RUN`, which exceeds the 873-cell ceiling by 418.** A valid long-sleep repair is therefore necessary; the currently inspected alternatives do not provide one. This does **not** prove that the frozen gate is mathematically impossible with all available data; it means a complete rescue launch is not yet justified. Search should continue for a phenotype-compatible long-sleep source with materially stronger case information and auditable `N`; for insomnia, a dense public or authorized comparable contrast with a valid LAVA input model; for Parkinson, EUR-stratum variant-level sample-size/ascertainment data; and for MDD, a validated effective-N/case-fraction interpretation. Any changed pair also needs a new overlap matrix. Preserve every existing canonical, v2, roundoff and pilot receipt.
