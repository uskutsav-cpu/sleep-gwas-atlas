# Dashti long-sleep original release: model and LAVA admission check

**Scope:** source and method review only, completed before any repaired full-family outcome. This record does not modify the frozen LAVA v3 run, its 5% family gate, or any candidate call.

## Verified source facts

- Original study: Dashti et al., *Nature Communications* 10:1100 (2019), DOI [10.1038/s41467-019-08917-4](https://doi.org/10.1038/s41467-019-08917-4). The [full article XML](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC6405943/fullTextXML) was retrieved on 2026-09-27, SHA-256 `9a900edf6498ed302e6cec5fe4fea902c1ad99698ec0b992a7878052b4821818`.
- Phenotype: at least 9 hours of self-reported sleep versus 7–8 hours. The study reports 34,184 cases and 305,742 controls of European ancestry for this contrast, 339,926 participants combined.
- The article's genome-wide association methods use BOLT-LMM linear mixed models in related European-ancestry participants. It describes adjusted PLINK logistic regression in an unrelated white British subset for odds-ratio estimates. The released long-sleep archive has `BETA_LONGSLEEP`, `SE_LONGSLEEP`, and `P_LONGSLEEP`, not odds ratios or per-variant `N`/case/control counts. Its header and a first row were inspected; this is consistent with the main association release, but the release README does **not** explicitly identify which association model produced those columns.
- The [project download page](https://www.kp4cd.org/node/235) links the [original release README](https://s3.amazonaws.com/broad-portal-resources/sleep/Saxena_fullUKBB_Longsleep_summary_stats_README), saved byte-for-byte in `source_docs/Saxena_fullUKBB_Longsleep_summary_stats_README` with SHA-256 `ec79d6599ad8ec0353c2d8476bd182e512b5a333519c5b6d9263bf2a9e9df0aa`. It identifies GRCh37, effect allele, effect-allele frequency, imputation INFO, and association fields; it supplies no `N` field or model definition.
- The previously downloaded original `longsumstats.txt.zip` remains at `/Volumes/Extreme SSD/brain6-work/atlas-raw/.archives/longsumstats.txt.zip`, SHA-256 `0afd9a3ccf459d283f1b6eb6a8b8b0780f54d9d634a05f816be31171a42ec885` (verified again on 2026-09-27).
- A [source-only effect-scale audit](longsleep_effect_scale_v1/effect_scale_summary.json) used the first 1,000 variants with INFO at least 0.9 and finite frequency/SE, without reading effects or association P values. Their median observed-to-simple-linear SE ratio was 0.9942; the corresponding observed-to-simple-logistic ratio was 0.0899. This strongly supports linear-scale released effects, consistent with the paper's primary BOLT-LMM analysis. The simple formulas do not account for relatedness or covariates and cannot alone admit a LAVA input model.
- A later [coauthored sleepiness study](https://www.nature.com/articles/s41467-019-11456-7) explicitly describes the publicly available long-sleep genome-wide summary statistics, citing Dashti et al., as BOLT-LMM results. This corroborates the source model independently of the generic release README; it does not supply per-variant analyzed `N`.
- A [genome-wide source-only SE audit](longsleep_se_stability_v1.json) scanned all 14,661,601 original rows. Among 7,015,021 autosomal rows with MAF at least 0.01, INFO at least 0.95, and finite positive SE, a deterministic every-100th-row sample of 70,150 had median observed-to-simple-linear SE ratio 0.99382 (5th–95th percentile 0.99110–0.99566). All 22 chromosome medians were between 0.99356 and 0.99420, and none of the sampled ratios fell outside 0.9–1.1. The scan accessed frequency, INFO, SE, and chromosome, not beta or association P. This is strong evidence for a stable linear-model *scale* in high-quality variants, not an observed per-SNP `N` or proof that all variants used 339,926 participants.

## Consequence for a confirmatory repair

The atlas harmonizer placed a fixed balanced-equivalent effective `N = 122,985.408918` in this trait's LAVA sumstats, calculated from the study-wide case and control counts. Its LAVA input-info file supplies the observed case fraction `34,184 / 339,926`. The pinned LAVA binary routine interprets each SNP's `N` jointly with that fraction as a reconstructed case-control cohort. These are different sample-size representations. The [receipt-bound crosswalk](../lava_binary_n_crosswalk_v1/binary_n_crosswalk.tsv) documents the exact canonical input and code hashes.

Using 339,926 for every SNP would also require evidence about analyzed per-variant samples; the publication permits SNP missingness, and the public release has no variant-specific count. The study's main BOLT-LMM statistic raises a separate question: whether LAVA's marginal binary-statistic reconstruction adequately represents this association test. [LAVA 0.1.5's update history](https://github.com/josefin-werme/LAVA/blob/main/UPDATES.md) says its **univariate** binary test changed from logistic regression to a linear probability model; that does not remove the preceding `process.binary` conversion, which reconstructs SNP correlations from the reported statistic, `N`, and case fraction. The paper's PLINK odds ratios are sensitivity estimates and are not shown by the README to be the genome-wide release. A larger `N` chosen because it clears low-local-h² failures would be outcome-driven and invalid.

**Full-family admission status: HOLD.** The publication, coauthored follow-up, and source SE audits now support the identity of the linear BOLT-LMM association model and a nearly constant high-quality-variant SE scale. Before a trait-only diagnostic pilot, explicitly freeze a method-supported LAVA mapping for a binary outcome analyzed with a linear mixed model, the fixed-`N` proxy and allowed INFO/MAF subset, and comparison arms without using any association result to choose the model. Before a full-family source admission, establish whether that proxy is sufficiently faithful to analyzed per-variant samples and whether changed-source overlap covariance can be estimated. If those conditions cannot be met, seek a documented, comparable genome-wide long-sleep source. The current public alternative search found different phenotype definitions and fewer cases; see `longsleep_source_triage_20260927.md`. The 1,291 frozen long-sleep `NOT_RUN` cells remain unresolved.
