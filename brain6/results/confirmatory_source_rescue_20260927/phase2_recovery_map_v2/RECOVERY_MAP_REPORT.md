# Frozen LAVA failure and candidate-overlap map

The canonical seven-trait family contains 17,465 planned trait-by-locus cells: 13,745 `TESTED`, 3,720 `NOT_RUN`, and 0 `FAILED`. The unchanged 5% ceiling is 873 `NOT_RUN`; at least 2,847 validated recoveries would be required. The read-only Phase 1 trait and pair burden tables retain planned counts, reasons, source GWAS, N fields, variant/reference coverage, and theoretical maxima. Perfect repair of long sleep, insomnia, and Parkinson would still leave 1,122 `NOT_RUN`; the smallest theoretical perfect-repair set also includes MDD and would leave 533. These are mathematical bounds, not predicted source or outcome recoveries.

This Phase 2 crosswalk maps all **25** protected pair-specific PLACO candidate intervals to the fixed GRCh37 LAVA blocks. The intervals overlap **47 candidate–block rows** (6 candidates touch one block, 16 touch two, and 3 touch three). In 33 overlap rows both component traits had a numeric canonical univariate `TESTED` result; 14 had at least one `NOT_RUN`. Ten of the 25 candidate intervals contain at least one such blocked overlap: insomnia–ADHD 1/6, insomnia–MDD 1/6, long sleep–schizophrenia 4/7, long sleep–bipolar 3/3, and long sleep–Parkinson 1/3. A numeric univariate pair is only a prerequisite; strict local-h² gates, sample-overlap handling, and the frozen failed family decision still prevent treating it as local correlation or a promoted candidate.

`candidate_lava_locus_overlap.tsv` retains exact block coordinates, component status/reason/*P* and both-tested flags. `candidate_recovery_summary.tsv` retains all 25 candidate IDs and the number of blocked overlapping blocks. `receipt.json` pins source and output hashes. The candidate file, LAVA reference block file, and canonical family aggregate were read without modification.
