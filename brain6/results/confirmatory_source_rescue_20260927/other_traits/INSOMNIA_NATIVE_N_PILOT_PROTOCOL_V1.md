The exact Jansen UKB-only archive is `/Volumes/Extreme SSD/brain6-work/atlas-raw/.archives/Insomnia_sumstats_Jansenetal.txt.gz` (SHA-256 `32848cd92a6324c9048cad4a804cf1546299af1d0281981c6ca43c2046a9065b`). The exact-file official CNCR README in this ledger (SHA-256 `a5e92e264da88054173fc441e05f4587a6c6134078cc12b69e7294986fcc84a0`) defines `A1` as effect allele, `OR` as its odds ratio, and `N` as per-SNP sample size, for the UKB-only 386,533 participants and GRCh37. The 10,862,567 source rows have N 366,461–386,533. The original harmonizer assigned the same effective N, 313,750.03595553286, to every binary insomnia row and did not use the native N. This is an N representation sensitivity, not a new association source.

The source README and OR field support a log-odds effect interpretation, and the primary article describes phenotype-dependent linear/logistic association. The exact regression command for this file is not documented. Per-variant case/control counts are unavailable. LAVA's binary specification will use the **fixed UKB-wide case fraction** `109402/(109402+277131)` = `0.283034048839` as an explicit approximation at each SNP. This approximation is not an assertion of variant-specific case balance. Do not propagate it into LDSC, treat it as a measured per-SNP fraction, or infer an exact liability model. The source is `ADMISSIBLE_SENSITIVITY_ONLY` for this technical pilot. Confirmatory/bivariate use requires separate model adjudication and a matched LDSC overlap covariance.

## Fixed selection and unchanged association input

The independent selection script and frozen 88-locus table/receipt in this directory select exactly two canonical `TESTED` and two `NOT_RUN` insomnia loci from each chromosome, by deterministic SHA-256 rank within each stratum. All 38 LAVA loci intersecting the 25 protected PLACO candidate intervals are excluded. Selection uses canonical status and coordinates, never canonical or source effect, SE, p value, pilot outcome, or candidate association. It is deliberately balanced by prior status, so the resulting TESTED fraction does not estimate the full 2,495-locus family.

Each pilot locus starts from its receipt-verified canonical insomnia input shard. The materializer preserves **the exact SNP identity, A1/A2 orientation, Z, row order, and row count** of that shard. It replaces only the constant N with the same SNP's literal positive integer source N. It fails the entire materialization on a missing or duplicate source rsID, mismatched chromosome/coordinate, allele mismatch, source QC regression, or Z mismatch against the source OR/SE representation. It applies no new association, allele, MAF, or INFO filter and does not optimize by pilot outcomes. Native N must be within the source-observed 366,461–386,533 range and at most 386,533. If exact numeric or identity validation fails, stop and document the failure; do not loosen it after inspection.

## Pinned execution and decision

The config pins source, README, selection table/receipt, original-shard provenance, canonical aggregate, frozen loci, reference provenance, Python materializer/runner and R runner hashes; the materialization receipt additionally pins each original and new shard and input-info file. Four workers execute disjoint 22-locus batches using the installed LAVA 0.1.5 and exact previously established roundoff symmetry patch, one BLAS/OpenMP thread per worker, seed 20260928, and canonical locus/univariate parameters (`min.K=2`, `prune.thresh=99`, `max.prop.K=0.75`, `drop.failed=TRUE`, `max.block.size=3000`, `cap.estimates=TRUE`). Strict univariate p is `<0.05/17465 = 2.86286859433152e-6`; this gate is descriptive for the pilot and is not family promotion.

The **predeclared advancement rule**, identical in form to the earlier MDD2025 trait-only technical pilot, is zero failed or missing results and either (a) an absolute increase in TESTED fraction of at least 0.10 across the same 88 loci, or (b) at least 25% relative reduction of canonical `LOW_LOCAL_H2_UNDERPOWERED` NOT_RUN cells. If the canonical low-h2 count is zero, condition (b) cannot pass. Passing authorizes only discussion of a **separately predeclared complete 2,495-locus insomnia trait-only sensitivity screen**, with no canonical or family promotion. A failed criterion means no advancement from this pilot. The 873-cell gate, 25 candidates, and 20 regions remain unchanged regardless of pilot output.
