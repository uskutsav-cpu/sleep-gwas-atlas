## Null and test definitions

With seed 20260928, draw one eligible null window **independently with uniform probability for each of the 18 regions**. Reject the entire draw when any two sampled windows overlap on the same chromosome. Continue until 10,000 accepted replicates, or stop after 200,000 attempts and issue no p-values. An accepted null therefore has one exact-width matched window per included region, with within-replicate nonoverlap. All tests use the same accepted null draws.

For each tissue, sum the 18 region-level mean gene tissue-specificity scores (zero for an interval without a GTEx-mapped gene). For each pathway, count the 18 regions with at least one positional gene in the pathway. The one-sided high-tail empirical p-value is `(1 + #null statistic >= candidate statistic) / 10001`. Apply Benjamini–Hochberg separately across all 54 tissues and all 1,680 pathways; `q < 0.05` is the descriptive exploratory threshold. Report all tests, including zero-hit pathways, with observed statistic, extreme-null count, p, and q. No source, subset, cutoff, or direction can be changed after viewing results.

These p-values, if the joint-null gate passes, describe the **feasibility-defined 18-region subset only**. The two omitted regions are nonrandom with respect to positional gene density and tested variant density, so 18-region results cannot be extrapolated to the original 20, all PLACO hits, or genome-wide biology. Bulk tissues are not cell types. No regulatory-feature enrichment or causal-gene conclusion is possible from this branch.
