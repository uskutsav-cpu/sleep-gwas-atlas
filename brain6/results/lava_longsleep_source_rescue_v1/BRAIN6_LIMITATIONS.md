# Limitations and unresolved assumptions

1. The exact public Dashti file has no per-variant analyzed N or case/control count. The primary methods and coauthored paper support BOLT-LMM, but no located export manifest binds each released statistic to an exact command/transform. The archive permits up to 10% per-SNP missingness; total study N cannot automatically be assigned to every variant.
2. LAVA's binary branch reconstructs logistic statistics from supplied Z, N, and case fraction. A BOLT-LMM binary-trait output is not demonstrated to be identical to that input; using an effective N with observed case fraction is algebraically a synthetic cohort. The larger total-N pilot's numerical outcomes do not resolve this method question.
3. The 88-locus pilot is a deliberately balanced diagnostic, not a full-trait effect estimate. Its strict advance criterion failed; extrapolating a reliable whole-family gain from it would be unjustified.
4. Yale's ≥10 h UKB+MVP source overlaps Dashti's UK Biobank and differs in threshold; candidate-level concordance is neither independent replication nor LAVA confirmation. Six lead variants were unavailable under the predeclared exact rsID/position match. Nearby minimum P values were not LD-proxy tests.
5. The SleepChart >8 h versus 6–8 h genome-wide file could not be anonymously downloaded from Synapse; no variant-level SleepChart result is reported. PGS Catalog weights lack raw GWAS P/SE/N and were excluded.
6. Other binary archives have promising N-like fields, but actual-versus-effective definitions and model compatibility require source-specific review. The MDD2025 pilot's numerical gain remains on interpretation hold. The present terminal package does not claim that other traits can be perfectly repaired.
7. There is no documented, technically available approved UK Biobank individual-level environment in the searched local project documents. An exact rerun therefore remains an institutional access/custodian route, not a local computation performed here.

The frozen family gate and protected candidate status remain unchanged by these limitations or exploratory results.
