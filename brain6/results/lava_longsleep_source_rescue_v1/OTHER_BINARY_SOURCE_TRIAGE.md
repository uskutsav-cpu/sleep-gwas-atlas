# Source-first queue for the other binary LAVA traits

The frozen canonical NOT_RUN burden is ordered: long sleep **1,291**, insomnia **671**, Parkinson disease **636**, MDD **589**, ADHD **223**, bipolar disorder **168**, schizophrenia **142**. Full-family passing needs 2,847 fewer NOT_RUN cells; no single repaired trait suffices. The [locked planning arithmetic](../lava_confirmatory_rescue_plan_v1/planning_summary.json) shows the smallest set of hypothetically perfect replacements is long sleep, insomnia, Parkinson disease, and MDD, leaving 533. This is an upper-bound scenario, not evidence that those inputs can be repaired or admitted.

This is a read-only archive-header triage, not a prospective input amendment. No source for these traits was promoted and no new trait pilot was launched. The next repair, if exact long sleep becomes admissible, should follow descending frozen burden and be frozen before outcome inspection.

This is a verified mapping/filter path, not proof that the dropped variants would match the frozen LAVA LD reference. A repair would require an audited broader GRCh37 variant-ID map, reference overlap check, and a new prospective lock before any local-h² result.
