# Frozen phenotype contract: Dashti 2019 long sleep

Frozen before the new source-file, LAVA-code, and replacement-source audits. This contract defines the **exact confirmatory phenotype**. An unknown field is not permission to infer or substitute a value. It does not alter any existing LAVA threshold, run, or candidate call.

| Field | Contract / current source evidence |
|---|---|
| Phenotype | Baseline self-report to the UK Biobank question asking usual hours of sleep in every 24 h, including naps, with responses in whole-hour increments. Long-sleep cases report **9 h or more**; normal-sleep controls report **7 or 8 h**. The 6 h category is not a control. [Dashti main paper, Methods, p. 8](https://research-information.bris.ac.uk/ws/files/187399081/s41467_019_08917_4.pdf). |
| Counts | 34,184 cases; 305,742 controls; their sum is **339,926 participants** for this contrast. These are study-level counts, not observed variant-level N. [Dashti main paper, Fig. 1 and Results](https://research-information.bris.ac.uk/ws/files/187399081/s41467_019_08917_4.pdf). |
| Baseline exclusions | Non-European ancestry; self-reported sleep <3 h or >18 h; `Do not know` and `Prefer not to answer` responses; self-reported sleep medication use. UK Biobank genotyping sample QC also removed high missingness/heterozygosity and sex chromosome abnormalities. [Dashti Methods, pp. 8–9](https://research-information.bris.ac.uk/ws/files/187399081/s41467_019_08917_4.pdf). |
| Separate secondary exclusions | Shift/night-shift work, specified prevalent cancers, heart disease, stroke, or psychiatric disorders were *additionally* excluded in a later secondary GWAS. These exclusions must not be imposed on the primary released contrast without file-specific evidence. [Dashti Methods, p. 8](https://research-information.bris.ac.uk/ws/files/187399081/s41467_019_08917_4.pdf). |
| Ancestry and cohort | European-ancestry UK Biobank participants; related participants were retained in the primary mixed-model analyses. [Main paper, pp. 8–9](https://research-information.bris.ac.uk/ws/files/187399081/s41467_019_08917_4.pdf); [official Knowledge Portal release](https://www.kp4cd.org/node/235). |
| Primary association model | The paper describes additive **BOLT-LMM linear mixed models** in related European-ancestry participants. A separate adjusted PLINK logistic regression in unrelated white British subjects supplied odds-ratio sensitivity estimates. The official long-sleep archive README describes its BETA/SE/P fields but does not explicitly name the model that produced the released file. Direct file-to-model linkage therefore remains to be audited; `BOLT-LMM` is not yet a file-specific admission claim. [Main paper, Methods, p. 9](https://research-information.bris.ac.uk/ws/files/187399081/s41467_019_08917_4.pdf); [portal README](https://s3.amazonaws.com/broad-portal-resources/sleep/Saxena_fullUKBB_Longsleep_summary_stats_README). |
| Primary covariates | Age, sex, ten ancestry principal components, genotyping array, and genetic relationship/correlation structure in BOLT-LMM. BMI, sleep apnea, and lifestyle variables were follow-up sensitivity adjustments, not baseline covariates. [Main paper, Methods, p. 9](https://research-information.bris.ac.uk/ws/files/187399081/s41467_019_08917_4.pdf). |
| Genome build and alleles | Public file uses **GRCh37/hg19**; `ALLELE1` is effect allele, `ALLELE0` is described as reference allele, `A1FREQ` as effect-allele frequency. The README does not resolve every REF/ALT normalization or strand edge case. [Official portal README](https://s3.amazonaws.com/broad-portal-resources/sleep/Saxena_fullUKBB_Longsleep_summary_stats_README). |
| Imputation/reference | UK Biobank prephasing with SHAPEIT3 and imputation with IMPUTE4; this analysis used SNPs imputed to the Haplotype Reference Consortium panel. [Main paper, Methods, p. 9](https://research-information.bris.ac.uk/ws/files/187399081/s41467_019_08917_4.pdf). |
| Variant QC stated by paper | Maximum per-SNP missingness 10%, maximum per-sample missingness 40%, hard-call genotype threshold 0.1, imputation quality threshold 0.80, and MAF threshold 0.001 are reported in the association-methods paragraph. The exact relationship of those thresholds to the exported archive is not independently specified by its README. [Main paper, Methods, p. 9](https://research-information.bris.ac.uk/ws/files/187399081/s41467_019_08917_4.pdf). |
| Per-SNP N | **UNKNOWN.** The public README names SNP, chromosome, position, alleles, frequency, INFO, BETA, SE, and P only. It contains no N, NMISS, or cases/controls definition. The paper allows up to 10% per-SNP missingness; it does not establish that every released statistic used exactly 339,926 participants. [Official README](https://s3.amazonaws.com/broad-portal-resources/sleep/Saxena_fullUKBB_Longsleep_summary_stats_README); [main paper, Methods](https://research-information.bris.ac.uk/ws/files/187399081/s41467_019_08917_4.pdf). |

**Admission boundary:** An exact-phenotype replacement must preserve ≥9 h versus 7–8 h and source-valid association/sample-size semantics. A ≥10 h versus 7–8 h, >8 h versus 6–8 h, continuous sleep-duration, PRS-weight, or differently ascertained study is a separate exploratory or replication source, even if it has more variants or stronger signals.
