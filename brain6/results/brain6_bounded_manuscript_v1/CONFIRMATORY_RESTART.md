This is the single restart workflow. Today it stops closed. ## Exact entry command

From the repository root, copy [the manifest template](confirmatory_source_manifest.template.json) and [method-review template](signed_method_review.template.json) to **new** source-specific paths. The review JSON must name its reviewer, record pre-pilot admission and the exact source-file hashes, and explain phenotype equivalence, source-statistic mapping into LAVA, N, and case-fraction or continuous-model semantics. Hash the completed review into the manifest. Fill the manifest only from received primary/custodian evidence and a signed scientific method review. Set the new output directory's final component to the source-specific `analysis_id`. Then run:

```sh
python3 brain6/scripts/brain6_confirmatory_workflow_v1.py --manifest /ABSOLUTE/PATH/TO/NEW_SOURCE_MANIFEST.json
```

The command verifies SHA-256 for the frozen canonical decision, family lock, exact-phenotype contract, prespecified 88-locus selection, new source files, custodian/source document, and signed review. It requires the exact phenotype, EUR/GRCh37 compatibility, literal analyzed-N semantics, an explicit source-model-to-LAVA mapping, all eight pre-output review decisions, and an unused output directory disjoint from protected roots. Missing evidence produces a `BLOCKED_SOURCE_ADMISSION` JSON list and exit code 2 without writing an output. The template currently does this intentionally.

Only after a source-specific manifest and the nine versioned stage adapters pass plan review, execute the workflow:

```sh
python3 brain6/scripts/brain6_confirmatory_workflow_v1.py --manifest /ABSOLUTE/PATH/TO/NEW_SOURCE_MANIFEST.json --execute
```

The executor writes `source_admission.freeze.json` under the new source-specific output root, then runs only hashed repository Python adapters in the fixed order below. Each adapter must write a JSON receipt with `status=PASS`, its exact stage name, analysis ID, and the frozen admission receipt SHA-256. The orchestrator verifies the receipt and method-specific gate, writes a checksum checkpoint, and resumes by verifying completed receipts rather than rerunning them. Missing adapters, mismatched hashes, absent receipts, failed commands, and failed gates stop before the next stage. The [workflow code](../../scripts/brain6_confirmatory_workflow_v1.py) and [source guard](../../scripts/brain6_confirmatory_restart_v1.py) are the executable entry point. A new source revision gets a new manifest and output root.

3. **Multi-trait feasibility projection.** Apply the unchanged frozen 873/17,465 maximum `NOT_RUN` rule. Long sleep has 1,291 canonical `NOT_RUN` and cannot alone repair the family. Full-family launch requires a source-valid, prespecified plan capable of the full gate, not a favorable candidate-locus association.

Audit 17,465 identities, hashes, `TESTED`/`NOT_RUN`/`FAILED`, duplicates, and the unchanged ≤873 ceiling. Stop promotion if any frozen criterion fails.
5. **Bivariate and region follow-up, conditional on full-family pass.** Recompute and validate pair overlap for every changed GWAS; run bivariate LAVA only where both canonical univariate gates pass; apply the prespecified full 12,475-slot multiple-testing policy. Rejoin the 25 protected pair candidates without changing identity, require each independent replication/LD/fine-map/coloc criterion from its own reviewed method, and assign tiers only under the frozen rule. Generate new provenance and manuscript tables instead of editing old receipts.

The stage binding for each `workflow_stages` entry is `{"script":"brain6/scripts/NEW_VERSIONED_ADAPTER.py","script_sha256":"...","receipt":"stages/STAGE.json","args":["--output-root","$OUTPUT_ROOT","--analysis-id","$ANALYSIS_ID",...]}`. The source-admission guard makes the first step immediately runnable when evidence arrives. Source-specific adapter commands cannot be filled honestly before the received source establishes which statistical mapping is valid; their old versions are deliberately source-bound. The 88-locus gate requires at least nine net newly `TESTED` loci using the locked selection and **four workers**; projection and repair receipts require a source-valid ≤873 `NOT_RUN` route; full-family receipts require 17,465 cells and four workers; and the frozen QC receipt must pass before candidate promotion. This boundary prevents a higher `TESTED` count from substituting for scientific admission.
