The seven harmonized GWAS identities and exact paths/hashes are frozen in `canonical_family_trait_power_audit_v1.provenance.json` and copied into `lava_rescue_v1_manifest.json`. Source GWAS versions, build, effect allele and N semantics remain those of the canonical inputs. The pinned UK Biobank LAVA v1.1 reference is `ref/lava/ukb_v1.1/lava-ukb-v1.1`, with repository reference provenance SHA-256 `35ab371935b9c260dab21be248f4907b693565787ef9f62334e7d8030204270e`. Canonical overlap matrices are pair-specific LDSC-intercept covariance files recorded in `brain6/manifests/lava_overlap_v2/lava_overlap_family_v2.tsv` (SHA-256 `9cac309e31a4b7e3571a8c1e2a82b0e28a5f86099e120ac9f10130fc32f45590`). ## Fixed statistical and computational rules

Use LAVA 0.1.5 at commit `e729a245f7b6923967a96804fbf5246eadf2d6c6`, R 4.3.3, BLAS/OpenMP one thread per worker, and seed `20260922`. For each trait-locus, evaluate `process.input` with that trait alone and no cross-trait overlap matrix. Preserve `process.locus` settings `min_K=2`, `max_prop_K=0.75`, `max_block_size=3000`, `prune_thresh=99`, `drop_failed=TRUE`, `cap_estimates=TRUE`; `run.univ` uses `cap_estimates=TRUE`. Retain the previously locked bounded symmetry patch; do not change scientific parameters. A finite local-h2 result is `TESTED`; low support, missing minimum K and other unmet prerequisites are `NOT_RUN` with exact reasons, not a null genetic-association result. Any exception, nonconvergence, singular or ill-conditioned covariance, invalid sample-size/allele mapping, missing LD, or unstable estimate is recorded as its own failure class and may not be silently dropped.

All 17,465 unique trait-by-locus cells must be present in a receipt-verified aggregate. Strict univariate gate: p < `0.05/17465 = 2.86286859433152e-06`. Family QC requires at most 5% untested, meaning at most 873 cells, and at most 1% failed loci. Failed/missing cells count against both applicable gates. Complete pairwise testing is permitted only after this gate passes. For each locked pair-locus where both traits pass the gate, use the pair-specific overlap matrix and LAVA bivariate test. Report all 12,475 slots; ineligible/non-tested/numerical-failure slots contribute p=1. Apply Benjamini-Hochberg across all 12,475 slots. No lower denominator, post hoc threshold relaxation, trait substitution, or regional cherry-picking is allowed. Bonferroni is retained for the 17,465 univariate gate. The locus definitions, genome build, allele harmonization and objective exclusions are unchanged. No exclusions are allowed beyond receipt-documented input invalidity under the already fixed rules. Pairwise convergence and numerical failures must be explicitly enumerated; the family promotion gate still uses the fixed locus/cell fractions.

## Pilot, correction gate, and conditional full run

The first pilot is an outcome-blinded receipt/input QC diagnostic at loci `1`, `950`, `1416`, and `2207`, chosen to cover ordinary low local-h2, shared-reference minimum K, component minimum K, and a processable control. It verifies canonical locus receipt hashes, seven input hashes, source/schema/N and allele fields, reference identity, and exact reason/status concordance. It does not rerun association statistics or replace canonical results. Write one receipt per locus with command, environment, hashes, checks, exit status, and QC interpretation.

Proceed to a *new* corrected-statistics pilot only if this diagnostic demonstrates a specific objective software/input defect that plausibly affects enough cells to pass the fixed family gate. Predeclare the exact fix, changed bytes, affected cell set, and pilot locus selection in an immutable addendum before any corrected-statistics execution. The corrected pilot must remove the demonstrated defect without increasing numerical failures or changing unchanged-control outputs beyond floating-point tolerance. Only then may a full run begin in `/Volumes/Extreme SSD/brain6-work/lava-rescue-v1/` or another isolated root, with at most four single-thread workers, resumable per-locus and per-pair receipts, a hash-bound run ID, complete exit records, and an independent family audit.

Known pre-pilot bound: canonical v3 has 3,720 untested cells, including 3,564 low-local-h2 and only 156 minimum-K failures. Repairing every minimum-K failure alone leaves 3,564 untested, far beyond 873. The five unchanged disorder traits contribute 1,758 untested cells by themselves; even making both sleep traits perfectly testable would exceed the family cap by 885 cells. The previously completed continuous-duration sensitivity also remains above the cap at 3,305/17,465. These observations make a full rerun without a larger, demonstrated and scientifically defensible correction wasteful; a missingness-reduction claim must be evidenced in the pilot rather than assumed.
