# Exploratory functional follow-up, protocol v1

Frozen before any new regional QTL effect or coloc result is inspected. The input family is the 25 pair-specific PLACO candidates in `loci/five_track_cross_pair_region_reconciliation_v1/pair_candidate_members.tsv`; all retain `PLACO_ONLY_CANDIDATE` and `BLOCKED_LAVA` status. This branch cannot promote loci or change canonical results.

## Phase 11: source gate

Use only official eQTL Catalogue release-7 GTEx brain-cortex (QTD000171 expression; QTD000175 Leafcutter splicing) and frontal-cortex (QTD000176 expression; QTD000180 Leafcutter splicing) data, CC BY 4.0. The four source-verified published credible-set files and exact-lead lookups already reside in `exploratory_five_track_v4/v5`; do not rerun them. The official full regional `.all.tsv.gz` expression and `.cc.tsv.gz` Leafcutter splicing sources have GRCh38 variant, REF/ALT, beta, SE, P, MAF and `AN`; the source documentation defines autosomal sample size as `AN/2`. For new extraction, record URL, HTTP ETag/Last-Modified/content length, query interval, row count, local SHA-256, and software. Query no faster than one interval every two seconds per official EBI guidance. A regional slice is not a complete-source-file hash.

The dense harmonized Brain6 GWAS `N` column cannot be accepted uncritically: for insomnia it is a constant constructed effective N even though its raw source has literal per-SNP `N`; the ADHD raw source has `Nca` and `Nco`, which the harmonizer collapsed to effective N. MDD and long-sleep raw files lack native variant N, SCZ/bipolar use source-specific effective-N conventions, and Parkinson mixes clinical/proxy strata. Thus only the six **insomnia–ADHD** pair candidates are eligible for a new exploratory GWAS–QTL calculation using the *raw source* per-variant N/counts. Every other pair is method-held. Eligibility is methodological, fixed before examining new regional QTL association values.

## Phase 12: predeclared coloc gate

For each eligible pair candidate, examine both component GWAS separately against all four QTL contexts in the candidate's original GRCh37 ±500-kb window mapped to GRCh38 by the pinned hg19ToHg38 chain. Match variants by unique lifted GRCh38 position and unordered alleles, require unique source identity, finite beta/SE/P and N, and exclude ambiguous or mismatched alleles. Use the corresponding QTL `AN/2` and MAF. Do not use PLACO P as a GWAS input. A QTL molecular trait needs at least 500 distinct shared variants, source-window coverage, a QTL P≤5e-8 and component GWAS P≤5e-8 to be interpreted. Use `coloc.abf` with fixed priors `p1=1e-4`, `p2=1e-4`, `p12=1e-5`, and report all H0–H4 posteriors, min P, shared variants, sample-size range, and method status. A posterior is **exploratory single-causal-variant sensitivity** because multiple causal signals, sample overlap, genotype LD, imputation, and source-specific model assumptions are not fully resolved. PP.H4 must never become a causal-gene or shared-trait claim. If package or source/prerequisite gate fails, report `NOT_ESTIMATED`, not zero.

## Phases 13–14: replication and enrichment

Independent two-trait locus replication requires phenotype-compatible, verified, cohort-disjoint regional association results for both traits. The existing FinnGen ADHD global genetic-correlation result is pair-level only. Exclude UKB-overlapping Yale long-sleep EUR meta results and PGC-overlapping MDD 2025; do not use source labels as proof of independence. Annotate each of 25 candidates explicitly as `NOT_ESTABLISHED` unless new source-proven regional evidence satisfies the gate.

Carry forward source-bound regulatory coordinate overlaps and QTL credible-set memberships as descriptive context with their prior receipts. Inferential tissue/cell-type/pathway enrichment requires a source-verified target set, calibrated gene weights, tested universe, overlap-aware background, frozen ontology/panel and multiplicity family. Nearest genes and molecular credible-set membership alone do not meet this gate. Report `NOT_ESTIMATED` wherever prerequisites remain absent. Retain 25 pair rows and 20 geographic groups without ranking them by post hoc functional results.
