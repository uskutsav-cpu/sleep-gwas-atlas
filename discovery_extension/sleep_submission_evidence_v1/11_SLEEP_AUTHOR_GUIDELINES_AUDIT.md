The live guidelines do **not state a maximum main-figure count, numerical maximum figure width/height, or maximum uploaded file size** in the inspected figure/supplement sections. Do not import arbitrary limits from another journal. Publisher-linked graphics guidance and the submission portal may impose additional production constraints; check them when preparing the final article. Supplementary graphics have no extension/resolution restriction stated on this page; this does not waive legibility. No submission-ready compliance claim is made for the present evidence exports.

The [publisher preparation page linked by SLEEP](https://academic.oup.com/pages/for-authors/journals/preparing-and-submitting-your-manuscript) states a **2MB per supplementary file** general limit and disallows externally hosted supplementary links. This conflicts with the SLEEP-specific large-dataset option permitting author-hosted links. Final supplement sizing/hosting is therefore **PORTAL_OR_EDITOR_CLARIFICATION_REQUIRED**; this package is not certified against a universal upload maximum. Both official pages were checked2026-10-08.

The publisher-linked [artwork guidance PDF](https://static.primary.prod.gcms.the-infra.com/static/site/journals/document/images-author-guidance.pdf?node=1bf05d0b2fbd9c529a23&version=490455%3A30c2211aa70bba63a5ee) explicitly labels its recommendations as tips, to be read alongside journal rules. It recommends text at least7pt at final print size, embedded-font vector PDF/EPS/SVG, and raster resolutions300dpi color,600dpi gray,600–900dpi combination,1200dpi monochrome. Pure vector graphics have no inherent dpi. The atlas/forest8pt labels at source size need human inspection after any scaling; a300dpi PNG preview alone does not certify line-art production quality. No numerical maximum printed width is stated; use the target journal's intended column width.

The root figures use fresh plotting of project results rather than copied publisher panels. Preliminary graphical abstract has legible landscape layout and no discovery-priority or causal claim. The main atlas two-page PDF is a review aid: the author should choose one final main panel or assign it a sequential supplemental identity. Main editable tables must be assembled in Word; a static research workbook does not satisfy that main-table requirement by itself. Figure/source-data exports have not been reviewed by human investigators.

For studies actually conducting Mendelian randomization, SLEEP additionally requests STROBE-MR and its own MR checklist (PDF preferred), plus SNP lists (Excel preferred). This package conducts global summary-statistics genetic correlation and numerical validation, so those MR-specific submission requirements are **not applicable to the current executed analysis**. Citing prior MR studies does not make this an MR study. If new MR work is later performed, this assessment must change.

Novelty, rigor and measurement depth are editorial gates, not formatting requirements. Neither matching file formats nor a completed adapted checklist rescues the current limited novelty case. Author list, ethics determination, funding, affiliations, conflicts, AI disclosure, final interpretation and submission remain investigator decisions; no manuscript prose has been written.
