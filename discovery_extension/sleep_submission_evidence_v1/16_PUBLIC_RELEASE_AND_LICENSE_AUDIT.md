The source policies have distinct scopes. The portal site's prose license is not automatically the underlying GWAS data license. GWAS Catalog's blanket policy is subject to accession exceptions. Both MVP accessions explicitly identify [EMBL-EBI terms](https://www.ebi.ac.uk/about/terms-of-use/), which add no restrictions beyond original-owner rights and require attribution; upstream owner rights remain relevant. FinnGen's official free-download language supports access, not a new sublicense. Pan-UKB specifically states CC BY 4.0 for its GWAS results.

The released evidence tables include phenotypes, rg estimates, QC fields and scientific metadata; they do not contain participant-level data or full per-variant summary statistics. Three recovered checkpoint TSVs are project-generated original metadata/numerical results, with no restricted participant data. Release checklist: investigator confirms authority for project-generated artifacts, cites upstream studies, reviews all source-specific conditions, chooses project-code license, approves any archive/DOI, and confirms no restricted inputs have been staged.

Current raw-source verification is complete for the two MVP objects described below. The other 111 extension/validation raw objects retain historical full-stream checksums without current complete-body verification. The earlier bounded-access pilot only demonstrates current access to the first bytes. No contact, new agreement, registration submission or paid access occurred.

MVP ETag/Last-Modified metadata differ, so subsequent complete-body checks tested whether scientific compressed bytes changed. Initial metadata evidence remains separate in `sources/provenance_bounded_access.json`.

Literature-cache release boundary: newly fetched full article/supplement bodies, publisher HTML, complete extracted tables and raw search/web responses are local review cache, excluded from the tracked evidence release. The acquisition/hash/access ledgers and selected factual prior-estimate crosswalk remain intended deliverables. See `sources/literature_CACHE_RELEASE_BOUNDARY.md` and `sources/literature_acquisition_manifest.tsv` for exact exclusions and recovery procedures. Existing historical prior-screen files remain unchanged; the new package does not relicense them. No publisher figures are adapted into the deterministic study figures.
