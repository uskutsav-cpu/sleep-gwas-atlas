# Replication independence audit

All 23 historical qualifying positives are **EXTERNAL_OUTCOME_SIDE_REPLICATION**. Zero use independent GWAS for both sleep and outcome. The historical `REPLICATED` labels remain unchanged in the original files.

The discovery script `discovery_extension/scripts/14_rg_extension.sh` and validation script `49_rg_replication.sh` both supply `data/munged/$sleep.sumstats.gz`. Historical validation logs retain this input in the exact command line. Thus source reuse is established by code and historical run receipts, although current missing munged inputs prevent new byte-level execution verification.

The 23 pairs cover eight external phenotypes and seven sleep traits. Outcomes use seven FinnGen R13 endpoints (19 pairs) and MVP abdominal pain accession GCST90479148 (four pairs). Outcomes are cohort-distinct from Pan-UKB by study design. The positive sleep-apnea pair uses FinnGen R9 sleep apnea with MVP abdominal pain; it does not pair FinnGen R9 sleep apnea with FinnGen R13. Individual-level overlap was not audited and cannot be certified from summary statistics. Cohort labels and historical overlap receipts support outcome-side validation, rather than a mathematical proof of zero overlapping people.

The 18 exact matches mean the same named or coding construct according to the frozen curation. They do not guarantee identical ascertainment or clinical coding sensitivity. Five comparable matches retain documented endpoint differences in `tables/replication_source_comparison.tsv`. MVP veterans and Finnish biobank participants differ from UKB in demographic structure and ascertainment; all selected analyses are EUR, which does not make the populations interchangeable.

The 217-row source comparison preserves every unavailable, QC-ineligible and nonsignificant candidate alongside positives, with case/control totals, effective N, source accession, phenotype definitions, allele conventions, heritability, cross-trait intercepts and valid-SNP overlap. Outcome h2/intercept gates are historical observed-scale QC; current-source replay is blocked. Historical positive outcome h2 Z values range 5.1973–18.6866, outcome intercepts 1.0184–1.1786 and valid SNP overlap 812,325–1,151,818. LDSC used the same `ref/eur_w_ld_chr/` European reference path; current reference bytes are unavailable, so its full file identity cannot be newly certified.

The cross-trait intercept helps model overlap-associated covariance under LDSC assumptions. A small or nonsignificant intercept cannot establish participant independence. No assumption that it proves independence is used here.

The historical heterogeneity statistic uses variance `SE_discovery² + SE_validation²`, assuming independent estimates. Reusing the sleep GWAS makes the covariance between the two rg estimates unknown. Therefore the seven nominal heterogeneity findings are retained as approximate diagnostics, and their source comparison is investigated, but the independent-estimate formula cannot be promoted as a confirmed covariance-aware test. A joint block-jackknife or native repeated-estimation procedure would need original sleep, outcome and reference inputs.

Statistical success remains the frozen directional agreement and 0.05/217 threshold. `revised_positive_class` is a qualification of successful pairs, while `independence_design` describes source design for all candidates; `NOT_A_POSITIVE_REPLICATION` is not a replacement statistical label. Numerical replication verification and rounding analysis are reported separately in the generated tables.
