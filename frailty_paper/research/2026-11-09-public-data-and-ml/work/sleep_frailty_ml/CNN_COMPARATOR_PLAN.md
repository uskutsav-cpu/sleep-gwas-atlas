# Additional local-sequence comparator, before final testing

The frozen HyenaDNA validation result did not outperform the simple pattern-count baseline. Before final test evaluation, add one fixed, compact DNA convolution model as a stronger local-pattern comparator. This is a validation-driven expansion of the original plan, not an originally preregistered analysis. Use the same source pairs, chromosome split, measured target, class-weighted loss and validation-only checkpoint selection; no AlphaGenome or outcome-derived features.

Architecture: shared two-allele one-hot DNA encoder with 32 channels (kernel 15), 32 channels (kernel 5), and 64 channels (kernel 5), nonlinear activations, symmetric context/allele-difference pooling, both-strand averaging, and a 32-unit head. Train all of its newly initialized weights with backpropagation, AdamW learning rate 0.001, batch 128, at most 16 epochs, early stopping after three validation epochs without improvement. Do not perform a hyperparameter search. This model is trained from scratch, not a second pretrained biological model.

Select a checkpoint by validation average precision. Include it in the same validation-only model recommendation rule. Do not inspect final test results from the HyenaDNA experiment until this comparator's fitting and selection have finished. Preserve all comparisons and note that validation was reused across several choices. Supervised chromosome holdout remains within one assay study, not independent clinical validation.

Debugging amendment before any final-test result existed: the first CNN attempt produced constant validation scores. A layer-level check found growing convolution amplitudes and a saturated tanh head. Stop that attempt, preserve its log/checkpoint, and add parameter-free per-example RMS feature normalization before the head. This uses no cross-example or holdout statistics and requires no new hyperparameter search. Restart once with the same split, seed and remaining fixed settings; record this validation-driven debugging history rather than describing the architecture as wholly untouched.
