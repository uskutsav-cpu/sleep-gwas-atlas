# Version 3: broader measured neuronal training with permitted AVI supervision

## Why this is needed

V1 and the 42-model v2 search did not establish strong prediction. Adding downloadable AVI scores as input did not beat the best DNA-only v2 validation AP. The original v2 chromosome benchmark and Retallick neuronal assay have now been observed. Preserve those results. The exploratory auxiliary-AVI native-weight run remains in progress and must finish and be checked; do not restart it merely because a wait expires.

The Salomon study indicates that baseline element activity strongly affects detection of an allelic reporter effect. Actual reference/alternate activity measurements are forbidden as inference inputs, but can provide dense auxiliary **training targets**. Their difference correlates 0.99775 with the source signed variant readout, supporting a paired activity task. This is not a new independent label source. A model that has the answer as an input would be leakage and is excluded.

## Additional free measurements and immutable test split

Use the publicly deposited Siraj study, Zenodo 15297965 (CC BY-NC 4.0 according to the record metadata). Raw fixed-library file: `data/MPRA/processed_results/DE/OL42_SKNSH_emVAR_glm_paired_20221220.out.gz`, already downloaded and hashed in the original project's receipt. It contains 95,366 unique center/fwd/reference-background SNP rows. Use exactly this fixed library, not a library selected to maximize model performance. Paired DNA sequences come from the same deposit's `tables/stable2.txt.gz`. Require one unambiguous sequence record, duplicate=no, autosomal biallelic SNV, two 200-base ACGT strings differing only at the declared REF/ALT, an assessed row and finite quantitative activity/effect readouts. Exclude ambiguous contrasts and report all exclusions.

The binary target is a **predefined source-row screen**, not a claim to reproduce the authors' selected best-library final hit list: at least one A/B activity has abs(log2FC)>=1 and -log10 Bonferroni p>=2, and active-set -log10 skew FDR>=1. An inactive row has no detected call; an active row missing an assessed skew FDR is excluded. Nonsignificance/inactivity is not proven biological neutrality. Retain mean A/B activity and absolute allelic skew as auxiliary targets, with their original values never entering inference features. Do not infer A/B signed allele conventions without a separate audit.

Map GRCh37 source SNPs to GRCh38 using unique reciprocal chain mapping on the same chromosome; complement alleles for reverse mappings. Query only the explicitly permitted downloadable AVI raw/PHRED scores. Source 200-base reporter DNA stays the actual tested sequence. The reference environment used by AVI is hg38; surrounding native sequence and engineered constructs can differ. Missing scores remain missing, not zero.

**Fresh v3 test:** chromosomes 1, 2, 3, held out of all new supervised fitting across both Salomon and Siraj. **Validation:** chromosomes 4, 5. **Training:** chromosomes 6–22. Do not initialize from the v1/v2 assay-fitted weights: start from the original pinned pretrained DNA weights, or a fresh compact CNN. The original genome may have been seen in unsupervised pretraining. The new Siraj test model performance must not be inspected before all v3 model/ensemble choices are locked. The broader project previously queried selected project variants in this study; exclude those previously inspected project loci and close regions from the fresh test, and disclose that this is a new fixed-library/chromosome evaluation rather than proof of no foundation-model exposure. Exclude identical canonical 200-base reference/alternate windows containing the tested substitution across splits, considering all valid windows in longer fragments and favoring test over validation over training. A centered window cannot be assumed when the substitution is near a construct boundary. Do not choose eligibility based on model scores.

The existing Salomon chromosomes 1–3 were present in prior project development. Report their new-model test results as previously used study data, separately from the Siraj held chromosomes. Do not pool them into a falsely independent headline. Existing Retallick predictions remain a reused development comparison. A later independent study can still be useful but cannot be called unobserved after it has informed changes.

## Initial fixed training comparisons

1. DNA-pattern logistic and tree-boosting comparators with and without permitted AVI, with explicit cell/study context.
2. Small heads on the original frozen HyenaDNA representations, with and without AVI input. Shared representations and separate study-specific output heads account for different cell states and detection rules.
3. Paired comparisons adding predicted mean reporter activity/absolute skew as auxiliary training tasks. Only DNA/predicted features enter inference, never actual activity/skew measurements.
4. An auxiliary AVI target on DNA-only representations to transfer permitted model-score information. Do not let its head see AVI inputs and call that knowledge transfer.
5. Where justified by validation, native-weight fine-tuning and/or a compact sequence CNN with the same explicit tasks. Compare learned biological motif representations if freely licensed motifs can be verified.

Standardization and target transforms fit on training only. Define exact finite configurations in each run's locked config before fitting; select using the mean study-normalized validation AP skill `(AP - prevalence)/(1 - prevalence)`, retaining per-study AP/AUC and the baseline prevalence. Require results for both studies rather than a pooled mixture metric. Use multiple fixed seeds for neural heads and preserve all attempted configurations. No v3 test-driven redesign or reselection.

## Variant-focused mixture, specified before fitting and blind test

The biological validation diagnostic showed that much of the improved all-call ranking was background activity recognition. The leading motif/chromatin ensemble's within-active AUC was only0.4893 in NGN2 and0.5636 in SK-N-SH. This is not evidence of strong individual variant discrimination. Keep those results and address that gap rather than rebranding a high all-call score.

Train a context activity gate plus a bias-free variant-contrast trunk. Context inputs are motif mean global/local affinities, Hyena contextmean128, and physical reference chromatin36. Variant inputs are motif local absolute differences1611 and original Hyena difference features384, scaled by training RMS without centering so zero contrast remains zero. Context can modulate but cannot add a variant evidence term by itself. Study-specific active/inactive experts plus a predicted activity gate form the all-call score. Actual activity flags only define training targets and conditional-loss strata, never inference inputs. Salomon has calls outside its significant-active stratum, so it requires an inactive expert; Siraj's source-row definition excludes calls outside its active stratum, so its inactive expert is fixed tozero. This is assay logic, not biological neutrality.

Loss weights: all-call1, group-balanced conditional1, activity-gate0.25, real activity-regression0.1 and absolute-effect-regression0.1; compare auxiliary permitted AVI weight0 against0.05. Fixed seeds42/73/101; 128/32 units for each trunk; GELU; dropout0.1; AdamW3e-4, decay0.01; batch512; max80epochs, patience10. Checkpoints use the mean of macro all-call and conditional-active normalized AP skill, retaining both components. This makes variant-specific prediction an explicit objective rather than silently choosing a different headline metric. The other candidate families keep their original reported criteria. Compare this variant-focused model and the best call-detector separately in final validation. Treat scores as uncalibrated research outputs even after the analytic positive-weight correction.

Independent CPU/GPU, zero-contrast structural and finite-difference gradient checks precede fitting. Source gene/TF models are initially fixed. A prior-AVI snapshot run can proceed while the full score table downloads; the full-AVI run uses a separate immutable target snapshot afterward. No new held-chromosome Siraj model performance has been inspected.
