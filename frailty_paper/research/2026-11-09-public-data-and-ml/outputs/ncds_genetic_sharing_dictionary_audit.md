# NCDS genetic-sharing dictionary: age-50 and age-62 field check

Reviewed 29 October 2026. CLS's [direct-access page](https://cls.ucl.ac.uk/data-access-training/data-access/accessing-data-directly-from-cls/) provides a [NCDS longitudinal data dictionary for genetic-sharing applications](https://cls.ucl.ac.uk/wp-content/uploads/2017/02/NCDS_Longitudinal_Data_Dictionary.xlsx). The downloaded workbook identifies itself as version 11, dated 24 September 2025, and says that the main NCDS10 survey variables will be added in a future update. This is a list for choosing requested variables, not an approved participant-level linked dataset.

All **22 candidate age-50 FI variables** in the map at the time of the initial audit were found by exact case-insensitive variable name in this dictionary. Twenty-one names have one matching dictionary row; `N8HLTHGN` occurs in two datasets (`ncds8_imagine.sav` and `ncds_2008_followup.sav`) with the same displayed label and response categories. An application must identify the appropriate dataset, not assume a name is globally unique. The independent age-50 sleep-hour and sleep-maintenance fields `N8SCQ13` and `N8SCQ14` are also present. Six further candidate fields were subsequently identified in the same dictionary; see the [updated map](ncds_age50_frailty_candidate_questionnaire_map.md). These matches establish that the listed *names* are requestable in this dictionary, not that their mapping reproduces the 34-item FI or that the final linked records are complete.

The dictionary explicitly labels `N8SCQ14` values 1–6 from “all of the time” through “none of the time,” with negative values for missing or nonstandard answers. That confirms the inconsistency with the 30-item FI supplement's pain-severity labels, but does not establish which numeric transformation its authors actually used. Obtain the original scoring code or clarification before reconstructing that published index.

The six previously identified age-62 grip and timed-walk measurement fields were not found by exact name in this version-11 workbook. Its main age-62-sweep warning means this **cannot be interpreted as absence of age-62 data or a prohibition on linkage**. The sheet does contain 271 rows labelled Sweep10, so the warning must not be generalized to every age-62-related field. The custodian's current dictionary and explicit permission for the relevant biomeasures in a genetic-linked extract remain necessary.

CLS's workbook instructions request retaining its layout, using its request and research-purpose columns, and not converting the application workbook to CSV. No application workbook was edited or submitted. The [genetics access documentation](https://cls-genetics.github.io/docs/access.html) describes genomic data as available without charge after application; eligibility and other institutional costs remain to be confirmed.

The workbook was inspected locally as public metadata using the bundled Python runtime; SHA-256 `149bf4ef9278b6558ad2a40c37d746fbba8462083c62a8f33a794a7824196a6e`. No survey or genetic participant records were accessed. The linked sample, exact genotype coverage, independent evaluation, and score validation remain unresolved.
