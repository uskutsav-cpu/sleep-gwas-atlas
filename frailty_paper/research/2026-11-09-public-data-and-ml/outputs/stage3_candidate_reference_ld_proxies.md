# LD proxy inventory for the 23 candidate markers

The [proxy table](stage3_candidate_reference_ld_proxies.csv) contains 749 candidate–reference-record pairs, including each of the 23 markers themselves, across a ±250 kb window and r² ≥ 0.8. There are 726 records at a position other than the marker, counted separately for each candidate; the same variant can appear under multiple candidates. All 23 markers had exactly one matching reference record by the supplied GRCh37 coordinate and two-allele set. This is a bounded proxy inventory, not a count of independent loci or causal variants. See the [coverage audit](stage3_candidate_reference_ld_proxy_audit.json) for each marker.

The calculation uses the public MAGMA 1000 Genomes European reference (503 individuals), SNP-major PLINK files and pairwise-complete Pearson r² of unphased allele dosages, with at least 400 nonmissing pairs. Candidate and proxy BIM alleles are shown. All reference records were limited to single-base A/C/G/T allele pairs; insertions, deletions, structural variants, variants absent from the panel and proxies beyond 250 kb are not included. Source variants with multiallelic sites or duplicate rsIDs require further allele-specific interpretation. The study's candidate coordinates were treated as GRCh37 as in prior analyses and have not all been independently lift-over validated. Small reference sample size, ancestry mismatch and input filtering can alter LD in the actual GWAS cohorts. No direction of effect is inferred from r².

An independent `bed-reader` genotype decoder and correlation calculation reproduced the scan for four selected marker/proxy pairs, including rs323509 and rs7734045; see [the validation receipt](stage3_reference_ld_validation.json). This spot check does not establish the accuracy of all reference coordinates, source study alleles, or every proxy. An LD proxy is only a correlated reference variant; it is not necessarily associated in either GWAS, fine-mapped, regulatory, or causal. Pairwise LD alone does not prove that insomnia and frailty share a causal variant.
