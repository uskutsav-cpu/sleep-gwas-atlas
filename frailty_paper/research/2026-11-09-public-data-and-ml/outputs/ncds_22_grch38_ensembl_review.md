# GRCh38 reference screen for the 22-marker NCDS request

On 29 October 2026, 10 of 22 individual Ensembl variation lookups returned successfully. Each of those 10 had one GRCh38 mapping at the converted position with both requested alleles listed; eight list more than two reference alleles. Twelve live requests failed or timed out; they are **unknown**, not absent. The [per-marker file](ncds_22_grch38_ensembl_audit.csv) records response status, matching position, reference allele lists, source URL and response SHA-256. The [script](../work/ncds_22_grch38_ensembl_audit.py) retrieves public variation records, not NCDS participant data.

Two of the 12 failed live lookups, rs12536335 and rs7734045, also appear in the existing [15-marker saved GRCh38 audit](ncds_15_grch38_reference_audit.md); their saved mappings match the same positions and allele pairs. Thus there is current or previously saved reference support for 12/22 marker positions and pairs, and **10/22 remain unverified in this audit**. This is a combined reference-inventory count with records retrieved at different times, not 12/22 genotyped NCDS markers.

Reference multiallelicity does not determine NCDS's representation or whether its biallelic quality filters exclude the scored contrast. An rsID, locus and listed allele match also does not establish effect-allele direction in the GWAS or accurate imputed dosages. This check cannot validate either project score, identify absent target variants, or determine a linked outcome sample. Actual marker coverage and linkage still require authorized CLS data or reliable target-specific metadata. [CLS release description](https://cls-genetics.github.io/docs/NCDS.html).

**Retry, 29 October 2026:** A separate [retry](ncds_22_grch38_ensembl_retry.csv) returned a matching GRCh38 position and allele pair for rs34290943; the other 11 live requests failed again. Combining the original live results, the retry and two previously saved 15-marker reference mappings gives reference support for 13/22 positions and pairs; nine remain unverified. These are reference records, not NCDS coverage. [Retry script](../work/ncds_22_grch38_ensembl_retry.py).

**UCSC dbSNP follow-up, 29 October 2026:** All nine remaining markers returned one exact rsID and GRCh38 position from the public UCSC dbSNP 155 track, with both requested alleles listed; six of these nine records are multiallelic. Together with the prior 13 Ensembl-supported markers, this provides reference-inventory position and allele-pair support for **22/22**, using two sources and different retrieval times. It does not show that NCDS carries any of them, nor does it verify dosage quality or effect-weight direction. [Per-marker results and response hashes](ncds_ucsc_dbsnp155_review.json); [reproduction script](../work/ncds_ucsc_dbsnp155_review.py). Exact allele pair presence in a multiallelic record does not guarantee the target genotype encodes the same contrast.

**Complete UCSC inventory:** Running the same check on all 22 markers independently found one exact position/rsID record and both requested alleles for every marker, with 14 of 22 records listing additional alleles. All 22 full allele sets agree with the earlier Ensembl GRCh37 inventory, despite build and retrieval differences. [All 22 results](ncds_ucsc_dbsnp155_all22.json); reproduce with `python3 work/ncds_ucsc_dbsnp155_review.py --all`. These reference matches still cannot establish target-cohort representation, sample coverage, imputation quality or score performance.
