# RBM6 cortex expression and insomnia: direct-pair sensitivity analysis

A direct GTEx cortex RBM6 eQTL–Jansen insomnia intersection yields 985 variants after NFE reference matching and available frequency checks, compared with 947 variants in the earlier five-study intersection. One modeled signal pair favors sharing: at p1=p2=0.0001 and p12=0.00001, PP.H4=0.922 and PP.H3=0.078. PP.H4 ranges 0.542–0.983 across p12=0.000001 to 0.00005. A second pair favors distinct signals (PP.H4=0.0058, PP.H3=0.812 at p12=0.00001). These are postselected pairwise model outputs, not a joint insomnia–frailty–expression probability or evidence of a causal RBM6 mechanism.

**The central limitation remains:** rs10049477, the largest-PIP variant in the published cortex RBM6 expression set (PIP 0.503), is not present in the cached Jansen regional data by position or rsID, so this comparison cannot include it. The new set contains 39 of the 49 unique variants in the published expression credible set, with reported PIPs summing to 0.387 of 0.953 within that set. That is not comprehensive causal-variant coverage. The cache may have upstream restrictions; absence from it is not proof the variant is absent from every original insomnia source. A direct frailty analysis retained this variant and 44 of 49 published expression-set variants, but it is not a test of insomnia association; see [expanded frailty comparison](stage6_rbm6_gtex_direct_coloc_review.md).

The direct input retains all 89 variants and 100% of the component mass in the earlier Jansen credible set led by rs7428430, and 14 of 16 variants and 60.9% of the mass in the other set. These are within-set coverage checks of a previous fitted model, not coverage of all causal alternatives. The earlier 947-variant analysis yielded PP.H4=0.922 for one modeled insomnia pair at the same illustrative prior; the similar result is a sensitivity observation under similar data and LD, not independent replication. Both analyses miss the published highest-PIP cortex variant and the wider-window insomnia signal described in the earlier regional review.

## Methods and reproducibility

The [eQTL Catalogue GTEx v8 cortex](https://www.ebi.ac.uk/eqtl/Data_access/) sample size is 205; the Jansen insomnia model uses effective N=313,750. The regional QTL and cached Jansen data were matched by uniquely lifted GRCh37 position and exact non-palindromic SNP allele pair, and effect sizes oriented to the QTL ALT allele. All 985 direct matches had a gnomAD NFE reference match and passed an absolute allele-frequency difference threshold of 0.20; the maximum differences were 0.0618 for QTL and 0.0285 for Jansen. These checks do not ensure matching LD or imputation. The source QTL index and full source were not independently checksum-verified; the publicly downloaded published credible-set file has a local hash but no publisher checksum verification.

SuSiE-RSS used 95% credible sets, L=10, fixed residual variance and external signed NFE LD. The cortex and Jansen fits converged, with one and two sets respectively; the matrix minimum eigenvalue was 4.78e−6. Working sample sizes can vary per variant, convergence is not calibration, and the custom Hail index decoder has not been independently checked with Hail. Cortex is a bulk measurement and does not identify a causal cell type. A non-overlapping patient-level cohort is still needed to evaluate the actual risk scores.

Scripts `stage6_rbm6_gtex_jansen_prepare.py`, `_nfe_index.py`, `_align.py`, `_ld.py`, `_coloc.R`, and `_coverage.R` generate the aligned input, source and reference receipts, diagnostics, credible-set members, posterior table, and prior-set coverage table with the same prefix. Reference blocks are downloaded and hashed locally; the full reference matrix is not checksum-verified. A stronger insomnia comparison would require a public dataset with the high-PIP eQTL variant and suitable LD, assessed alongside phenotype and sample overlap.
