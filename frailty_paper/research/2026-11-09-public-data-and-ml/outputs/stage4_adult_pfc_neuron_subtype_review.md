# Adult human prefrontal-cortex subtype sensitivity analysis

To improve coverage of neuronal subtypes, I used the FUMA-processed adult level-2 matrix from [GSE168408](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE168408), a public human prefrontal-cortex single-nucleus atlas. The matrix provides 15 source-labeled groups including cortical neuronal labels, astrocytes, microglia, oligodendrocytes, progenitors and vasculature. It was selected **after** the original six-matrix analyses and is not an independent genetic cohort. Source labels are retained exactly rather than being treated as verified sleep-regulating cell identities.

The [results](stage4_adult_pfc_four_trait_cell_properties.csv) contain 15 MAGMA gene-property tests for each of Jansen insomnia, Atkins FI, Mak FI and Ye FFS, using their Brown-1df gene results and conditioned average expression. I corrected the **60 planned trait–cell tests together** by BH; all 60 were estimable and none had q < 0.05. The smallest was Mak FI `L4_RORB`, p = 0.000848 and q = 0.0509. This narrowly misses the chosen threshold and should not be described as significant or as a shared insomnia–frailty result. BH values were checked against R `p.adjust`.

This matrix is a secondary exploratory sensitivity analysis, with a different correction family from the prior 102-group trait-specific tests. Processed expression across groups can be correlated; there is no direct test of differences between cell groups or traits, donor-aware frailty analysis, candidate-variant assignment, or evidence of mediation. GWAS sample overlap and phenotype differences remain relevant. [Matrix and source receipt](stage4_adult_pfc_matrix_receipt.json); [analysis receipt](stage4_adult_pfc_gene_property_receipt.json); [original cell comparison](stage4_matched_brown_cell_type_comparison.md).

The multiple-testing correction in this report applies to its stated exploratory family only; it does not correct across all of the project's prior models, matrices, locus selections or other analyses.
