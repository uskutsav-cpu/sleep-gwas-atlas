# Existing FFS PLACO+ output: provisional source audit

I found two local files named `FFS_1_569131.tsv.gz` and `FFS_569132_1138262.tsv.gz` under `brain6-placo-ffs-rerun-20261027`. Each contains 569,131 rows marked `TESTED`, with insomnia Z and p, frailty Z and p, and a `P_PLACO_plus` field. Their SHA-256 hashes and row counts are in the [receipt](stage3_existing_placo_ffs_receipt.json). A separate 100-row smoke-test file was not included. The files do not themselves record genomic coordinates, input release, model settings, sample overlap, parameter estimation, or a validated completion/QC manifest.

Of the 23 requested candidate markers, 10 had one exact rsID in the two files and matched the candidate allele pair; 13 had no exact rsID. The [candidate lookup](stage3_existing_placo_ffs_candidate_lookup.csv) preserves these results. Absence is not a negative test and may reflect the source SNP set or another selection rule.

The files' frailty p-values closely match the Ye FFS values for inspected candidates; their insomnia p-values closely match FinnGen insomnia, **not the project's UKB insomnia values**. For example, rs7734045 has shard insomnia p = 0.035204 and FFS p = 0.015016, versus FinnGen p = 0.035218 and Ye p = 0.015; rs2838788 has shard insomnia p = 0.00034491 versus FinnGen 0.00034495. This is supportive numerical evidence of source identity, not a verified run manifest. Minor differences are consistent with the shard's rounded Z values, but their exact origin has not been established.

The inspected project status records failed local-correlation quality gates and prior downstream restrictions; this audit does not establish that the present shards satisfy those gates or recover their exact configuration. Do not rank candidates on these PLACO+ p-values as validated findings, call the missing 13 negative, or infer independent replication, causal sharing or a causal gene. Retrieve the command, input checksums, pair definitions, method parameters, eligibility and QC report before using this run as prioritized evidence. The explicit request to use available PLACO+ results is addressed here as a provenance and eligibility review, not an unqualified promotion of the outputs.
