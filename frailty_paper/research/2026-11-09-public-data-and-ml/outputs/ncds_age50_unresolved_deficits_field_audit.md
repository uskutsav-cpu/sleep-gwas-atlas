# NCDS age-50 FI: remaining composite deficit fields

Reviewed 29 October 2026 using CLS's public [genetic-sharing dictionary](https://cls.ucl.ac.uk/wp-content/uploads/2017/02/NCDS_Longitudinal_Data_Dictionary.xlsx) version 11 and the [published 34-item FI](https://academic.oup.com/aje/article/190/8/1550/6140871). These are **candidate request fields**, not a completed index, coding script or participant analysis. Question routing and original study code must be checked before deciding how non-applicable values contribute.

| Published deficit | Candidate age-50 dictionary fields | Key uncertainty |
|---|---|---|
| Type 2 diabetes | `N8KHPB03` asks about “sugar diabetes.” | The checklist does not distinguish type 1 from type 2; the original derivation or other fields must establish classification. |
| Stomach problems | `N8KHPB14` screens stomach/bowel/gallbladder problems; subtype fields `N8SBGB01`, `02`, `06`, `08`, `09`, `11` name ulcer, gallstones, reflux, diverticular disease, hernia and tumours/cancer. | Broad checklist includes conditions outside the published list. Confirm exact subtype and eligibility logic, and how unknown or backcoded “other” responses were handled. |
| Hearing problems | `N8KHPB07` screens hearing; `N8HPRB01`, `02`, `04`, `05`, `07`, `09` identify hearing loss, tinnitus, Ménière's, age-related degeneration and difficulty hearing certain sounds. | The list is a plausible mapping to the paper's categories, not proof the published code used exactly these fields. Interview routing and additional backcodes need checking. |
| Eyesight problems | `N8KHPB08` screens eyesight; `N8EYEP07`, `08`, `09`, `10`, `13` identify diabetic eye disease, glaucoma, cataract, macular degeneration, and blindness/low vision. | The paper's table footnote lists these conditions, while its text uses presbyopia as an example of an age-related condition that could be included. Confirm the actual authors' code, including treatment of `N8EYEP03` and excluded routine refractive conditions. |
| Depression still symptomatic after medical contact | `N8MHPRB1` and `N8MHSTL1` | The former records contact in four years, the latter whether symptoms persist. Check cases with no reported contact, unanswered follow-up, and whether both “most of the time” and “occasionally” count as symptomatic in the original. |
| Anxiety still symptomatic after medical contact | `N8MHPRB2` and `N8MHSTL2` | Same routing and coding concern; do not turn unasked or refused follow-up into a definitive absence without documented logic. |

For mental-health checklist fields, dictionary labels use 0 “not mentioned” and 1 “mentioned”; follow-ups use 1 “yes, most,” 2 “yes, occasionally,” 3 “no,” and negative values for missing/not applicable. The [mainstage interview](https://cls.ucl.ac.uk/wp-content/uploads/2017/07/NCDS_8_FINAL_MAINSTAGE_DOCUMENTATION.pdf) states the persistence question is asked only for reported mental-health problems. A properly routed follow-up is therefore different from a refusal or incomplete interview; exact derivation must preserve that distinction.

These groups make the remaining six deficits more concrete for a future application; they do not justify asserting that all 34 have been fully mapped. The existing 28-field candidate map covers single candidate names; the six above may each require multiple fields and additional source verification. No participant records were accessed, and no project score has been evaluated.
