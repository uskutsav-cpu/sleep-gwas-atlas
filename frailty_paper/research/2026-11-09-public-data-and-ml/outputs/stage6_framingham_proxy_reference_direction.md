# Direction of selected Omni5 candidate tags in the reference panel

This is an allele-orientation audit, not a proxy score or outcome validation. For the 16 score-by-marker rows without a same-position probe in the [preliminary related-array screen](stage6_framingham_omni5_nexus_review.md), [the signed table](stage6_framingham_proxy_reference_direction.csv) reports Pearson r between target counted-allele dosage and the best tag's **A1 dosage in the project's 503-person 1000 Genomes European PLINK reference**. Eleven rows are positive and five negative; two markers occur in both score definitions, so these are not independent loci. All 16 reconstructed r² values match the earlier tag-screen values to within 0.000002. Reproduce with `python3 work/framingham_proxy_signed_reference.py`.

For example, rs4886140 is counted as A in the 15-marker score and G in the 22-marker count. Against the same reference rs9570080-C tag, r is +0.945 and −0.945 respectively. The algebraic sign change is expected for a verified biallelic target, but this marker has a broader multiallelic reference annotation, and the true source and target contrasts remain unresolved. These numbers cannot establish that a Framingham target record is biallelic or authorize a `2 − dosage` conversion.

The reference allele labels are PLINK BIM A1/A2, **not verified Framingham effect or assay alleles**. The best tags were selected in this same reference, the GEO report's genome build and exact FHS array revision are not confirmed, and real cohort quality, target availability, ancestry-specific LD and phenotype linkage remain unknown. The tag identification allowed direct or complementary assay strand; the sign is for the matched reference genotype, not a claim about the raw array strand. A positive or negative correlation does not supply a calibrated proxy coefficient: using proxies changes the score and requires a separately defined and independently tested method. No individual genotypes or personal scores were saved.
