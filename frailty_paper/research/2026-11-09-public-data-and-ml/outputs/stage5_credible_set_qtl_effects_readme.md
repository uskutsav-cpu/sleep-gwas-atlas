# Frozen credible-set QTL effect records

The [effect table](stage5_credible_set_qtl_effects.csv) retains 651 molecular fine-mapping rows from eight frozen Stage 3–4 source tables, covering all 444 distinct credible-set variants. It joins each source variant ID to its reference-checked, normalized GRCh38 queue allele and preserves the source beta, SE, p-value, Z score, molecular PIP, gene, molecular event, credible-set identifier and dataset or phenotype label when available. Multiple rows for one variant can represent different genes, events, credible sets or source datasets and are not independent replications. The original files are named in each record and preserved in the frozen input archive.

These rows are separate from the 1,176-row targeted [measured molecular evidence inventory](stage5_measured_molecular_evidence.csv); they may overlap it and must not simply be added as independent observations. The original REF and ALT are retained, but effect-allele conventions and any changes in allele representation must be checked against each original dataset before comparing beta direction with model output. A blank dataset or tissue label means that this particular source table did not contain that field; consult the corresponding Stage 3–4 methods and receipts rather than inferring a tissue from a nearby gene. Molecular credible-set PIP is not a disease causal probability, and source selection and shared samples limit inference.

The updated [functional atlas](stage5_functional_atlas_with_priority_splice.csv) includes a count of these source rows per variant. Full-precision AlphaGenome predictions are not yet available, so this table does not establish prediction–measurement agreement or independent validation.
