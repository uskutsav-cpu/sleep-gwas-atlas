# Framingham Omni5: candidate tag feasibility in a public reference

Checked 29 October 2026. Among variants **without a same-position probe** in the earlier [screen of a related Omni5 revision](stage6_framingham_omni5_nexus_review.md), all 6 remaining markers in the 15-marker score and all 10 remaining markers in the 22-marker score have at least one nearby probe whose matched reference variant has dosage r² ≥ 0.8 with the target in the 1000 Genomes European reference used here. The score sets overlap; these are not independent observations. The weakest of these selected r² values is 0.818. [Candidate results](stage6_framingham_omni5_reference_tags.csv); [run receipt](stage6_framingham_omni5_reference_tags.json).

This is **not evidence of complete Framingham genotype coverage**. FHS used an Omni5 family array, but the exact version, coordinate build in its released data, post-QC availability, participant calls and imputation quality are unknown. The source report is a publicly shared NA12878 array report, not FHS. The earlier direct screen checks coordinates only, without verifying alleles. The proxy screen uses the project's assumed/inferred GRCh37 coordinates and matches reference and report pairs by position under either direct or complementary strand; it requires a unique target anchor in the reference and ≥400 paired reference calls. Actual alleles, same-record identity and coding remain unresolved, especially at palindromic or multiallelic sites. Each best tag was selected and evaluated in the same reference panel, and its r² does not give the signed allele alignment.

The heuristic r² threshold is not an imputation-quality threshold, and a proxy is not interchangeable with the actual weighted allele. Replacing targets changes the score and requires a separately specified and independently evaluated allele-oriented model; do not silently substitute these probes. None of these calculations tests an association with insomnia, FI or FFS, or validates a genetic score. The existing matched genotype calls in the 503-person reference are only used for LD; no individual reference data or results were retained.

`work/framingham_omni5_reference_tag_screen.py` streams the [GEO report](https://ftp.ncbi.nlm.nih.gov/geo/samples/GSM2545nnn/GSM2545742/suppl/GSM2545742_HumanOmni5-4v1_NexusFinalReport1.txt.gz), checks 4,301,332 rows, matches nearby probes within ±100 kb to the local `work/stage4_magma_reference/g1000_eur` PLINK files and computes pairwise complete dosage r². A prior full download's SHA-256 is in the [screen receipt](stage6_framingham_omni5_nexus_receipt.json); the rerun was streamed and gzip integrity and full row count passed. Source access and subsequent score application remain separate issues.

A subsequent [signed reference audit](stage6_framingham_proxy_reference_direction.md) reports which reference tag A1 dosage tracks each score-counted allele. This is not target-cohort strand verification or a validated proxy implementation.

A [genotype-only reference simulation](stage6_framingham_proxy_score_reference_audit.md) now compares the experimental tag-substituted sums with complete sums in the same panel used to select tags. This is an optimistically selected arithmetic feasibility check, not target-cohort or outcome validation.
