# Korean public GWAS resources: availability and endpoint check

The [Open KoGES PheWeb overview](https://openkoges.com/pheweb/about) describes summary results for 89 traits in a Korean cohort, with 152,719 participants after quality control and GRCh37 coordinates. That number is not a sleep–frailty sample size. As checked on 29 October 2026, direct requests from this environment to the PheWeb root and phenotype API returned HTTP 502. The overview is available in a search index, but the live phenotype inventory and current data files were not verified. We cannot conclude that its 89 traits lack sleep or frailty, nor establish whether any project variants are present. Summary statistics, if obtained, would support association follow-up, not individual-level score prediction or calibration.

A separate, older [2022 KoGES GWAS archive](https://doi.org/10.5281/zenodo.7042518) is publicly listed under CC BY 4.0 and describes analyses of 72,298 individuals across 76 traits. This is **not the same release or sample count** as the 89-trait PheWeb. The archive README describes 43 non-dietary SAIGE traits, 23 dietary SAIGE traits and ten POLMM categorical traits. To avoid downloading tens of gigabytes, we retrieved just the ZIP central directories of the 43-trait and ten-trait files via HTTP byte ranges. Their 53 file names are recorded in the [inventory](stage6_koges_archive_trait_inventory.csv); none contains the strings `sleep`, `insom`, `frail` or `grip`. This is a filename check, not a comprehensive assessment of coded phenotypes, their content or all six archives. POLMM uses coded phenotype names, and the dietary archive and secondary-analysis files were not inspected. The README directs users to Table S1 of [Nam et al.](https://doi.org/10.1016/j.xgen.2022.100189) for trait definitions; consult it before making claims about particular coded entries.

No result was downloaded, no variant was queried and no score was evaluated. A live phenotype inventory and exact definition, sample overlap, variant contrast, study quality and data-use terms must be established before selecting any future endpoint. The PheWeb's cached overview says ALT is allele 2 and beta describes allele 2; that statement does not verify the orientation of a specific older Zenodo file. Individual-level KoGES genotypes and phenotypes are not provided by these summary archives and require their own authorized-access process.

Reproduce the bounded archive inventory with `python3 work/koges_archive_inventory.py`. It requires HTTP 206, checks byte count, archive end signature and the README's expected 43 and 10 entries, and stops if the server tries to send an entire archive. File sizes are fixed to this release; retrieve fresh metadata before using it on a different release.

## Follow-up: complete published phenotype table

We subsequently retrieved the paper's actual [Table S1](https://ars.els-cdn.com/content/image/1-s2.0-S2666979X22001380-mmc2.xlsx) and extracted its 76 labeled phenotype rows: 14 disease endpoints, 31 biomarkers, 23 dietary measures and eight alcohol-consumption measures. None of the 76 labels names insomnia, sleep, frailty or grip strength. The coded POLMM archive entries correspond to categories represented by urinary measurements and alcohol-consumption patterns; they should not be assumed to be hidden sleep or frailty outcomes. This establishes what the **2022 paper's Table S1 labels** list; it does not prove that the parent cohort collected no sleep or frailty measures, or say what the later 89-trait PheWeb contains. It also does not evaluate any project's variant.

The source workbook is saved as `work/koges/nam2022_table_s1.xlsx` (SHA-256 `b632215bde2a9ba289c78c3b2daa40ef1ba1e7418cb3c0210e002461d4fed614`); the [76-row extraction](stage6_koges_nam2022_76_phenotypes.csv) and [receipt](stage6_koges_nam2022_76_phenotypes_receipt.json) reproduce the label check. The source sheet has headings and metadata in addition to the 76 trait rows; extraction uses the original row spans and asserts their category counts. Run with the bundled Python and `work/koges/extract_nam_traits.py`.

## Accessible 2022 browser and BMI follow-up

The separate [2022-release KoGES PheWeb](https://koges.leelabsg.org/about) is live and describes GRCh37 coordinates and ALT-effect betas for this study. Its phenotype inventory includes 136 entries across KoGES, meta-analysis, and other analysis categories; it does not replace or identify the later 89-trait Open KoGES release. We queried its 2022 KoGES BMI results for the project's candidate variants; see the [exploratory follow-up](stage6_koges_bmi_candidate_followup_review.md). This is not sleep/frailty score validation.
