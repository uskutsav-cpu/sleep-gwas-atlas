# Which variants drive the UKB–TwinGene score disagreement?

The negative correlation between the two cohort-weighted 22-marker FI sums is **not explained by any one marker alone**, but it is sensitive to a small group of markers selected after looking at the cohort differences. In the same 503 EUR-labeled 1000 Genomes reference individuals, the full correlation is −0.455. Removing each variant one at a time produces correlations from **−0.540 to −0.320**, all still negative. Removing rs12536335 makes the correlation least negative (−0.320); removing rs12524473 makes it most negative (−0.540). This is a mathematical sensitivity analysis of the sums, not evidence that either marker is causal.

In an additional **post hoc** check, removing all four candidates whose UKB–TwinGene difference passed the earlier exploratory numerical 0.05/22 threshold (rs12536335, rs28528997, rs17312861, rs11636381) changes the correlation to **−0.018**, for the resulting 18-marker sums. These four were chosen using the same data, so the near-zero result is not an unbiased estimate of replication or a justified rule for excluding them. It shows that this particular combined result depends strongly on selected weights. Removing them does not resolve the source of the discrepancy or establish which set of weights predicts frailty better.

The full 22-marker correlation was negative within each of the five EUR-labeled reference subgroups, ranging from −0.3976 to −0.5471, with 91–107 individuals per subgroup. These subgroup results are small, descriptive and potentially influenced by relatedness; they do not establish ancestry differences or population-generalizable performance. No phenotypes or individual risk estimates were available.

The TwinGene sign convention remains inferred rather than author-confirmed and conflicts with the archive README. Flipping that convention would flip the sign of every UKB–TwinGene score correlation shown here. The cohorts use different FI constructions and separately normalized scales, and the markers were selected using related meta-GWAS and follow-up results. Precise allele representation and cohort overlap remain unresolved. See [the cohort-weight sensitivity analysis](22_fi_cohort_weight_sensitivity.md) and [direction adapter audit](twingene_direction_genomewide_audit.md). All scores are uncalibrated, and none should be used for an individual's risk.

## Method and records

The code recomputed UKB and inferred TwinGene sums using the same 22 aligned alleles, coefficients and 503 reference individuals, reproducing the earlier full correlation to 1e−12. For each variant, its dosage-weight term was removed from both sums before recomputing the correlation. For the four-marker sensitivity, all four terms were removed simultaneously. [All 22 leave-one-out results](22_fi_score_cohort_leave_one_out.csv) and [the calculation receipt](22_fi_score_cohort_leave_one_out.json) contain exact values. The calculation uses no phenotype data; no person-level genotypes or scores were retained. Script: `work/score22_cohort_weight_leave_one_out.py`.
