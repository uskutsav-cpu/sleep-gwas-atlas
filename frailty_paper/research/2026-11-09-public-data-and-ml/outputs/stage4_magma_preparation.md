# Genome-wide MAGMA cell-type analysis: preparation and running status

A genome-wide MAGMA Brown-approximation analysis for the Mak frailty-index GWAS has completed; see the [FI results](stage4_mak_fi_brown_magma_cell_type_review.md). The separate original Imhof FI run remains in progress. The Ye Fried frailty score analysis and its exploratory gene-property tests have completed; see the [FFS results and validation](stage4_ye_ffs_magma_cell_type_review.md). The two traits come from different studies and are not a controlled test of a difference between FI and FFS. Both use UK Biobank participants, so their analyses are not independent.

The local analysis uses MAGMA v1.10, the 503-person 1000 Genomes Phase 3 European GRCh37 reference, and Ensembl v92 coding genes with a 1-kb upstream/downstream mapping window. The extracted reference files match the SHA-256 and byte counts recorded in the archived project's pinned manifest. MAGMA mapped at least one reference SNP to 20,144 of 20,260 annotated genes. These reference and annotation choices do not establish ancestry matching for every phenotype, nor do they cover all genes, regulatory links or cell types. Mak FI is being analyzed with per-SNP N. The Ye FFS input does not contain per-SNP N; its reported total N of 386,565 can only be used as a documented approximation, not a verified N for every SNP. Source p-values are used as provided; source rounding, duplicate identifiers and rsID-only matching remain limitations. In a fixed rsID-number sample, all 7,887 directly matched Mak FI rows and all 7,824 directly matched Ye FFS rows agreed with reference coordinates; another 611 and 644 sampled rows, respectively, lacked direct reference IDs. This is a partial diagnostic, not proof for unsampled SNPs or reference synonyms ([audit](stage4_magma_reference_coordinate_sample_audit.json)).

Six processed FUMA scRNA expression matrices have been extracted for a planned gene-property analysis: human cerebral cortex, human PBMCs, mouse hypothalamus, mouse brain vasculature, mouse adult muscle atlas, and mouse limb muscle. Mouse matrices are mapped by the source to human Ensembl gene IDs and require cross-species interpretation. [Matrix extraction receipt](stage4_fuma_matrix_receipt.json). A proposed model conditions each cell-type covariate on its dataset-wide `Average` expression, with a one-sided enrichment test; for each completed trait, its full set of tested cell-type variables across the six exploratory datasets will form one BH multiple-testing family. These matrices were selected after reviewing availability and are not a preregistered confirmatory panel. The completed FFS Imhof and FI Brown models each used their own 102-variable BH family; matched models and original-study analyses remain in progress.

This analysis will test each trait separately. Even if the same cell group is enriched for both, that pattern alone will not prove a shared variant, a shared gene, mediation, or a direct difference between traits. A direct shared-signal analysis requires a properly validated joint GWAS statistic and matched LD. The muscle and vascular matrices are distinct from the human atlas files being acquired; cell populations and gene representation will be reported as actually measured.

The original SNPwise-mean (Imhof integration) FI and Ye FFS gene analyses are running. A sampled live stack showed the FI process in numerical integration at one gene; the process remained CPU-active. An additional FI run uses MAGMA v1.10 `snp-wise=brown1df` as an explicitly labeled Brown-approximation sensitivity analysis. A corresponding Ye FFS approximation was started and then interrupted because concurrent analyses were placing pressure on local storage and swap; it needs a clean rerun when resources permit. This is a separate model run, not a replacement or equivalent numerical result, and its output needs comparison and calibration review before interpretation.

For a more comparable follow-up, matching Brown 1-df analyses have been started for the public Ye FFS and UKB-only Jansen insomnia GWAS; an Atkins FI input is being prepared. They still differ in phenotype, filtering, sample and ancestry, and do not constitute a formal FI–FFS difference test or a shared-variant analysis. The Jansen input uses per-variant source N, INFO ≥0.9, MAF >1% and autosomal single-base alleles. The Atkins input uses source allele frequency >1% and constant total N because variant-level N and INFO are not supplied.
