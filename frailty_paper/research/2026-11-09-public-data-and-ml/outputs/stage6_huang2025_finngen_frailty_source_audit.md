# Source check: apparent FinnGen frailty GWAS in Huang et al. (2025)

The [Huang et al. paper](https://onlinelibrary.wiley.com/doi/10.1155/ijcp/6662987) refers in its methods to “frailty sample data” from FinnGen DF10 (412,181 participants), which initially looks like another freely accessible frailty GWAS. Its source description is internally inconsistent: it names `ebi-a-GCST90020053` as frailty data obtained via ICD codes, while elsewhere it states that frailty GWAS data came from UK Biobank and osteoporosis data came from FinnGen. The named [GWAS Catalog record GCST90020053](https://www.ebi.ac.uk/gwas/studies/GCST90020053) is the Atkins self-reported deficit FI meta-analysis of UK Biobank and TwinGene, not evidence of a distinct FinnGen ICD-based frailty GWAS. The only explicit FinnGen endpoint identified in the checked passage is osteoporosis (`finn-b-M13_OSTEOPOROSIS`), not frailty.

Do not treat the 412,181 statement as a verified new independent frailty dataset or use it to support a replication claim. A true second dataset would need a specific frailty endpoint ID, source URL, phenotype, sample details and file-level verification. This review does not establish that no relevant FinnGen endpoint exists elsewhere, nor does it resolve what the authors actually analyzed.

A separate, real [FinnGen hospital frailty risk score GWAS](https://www.ebi.ac.uk/gwas/studies/GCST90707291) has already been used in the project. Its dementia-excluded sensitivity analysis is described in the [Mak et al. article](https://www.nature.com/articles/s43587-025-00925-y), but the current Catalog v2 publication query `pubmed_id=40764432` returned only the full HFRS accession. Its supplement contains selected significant dementia-excluded results, not an established complete genome-wide file; the selected FOXP2 marker follow-up is already in `rs12536335_finngen_hfrs_followup.md`. These sources do not validate the proposed participant-level genetic scores.
