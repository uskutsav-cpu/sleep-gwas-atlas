# Standardized credible-set QTL effects

The [standardized table](stage5_credible_qtl_standardized_deduplicated.csv) reduces 651 retained source rows to 525 unique combinations of dataset, molecular trait/event, credible set and source variant, spanning 444 variants. The 126 repeated rows were duplicate exports; identical effect, standard error, p-value and PIP were verified for each repeated key. Source files and copy counts remain in the table. Distinct credible sets or events remain separate, and statistical independence must not be assumed.

Dataset and tissue labels were restored from the Stage 3–4 source receipts and the release-specific fine-mapping summary. The [eQTL Catalogue](https://www.ebi.ac.uk/eqtl/Data_access/) states that ALT is the effect allele. For these records, the original and normalized allele representations are identical; `qtl_beta_alt` therefore retains the source beta for the specified alternate allele. Four exact variant/gene/event/dataset records shared with the existing targeted evidence inventory agreed exactly in effect. The [audit](stage5_credible_qtl_standardization_audit.json) records the checks. This cross-check covers only four records and is not independent validation of all source data.

An ALT-oriented molecular QTL effect is not automatically comparable to every AlphaGenome score: a valid comparison requires matched gene, tissue, assay, molecular event, allele and effect scale. LeafCutter betas describe specific splice-junction usage, so they cannot be directly compared with an unsigned maximum splicing score or a gene-expression score. Molecular PIPs do not establish disease causality. Source data can overlap AlphaGenome training or the trait GWAS and the records are selected from molecular credible sets.

The 651-row [unconsolidated source table](stage5_credible_set_qtl_effects.csv) remains available for traceability. These QTL records do not replace the still-missing live AlphaGenome predictions and independent functional validation.
