# NCDS marker request: GRCh38 reference cross-check

The existing [saved Ensembl GRCh38 inventory](../work/variant_reference_grch38.csv) contains public reference mappings for the 15 weighted-prototype rsIDs. Compared with the new [NCDS marker request](ncds_score_variant_request.csv), all 15 have exactly one recorded Ensembl mapping at the converted chromosome and position, and both project alleles occur in the reference allele listing. Nine of the 15 mappings list more than two reference alleles. [Per-marker results](ncds_15_grch38_reference_audit.csv); [reproduction script](../work/ncds_grch38_reference_audit.py).

This is a position-and-allele-list consistency check between existing records, not an independent experimental validation. The 15 saved records include original endpoint URLs and response hashes, but were retrieved earlier; a new bulk Ensembl request timed out in this session. The matching count does not establish the right allele contrast in the source GWAS, effect direction, target cohort variant availability or INFO, nor prove that NCDS's biallelic filter retains or excludes any marker. A locus listing more alleles does not itself identify which participants carry each allele or how the NCDS release represents the locus. The 22-marker list has not received this same complete GRCh38 inventory check.

Actual score evaluation still requires the approved linked genotypes and outcomes. The [CLS NCDS release documentation](https://cls-genetics.github.io/docs/NCDS.html) describes GRCh38, imputation and QC filtering, but does not provide the per-marker target evidence needed here.
