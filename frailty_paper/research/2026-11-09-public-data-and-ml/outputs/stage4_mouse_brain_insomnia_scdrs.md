# Exploratory insomnia scDRS analysis of mouse brain cells

I ran scDRS on 3,005 cells in the public [Zeisel et al. mouse somatosensory cortex and hippocampal CA1 dataset](https://pubmed.ncbi.nlm.nih.gov/25700174/) using the scDRS authors' published, human insomnia GWAS-derived gene set mapped to mouse genes. **This is an insomnia-only, cross-species analysis; it does not test frailty or shared insomnia–frailty genetics.** The dataset does not include hypothalamus and its cells are not independent biological donors.

For the seven broad annotated groups, CA1 pyramidal neurons had the lowest group-association Monte Carlo p-value: **p = 0.0140, BH-adjusted q = 0.0979 across these seven groups**. The next was somatosensory pyramidal neurons (p = 0.0599, q = 0.1871). No group passes q < 0.05 in that family; the CA1 q < 0.10 is exploratory and does not account for future datasets or other analysis choices. At the single-cell level, no cell passed FDR < 0.10. [Complete results](stage4_mouse_brain_insomnia_scdrs_groups.csv) include group sizes and separate within-group heterogeneity tests; their adjusted values use a separate seven-test family and should not be conflated with the association tests.

These results reflect whether expression of a polygenic insomnia-associated gene program is unusual relative to matched control gene programs, not whether a particular gene or cell type causes insomnia. Mouse–human gene mapping, cross-species differences, donor/region composition, age and source-GWAS sample overlap limit interpretation; there is no donor-aware inference or independent replication. A group-level association is not proof of a particular variant–gene–cell mechanism. Cell classifications, small groups, the selected seven-category resolution, and sensitivity to normalization and covariates also matter.

## Methods and provenance

The source inputs are the authors' [scDRS public release](https://figshare.com/articles/dataset/scDRS_data_release_030122/19312583), with their Zeisel expression matrix, their `geneset.gs` mouse-mapped weighted set `PASS_Insomnia_Jansen2019`, and their provided covariates (`const` and number of genes per cell). The ZIP archives downloaded for the weighted gene sets and single-cell data matched the provider's MD5 values `144346661435241ae1f44437bb1f8867` and `f444b1bf952cc307be9510629783a68a`, respectively. Expression matrix SHA-256 `3f01f349f240c95395bb5238949db3a9ec246024051fd143e485df152ae6dbb1`; extracted one-trait gene set SHA-256 `d9132dacb20b9828480a32e3fd3161b505625e134639cdbaf37b0ea3114a1604`; covariates SHA-256 `93d9566d9b31353b5bb0b3d2f234f75960dedd2856ab01aaa4311f0871c25ff9`. The mouse-mapped set has 859 genes; scDRS used 710 present after processing.

scDRS v1.0.4 development code at Git commit `644a5c7900d3c8d84c068725b47dd81e0db22ffb` was run with its default mean/variance-matched controls, 1,000 control gene sets, raw-count normalization and filtering; the provided covariates were included. The downstream `level1class` group-association and heterogeneity tests use scDRS's control-score-based Monte Carlo procedure. See the [scDRS CLI documentation](https://martinjzhang.github.io/scDRS/reference_cli.html). Benjamini–Hochberg adjustment was applied across the seven group-association p-values and, separately, across seven heterogeneity p-values. The first analysis is a feasibility result; human brain and hypothalamus, muscle, immune and vascular analyses with suitable genetic inputs remain necessary.
