# SMAD5 excitatory-neuron source-statistics audit

The SingleBrain full-association file is block-gzipped and sorted by position. HTTP byte-range queries located and decompressed the GRCh38 chr5:135,000,000–137,300,000 window without downloading the 4.6 GB file. `stage5_singlebrain_regional_extract.py` reproduces the extraction, checks HTTP range responses, BGZF block integrity and coordinate ordering, and records the byte range and its SHA-256 in `stage5_singlebrain_ext_smad5_regional_receipt.json`. The source's published whole-file MD5 could not be verified because the whole file was not downloaded. The extracted SMAD5 records are `stage5_singlebrain_ext_smad5_full_regional.tsv.gz`.

The extraction retains 4,407 SMAD5 rows, of which 2,229 have a positive fixed-effect standard error. One exact position/allele appears twice, once with a zero SE and once with a positive SE; the audit filters to positive SE before matching. Among these 2,229 records, one valid-SE source row has an inconsistent effect allele: rs4392613, chr5:135756623:A>T, reports effect allele G, which matches neither REF nor ALT. It must not be used for signed analysis without clarification. The other 2,228 positive-SE rows report the alternate allele as effect allele.

The browser returned 2,206 distinct SMAD5 allele records for this cell type, all present among the positive-SE source records; 23 source records were not returned in the archived browser response. For the 35 exact project-queue variants returned by the browser, every portal beta exactly matches the fixed-effect source beta, the source effect allele matches ALT, and the portal p value matches the source random-effects p to portal rounding. Thus the direction of these 35 source comparisons is verified, but the browser's mixed fixed-beta/random-p columns should still not be used as a single matched estimate and SE. `stage5_singlebrain_ext_smad5_source_validated_matches.csv` provides source fixed beta, fixed SE, fixed and random p values, allele fields, and the pre-existing disease associations. Run `stage5_singlebrain_ext_smad5_source_audit.py` to reproduce the 35-match check.

A major coverage limitation prevents trustworthy colocalization here. Within the retrieved source range, the last source record before the original SMAD5 marker is at chr5:136164132 and the next source record, for another gene, is at chr5:139164641; the original marker chr5:136202653:A>C and alternative chr5:136207208:G>A fall in this apparent gap. The reason for this gap has not been established. These two variants were not observed in the source rows for SMAD5. This is not a negative biological result; any colocalization claiming to cover the disease lead or the regional signal on these data would be incomplete. The region was selected after earlier analyses, and SNPs and cell-type records are correlated. Neither exact molecular association nor sign agreement establishes mediation, independent phenotype replication, or causal shared risk.

Source: [SingleBrain publication](https://www.nature.com/articles/s41588-026-02541-x), [full-statistics release and dictionary](https://zenodo.org/records/14908182), and [public browser](https://singlebrain.nygenome.org/eqtl/).
