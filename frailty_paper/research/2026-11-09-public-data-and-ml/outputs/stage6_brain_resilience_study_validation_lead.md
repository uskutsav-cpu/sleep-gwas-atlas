# Brain Resilience Study: prospective open sleep-genetics resource

The [2026 Brain Resilience Study protocol](https://doi.org/10.1016/j.neurobiolaging.2026.02.001) describes recruitment of more than 1,000 adults aged 50+ from the BC Generations Project. The planned main study includes genotyping, two weeks of actigraphy and sleep diaries, and Pittsburgh Sleep Quality Index questionnaires; circadian biosamples are planned in a smaller sub-study. The protocol says newly collected BRS data will be offered in an open repository. This is a substantive **future sleep-genetics lead** for the user's free-data objective.

The protocol is prospective. We have not identified an active public repository containing participant-level genotypes, linked sleep measures and sufficient completed participants, or verified the release date, cost or conditions. The [study's public description](https://brainresilience.ca/study-info) confirms the planned sleep and genetic components but does not establish a released dataset. The protocol does not establish an FI or Fried frailty score, their components, or which parental cohort fields can be linked in the open release. Sleep-quality and actigraphy measures differ from an insomnia diagnosis. The parent [BC Generations Project access process](https://bcgpresearch.ca/access-process/) requires an application, funding, ethics documentation, review and an agreement; it should not be assumed that the parent data have the same access terms as the planned BRS repository. No fee estimate for this particular project has been confirmed, and no request was sent.

The protocol specifies an Illumina Global Screening Array without an exact version or imputation plan. An earlier project [scan of a representative GSA v3 manifest](stage6_nhats_gsa_v3_manifest_review.md) found no exact coordinates for our 33 unique candidates, but it was **not** the BRS array manifest and cannot establish BRS coverage. Different revisions, custom content and imputation can change coverage. When a release is available, verify the actual genome build, markers, imputed dosage/quality, allele representation, outcome definition, participants' age and overlap, and score–phenotype completeness. An open release alone will not guarantee adequate events or a valid predictive evaluation.

**Status:** potentially useful for independent sleep-score evaluation if the relevant linked data are actually released and meet the terms, not an available frailty-score validation dataset. Its planned multidimensional sleep and circadian measures may also support future methods research separately from the current score comparison.
