# AlphaGenome track provenance and reporter-independence audit

We inspected [Avsec et al. (2026), Supplementary Table 2](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41586-025-10014-0/MediaObjects/41586_2025_10014_MOESM3_ESM.xlsx), the published human and mouse track metadata. The downloaded workbook, URL, sheet and SHA-256 are recorded in `stage5_alphagenome_paper_metadata_receipt.json`; `stage5_alphagenome_priority_track_provenance.csv` retains ten selected human ATAC, DNase and CAGE rows for the cell contexts used in the reporter follow-up. This published manifest is evidence about the paper's model; the exact identity of every track in the later live API model has not been independently established.

## Material CAGE label discrepancy

The live API reports two CAGE rows named `LQhCAGE CL:0000895`, with biosample `naive thymus-derived CD4-positive, alpha-beta T cell`, data source FANTOM, and opposite `+` and `-` strands. The paper's corresponding human metadata rows match these visible labels and strands but list source file `CD42bCD25-CD45RA-20memory20conventional20T20cells2c20donor1.CNhs13239.11786-124B4`. The independent [UCSC FANTOM5 track listing](https://genome.bio.fsu.edu/cgi-bin/hgTrackUi?db=hg38&g=TSS_activity_TPM) explicitly describes CNhs13239/11786-124B4 as **CD4+CD25−CD45RA− memory conventional T cells**. This is a real discrepancy between the model ontology label and the source-file description, subject to confirmation that the published metadata and current API track are the same model version. It should not be interpreted as verified naïve-cell evidence.

The `stage5_ho2025_mpra_model_comparison.csv` now records `model_track_strand` and flags the 176 corresponding CAGE score rows (two strands for each of 88 variants). They are not independent CAGE donors or replicates merely because two score rows exist. Existing live raw and tissue-atlas files preserve the model's original biosample label; users should apply this provenance flag before making cell-state claims. The ATAC and DNase tracks with similar ontology labels are distinct tracks with their own ENCODE source records; this CAGE-specific flag should not be mechanically applied to them.

## Reporter-study independence

The paper metadata identifies the matched SK-N-SH DNase track as ENCODE experiment `ENCSR000ELQ` (file `ENCFF998QMV`), and the Jurkat DNase track as `ENCSR000EOS`. These tracks are model input/target metadata, not the Siraj or Ho MPRA reporter readouts themselves. The original AlphaGenome publication describes evaluating the model on CAGI5 MPRA data; this does not by itself establish whether these later reporter datasets, individual loci, shared source material, or a particular current API model were withheld. The study's `ALL_FOLDS` prediction setting is not a held-out-genomic-region analysis. Consequently, the reporter experiments are separate measurements but should not be described as a proven independent test of the model. A complete proof would require a model-version-specific training and benchmark manifest and confirmation of genomic-region and assay overlap.

To reproduce the selected metadata extraction, run `stage5_alphagenome_track_provenance.py` with the bundled Python and openpyxl after saving the official workbook at `work/alphagenome_2026_supp_tables.xlsx`; regenerate the Ho comparison with `stage5_compare_ho_mpra_alphagenome.py` and the live score directory. Cell descriptions, accession matches and file labels should be checked against the original sources before use as biological conclusions.
