# African-ancestry handgrip GWAS: candidate follow-up

The public [Hansen et al. 2026](https://www.sciencedirect.com/science/article/pii/S0002929726002727) handgrip summary dataset [GCST90854255](https://ftp.ebi.ac.uk/pub/databases/gwas/summary_statistics/GCST90854001-GCST90855000/GCST90854255/) provides a cross-population check of the project's 22 previously selected candidate variants. It describes 1,652 participants of sub-Saharan African ancestry and measures grip, not FI, FFS or insomnia. The paper describes adult participants aged 18 and older; the grip-specific older-adult distribution is unverified. The African sample is distinct in description from the UK Biobank-based frailty discovery studies, but individual participant and family overlap with all discovery and selection inputs has not been established.

The complete file's MD5 matched the Catalog metadata (`f634c1ceadf8bd32e98b311aab8a973f`). A scan of all 6,051,262 rows found matching GRCh38 position and the candidate's exact unordered allele pair for **16 of 22**; six had no row at the candidate coordinate. No matching coordinate had multiple rows or a different-only allele pair. Absence is not a null association: variants may be unavailable, filtered, differently represented or untested. The Catalog calls the source unharmonized. All 16 matched source reference alleles agreed with the source variant ID and with independently queried UCSC hg38 reference bases; all 16 were nonpalindromic. These checks reduce some orientation concerns but do not fully resolve multiallelic coding or establish correct imputation. Candidate-allele frequency differences versus the previously used 1000 Genomes AFR group ranged up to 0.183; these diverse populations need not have identical frequencies.

Only one matched candidate had a nominal two-sided p<0.05: **rs7731706**, G versus T, estimated grip beta −0.578 (SE 0.222; p=0.00909). In the existing project crosswalk, G is the allele with positive point estimates for insomnia and frailty traits, so the grip estimate points toward lower strength for that same contrast. This is descriptive, post-selection and cross-phenotype evidence, not a validated shared-risk locus. The p-value does not pass a simple 0.05/22 threshold (0.00227); that benchmark does not account for the wider project search and should not be treated as a complete correction. The locus is labeled TRPC7 by proximity in the project, which does not establish an effector gene. The broader reference lists an additional alternate allele for this rsID, so the specific G-versus-T comparison matters. The source sample is small and the other 15 p-values exceed 0.05; absence of nominal significance is not evidence of no effect. The original candidates were selected through multiple prior analyses, and LD and allele frequency differ between populations.

**Do not read the coefficient as kg.** The Catalog metadata says kilograms, but the authors' public preparation code labels the original measure in newtons and constructs standardized traits; the inspected GWAS workflow does not establish which input was used. The coefficient and SE above remain in unverified source units. The source reports per-variant N 1,651 or 1,652 for the matched variants. Reported p-values agree to rounding with a two-sided normal calculation from beta/SE, which checks numerical consistency but not allele coding or validity of the model.

This summary-statistic lookup is not an evaluation of a genetic score in independent individuals and cannot estimate discrimination, calibration, incremental prediction or shared causality. Nor is the nominal candidate test a prespecified trial. The full [lookup table](stage6_hansen_grip_candidate_lookup.csv) records source alleles, allele frequencies, effect estimates, p-values, reference checks and missing rows; [receipt](stage6_hansen_grip_receipt.json), [reference-base table](stage6_hansen_candidate_grch38_reference.csv) and scripts `work/hansen2026/extract_candidates.py` and `work/hansen2026/fetch_grch38_ref.py` document the workflow. UCSC reference retrieval uses 0-based half-open intervals for the Catalog's 1-based coordinates. Source details and unit investigation are in [source note](stage6_hansen_grip_source_in_progress.md).
