# Older-adult CHARGE gait-speed GWAS: public supplementary screen

[Ben-Avraham et al. (2017)](https://pmc.ncbi.nlm.nih.gov/articles/PMC5310665/) analyzed measured gait speed in 31,478 adults from 17 cohorts, followed by 2,588 individuals from four additional cohorts. Walking speed is one physical function relevant to Fried frailty, but it is not an FI, FFS or insomnia phenotype. No locus achieved the conventional genome-wide significance threshold in that study. The discovery cohorts include HRS and the Lothian birth cohorts, which feature in other project background and validation discussions; complete participant and relative overlap with every discovery or selection study has not been established.

The publicly downloadable [supplementary files](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC5310665/supplementaryFiles) contain Supplementary Table 2: 536 source-selected gait SNPs (reported selection p<1e-4). A literal rsID comparison with the 22 existing project candidates found **no exact matches**. The list is a significance-selected subset, so absence does not establish a null association, confirm the marker was measured, or assess other variants in the region. It supplies neither full candidate coverage nor participant genotypes and outcomes, and cannot validate the score. The [GWAS Catalog study GCST004110](https://www.ebi.ac.uk/gwas/rest/api/v2/studies/GCST004110) marks full summary statistics unavailable in its catalog entry; this does not establish that no other public repository or accessible copy exists. No request to investigators was made.

The [machine-readable screen](stage6_charge_gait_candidate_screen.json) records source and candidate counts and the SHA-256 of the selected supplement. The workbook has 536 distinct marker names in the 536 data rows; extraction script `work/gait_charge_2017/screen_candidates.py` uses the bundled Python runtime with openpyxl for read-only inspection. Exact rsID matching did not test genomic coordinates, alternative identifiers, LD proxies, cohort-specific alleles or the unreported genome-wide statistics.

The authors published a [correction](https://pmc.ncbi.nlm.nih.gov/articles/PMC5559176/) to a gene name in the article's annotation discussion. It does not identify a change to the selected-variant table examined here. The separate [ELSA precomputed-score report](stage6_elsa_precomputed_scores_access_review.md) describes constructing a gait PGS from a much broader set of GWAS variants, but its cited source has not been verified as an openly downloadable full file.

**Update:** The full gait GWAS was subsequently located on the [current NHLBI GRASP page](https://www.nhlbi.nih.gov/grasp/full-results) and scanned. See the [full candidate follow-up](stage6_charge_gait_full_candidate_review.md); the original selected-supplement screen was not the limit of the available data.
