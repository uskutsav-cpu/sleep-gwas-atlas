# FI versus FFS weights in Japanese insomnia: partial-score sensitivity

Using the same 13 of 15 available markers for all three weight sets, the Japanese insomnia GWAS yields approximate weighted marginal-Z values of **0.99 for FI weights**, **0.56 for inferred FFS weights**, and **0.48 for insomnia weights**, using a 104-person Japanese reference-LD panel. Each result is imprecise. This is a postselected sensitivity analysis of marginal SNP associations, **not** a measured score effect, a comparison of prediction in individuals, or evidence of no association.

| Weight set | 13 markers: JPT Z | Nominal p | 12-marker low-expected-case-count sensitivity: JPT Z |
|---|---:|---:|---:|
| FI | 0.992 | 0.321 | 0.993 |
| FFS, direction inferred | 0.562 | 0.574 | 0.555 |
| Insomnia | 0.480 | 0.631 | 0.497 |

The separate 12-marker sensitivity omits rs17550821, whose pooled-frequency-based null expectation is about 9.19 minor-allele dosage copies among 389 cases (`2 × cases × min(p, 1−p)`). This is an approximation, not a count observed in cases; the cutoff of 10 was selected after inspection and is not a validated QC rule. Two other prototype markers have no exact match in the source, and the original 15-marker score was not evaluated. Using an overlapping 504-person EAS reference gives very similar Z values (13-marker FI 0.996, FFS 0.557, insomnia 0.477). It is a reference sensitivity, not an independent replication.

For the 13 markers, the estimated correlation between FI- and FFS-weighted marginal statistics under the external reference approximation is about 0.87; their estimates are not independent. Differences between Z values or p-values cannot establish which score predicts insomnia or frailty better. The 15-marker and [22-marker](stage6_bbj_insomnia_matched14_z_review.md) screens use different candidate sets and weights, so the 22-marker positive exploratory Z is not a direct paired score comparison. A joint outcome, individual score regression, calibration, discrimination and incremental predictive value cannot be calculated from these summary data.

For each marker, `z = oriented beta / SE` assumes the BBJ source uses standard SAIGE Allele2 coding, while `a = weight × sqrt(2p(1−p))` uses BBJ counted-allele frequency. The test is `aᵀz / sqrt(aᵀRa)`, where `R` is within-chromosome reference genotype correlation and cross-chromosome correlations are zero. The FFS source weight direction remains inferred, and allele and multiallelic conventions need further confirmation. These 13 markers' reported normal and saddlepoint p-values coincide at the supplied precision; this does not make the aggregate statistic a score-level saddlepoint test or prove calibration with 389 cases. Target LD, sample or relative overlap and phenotype comparability remain uncertain; the remote 1000 Genomes reference VCF was not full-file checksum verified. These post hoc p-values are unadjusted for prior selection and analyses, and the estimated reference covariance is not a formal comparison of predictive performance.

Reproduce with `python3 outputs/stage6_bbj_fi_ffs_weight_sensitivity.py`; the [receipt](stage6_bbj_fi_ffs_weight_sensitivity.json) records input hashes and all reference sensitivities, and the [component table](stage6_bbj_fi_ffs_weight_components.csv) lists marker frequencies and case-count approximations. The [BBJ source review](stage6_bbj_insomnia_candidate_review.md) and [cohort independence audit](stage6_japanese_source_independence_audit.md) contain source details. Individual-level FI-versus-FFS predictive validation and an FI with sleep items removed remain outstanding.
