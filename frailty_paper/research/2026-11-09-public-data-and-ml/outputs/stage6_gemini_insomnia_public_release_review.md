# GEMINI public GWAS: insomnia validation feasibility

Checked 29 October 2026. The public [GEMINI summary-statistics collection](https://doi.org/10.5281/zenodo.14284046), version 1.1 (resolved record DOI 10.5281/zenodo.19890575), contains an insomnia GWAS and a sleep-apnoea GWAS among 73 listed files including `conditions.txt`. The record's `conditions.txt` describes the insomnia file as **UK Biobank only** and lists sleep apnoea as a UK Biobank–FinnGen meta-analysis. No filename in the release contains “frail” or “frailty”. The insomnia file is therefore not an independent test of the project's UK Biobank-derived insomnia discovery results; the sleep-apnoea meta-analysis likewise contains discovery-cohort participants and is a different phenotype. Neither provides linked participant genotypes and outcomes or tests the project's score performance.

The [dataset record](https://datasetcatalog.nlm.nih.gov/dataset?q=0002968671) reports that v1.1 corrects standard errors to account for Firth correction, reruns meta-analyses and makes other QC changes. If this resource is used for future exploratory disease context, pin the exact version, phenotype definition, cohort composition, file checksum and allele convention; avoid mixing v1 and v1.1 statistics. This is a release-inventory and metadata check only: the GWAS files were not downloaded, their candidate coverage and effect conventions were not checked, and no new association was calculated.

Recheck with `curl -fsSL https://zenodo.org/api/records/14284046` for the resolved record and file names and `curl -fsSL https://zenodo.org/api/records/19890575/files/conditions.txt/content` for cohort metadata. A filename search is not proof that no related phenotype exists under a different label.
