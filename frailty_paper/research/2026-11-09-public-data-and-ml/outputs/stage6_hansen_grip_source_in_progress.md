# Hansen 2026 African grip GWAS: pending candidate lookup

A new public source was identified through the GWAS Catalog v2 grip-strength ontology query: [GCST90854255](https://ftp.ebi.ac.uk/pub/databases/gwas/summary_statistics/GCST90854001-GCST90855000/GCST90854255/) from [Hansen et al.](https://www.sciencedirect.com/science/article/pii/S0002929726002727). Catalog metadata describes 1,652 sub-Saharan African ancestry participants, handgrip labeled in kg, GRCh38 coordinates, age and sex adjustment, and a genomic-relatedness-matrix random genetic effect. The file is explicitly not harmonized and its imputation panel combined 1000 Genomes Phase 3 with African whole-genome sequence reference data. The full sample described in the paper is 2,124 and should not be substituted for the grip-specific 1,652.

The public compressed summary file is being downloaded. Expected publisher MD5: `f634c1ceadf8bd32e98b311aab8a973f`. Once complete, `python work/hansen2026/extract_candidates.py` checks the full-file MD5 before scanning every record for the 22 existing GRCh38 positions and allele pairs. Check file coding and reference-allele convention before interpreting signs; mark palindromic sites and multiallelic ambiguity. The current local file is incomplete and **must not be analyzed** until checksum passes.

This small different-ancestry dataset offers an exploratory external candidate-to-grip comparison, subject to power, ancestry differences, selection of the 22 markers and participant overlap verification. Grip is a single frailty-related component, not FI or FFS, and no linked participant genotypes were made available; it cannot independently validate score prediction or a shared insomnia–frailty causal signal. The [study code repository](https://github.com/TishkoffLab/ComplexTraitsAnalysis_AfricanCohort_2026) says participant phenotype input is not public. Discovery sample independence from this specific African cohort is plausible by study descriptions but not individually verified.

**Unit discrepancy to resolve:** the source GWAS metadata labels grip in kilograms, whereas the authors’ [trait-preparation notebook](https://github.com/TishkoffLab/ComplexTraitsAnalysis_AfricanCohort_2026/blob/main/trait_data_prep/trait_data_prep.ipynb) labels the original grip variable `Grip_strength:N` (newtons) and also constructs standardized residuals. The checked EMMAX README does not identify which of those columns was passed to its phenotype input. Until this is resolved, the lookup records betas in **unverified source units**, never kg, and numerical units should not be interpreted. This discrepancy does not by itself establish that directions are wrong.

Source code repository inspected at commit `0fb8861210a01ce8901942bf23f0be22623c5a0c`. The `gwas/README.txt` describes generic phenotype input files but does not map them to original or transformed trait columns, so it does not resolve the units. The article's acknowledgment mentions UK Biobank for analyses in the paper; this accession's metadata instead identifies the African sample. Do not infer that every result in the paper is independent of UK Biobank; inspect accession-specific methods and overlap before using it for replication.

The [GWAS-SSF specification](https://github.com/gwas-catalog/summary-statistics-standard/blob/main/gwas-ssf_v1.1.0.tex) defines `ref_allele` values `EA` and `OA` as indicating that the reference allele is the effect or other allele, respectively. This is a field definition, not independent verification that every submitted record is oriented correctly; the source explicitly states it is not harmonized. Store the source coding, flag palindromic or multiallelic cases, and verify against a trusted GRCh38 reference before drawing allele-direction conclusions.

To improve throughput while preserving the original live transfer, a second transfer in eight explicitly checked HTTP byte ranges is running separately. It writes a distinct assembled file and verifies the same complete-file MD5 before marking it usable. Running sessions and temporary parts are not results.

**Age applicability:** The [published paper](https://www.sciencedirect.com/science/article/pii/S0002929726002727) says all subjects were at least 18 years old, and describes populations from eight sub-Saharan African countries. It does not establish that the 1,652 people in this specific grip analysis were older adults. Age adjustment is not equivalent to restricting to late life. This limits comparison with frailty GWAS in older cohorts, apart from grip being only one physical component.

The queued lookup now preserves the source variant ID and reference-allele indicator and records whether the source's own reference-base field agrees with its own variant ID. It also compares the candidate allele frequency to the project's 1000 Genomes AFR-group reference frequency. This is a diagnostic, not proof of strand correctness: the study comprises diverse African populations, so frequency differences may reflect real population differences as well as coding problems. The 22 counted alleles were checked against the reference-frequency table and all 22 names agree. The external-reference frequencies are not participant-level data and this comparison does not validate the score.
