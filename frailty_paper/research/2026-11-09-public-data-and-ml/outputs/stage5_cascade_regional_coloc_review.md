# Public CASCADE regional colocalization lookup

We queried the public CASCADE `coloc/by_region` endpoint for fixed ±250 kb windows around each of the 23 exploratory GRCh38 markers. All 23 requests returned a `pairs` array; `stage5_cascade_regional_coloc_pairs.csv` retains 3,898 returned rows and the marker and region used for each query. Windows can overlap and repeat records; 3,877 distinct pairs remain under the documented source/dataset, phenotype, cell, credible-set and lead-variant identifiers. No unit of analysis here is an independent variant or replication. The raw HTTP responses, request URLs and hashes are in `stage5_cascade_regional_coloc_raw.zip` and `stage5_cascade_regional_coloc_receipt.json`.

According to the [CASCADE methods page](https://cascade.finngen.fi/about), these are precomputed SuSiE-coloc comparisons against FinnGen R12 and the browser displays PP.H4 > 0.5. They are a selected set of significant-enough results, not all tested comparisons. The phenotype-code directory endpoint returned no entries during this search, so code-to-label mappings and the exact set of tested sleep or frailty phenotypes could not be independently established. No returned phenotype code contains the strings `insomn`, `sleep` or `frail`; that simple string check does **not** prove that related phenotypes were absent or that colocalization was tested and failed. Other GWAS such as Mak FI and Ye FFS are not recreated by this portal lookup.

The ±250 kb rs7734045 (`chr5:136202653:A>C`) region query returned four pairs, all between TGFBI eQTLs in monocyte contexts and FinnGen codes `I9_DISVEINLYMPH` or `I9_VARICVE`; PP.H4 ranged approximately 0.867–0.918. These pairs involve different reported lead variants and a different candidate gene; they are not SMAD5–insomnia or SMAD5–frailty colocalization, and the regional result does not mean rs7734045 itself is causal for those phenotypes. The rs323509 query returned no pairs. The FOXP2-region marker rs12536335 query returned 16 pairs for weight/BMI or a coded lab phenotype with several molecular features, none labeled FOXP2; an absent FOXP2 row is not proof that no FOXP2 association exists or that it could not colocalize under another analysis.

FinnGen molecular and disease cohorts can overlap. Portal selection thresholds, phenotype and source availability, the underlying molecular credible sets, LD, priors and signal resolution affect these results. Regional overlap, even with high PP.H4, does not establish that the project's marker, gene or causal mechanism is responsible. These results are context, not independent confirmation of a shared insomnia–frailty mechanism.

Reproduce using `python3 outputs/stage5_query_cascade_regional_coloc.py`. The endpoint and data can change; the archived raw responses and receipt preserve this retrieval. The coordinate convention of the query boundaries has not been independently established; the broad windows are used for contextual lookup, not nucleotide-level overlap assertions. The marker-level evidence and previously derived QTL analyses remain in `stage5_cascade_multiome_readme.md`, `stage5_cascade_effect_allele_crosscheck.md` and the project atlas.
