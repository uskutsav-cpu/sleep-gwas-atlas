# TPMI effect-allele audit

**Update, 28 October 2026:** A [comparison with the authors' supplementary table](stage6_tpmi_published_allele_comparison.md) finds that three selected browser effects, including one for organic/persistent insomnia, match published effect-allele-labeled betas when the browser ALT is the effect allele. This is stronger source-specific support, but it does not verify the exact production transformation or all project-marker contrasts.

The [TPMI browser About page](https://pheweb.ibms.sinica.edu.tw/about) states that it uses PheWeb 1.3.16 and GRCh38. The [PheWeb developer documentation](https://github.com/statgen/pheweb) specifies that its `beta` is the effect of the alternate allele and that `ref` must match the selected reference genome. This establishes the software's expected input convention, not by itself that TPMI's published browser was populated without a source-specific coding error.

The [TPMI authors' analysis repository](https://github.com/TPMI-Taiwan/tpmi/tree/main/3.2-SAIGE_GWAS) runs SAIGE with `--AlleleOrder=ref-first`. The same repository's [known-locus code](https://github.com/TPMI-Taiwan/tpmi/blob/main/4.1-PGRM/PGRM.R) extracts the fourth colon-delimited SNP component as `EffectAllele`, and the [fine-mapping wrapper](https://github.com/TPMI-Taiwan/tpmi/blob/main/4.2-FineMapping/fine-mapping.sh) references SAIGE's `AF_Allele2`. These conventions are consistent with an ALT-effect interpretation, but the repository scripts examined do not expose the complete production transformation from the exact released SAIGE file to the PheWeb `beta` column. In particular, the SNP-string schema and source-to-browser conversion were not independently traced for the displayed records. A separate Taiwan Biobank website states ALT effect coding, but it is a distinct browser and is not definitive documentation for TPMI.

Therefore ALT can be used only as an explicitly conditional hypothesis for these browser results; the inventory keeps `effect_allele_verified = false`. Do not calculate a directional score test or call allele concordance until the actual TPMI source file and transformation or source-specific confirmation establishes it. Other limitations remain: three of 15 markers not verified, rounded values, multiple testing, clinical sleep-disorder phenotype broader than insomnia, ancestry-matched LD and cohort non-overlap not established, and no linked individual-level outcomes. The local copy of the official repository was inspected at commit `4095899922ba9a49e1bf6727b55b6558a6ebac51`.
