# Ye FFS genome-wide MAGMA and cell-type analysis

The Ye Fried frailty score genome-wide MAGMA gene-property analysis tested **102 cell-type variables across six selected expression matrices**. None passed BH q < 0.05 across that 102-test family. The lowest nominal p-values were human-cortex neurons (p = 0.00147), a source-labeled human-cortex `hybrid` group (p = 0.00172), and mouse brain-vascular `FB1` (p = 0.00219); each had BH q = 0.0744. These q < 0.10 results are exploratory, depend on the selected matrices and model, and are not validated cell types for shared insomnia–frailty risk. [All cell-type results](stage4_magma_cell_type_exploratory.csv); select trait `ye_ffs` for these 102 rows.

The source labels `hybrid` and `FB1` are retained as provided; their precise biological identities require source-level annotation review. Mouse brain-vascular expression values were mapped by the source to human gene IDs, so that test is cross-species. The six matrices cover human cortex and PBMCs plus mouse hypothalamus, brain vasculature and two muscle references; they do not cover every requested population, and their selection was made after data availability review. The [matrix receipt](stage4_fuma_matrix_receipt.json) records the source files and local hashes. Donor composition and processing differences need further investigation. No direct insomnia enrichment or formal overlap test is included in this FFS analysis.

## Genome-wide gene analysis

I used the project's public Ye FFS summary statistics, treated as the continuous 0–5 Fried-criteria score described in the study, and MAGMA v1.10 SNPwise-mean with the 503-person 1000 Genomes Phase 3 European GRCh37 LD reference. The reference files match the archived manifest's hashes; it is a limited reference and may not fully match the GWAS ancestry or LD. Ensembl v92 coding-gene windows extend 1 kb upstream and downstream. MAGMA analyzed 19,015 genes; 854 have BH q < 0.05 across these 19,015 gene tests. [Full gene results](stage4_ye_ffs_magma_gene_results.csv). This is FFS association evidence; a gene-based p-value does not identify a causal variant or show an insomnia association.

The Ye source lacked per-variant sample size, so I used the reported total N = 386,565 as a constant approximation, not a verified N at every marker. rsIDs were matched to the reference with MAGMA's duplicate and synonym exclusions; a fixed partial coordinate audit found no coordinate mismatches among 7,824 directly matched sampled Ye IDs, but it does not validate unsampled variants or all synonyms ([audit](stage4_magma_reference_coordinate_sample_audit.json)). Input p-values were used as provided and may be rounded. The GWAS is UK Biobank based; its results are not independent of other UK Biobank analyses in this project. The calculation is not a clinical prediction model or a direct comparison of FI and FFS.

For each matrix, MAGMA regressed genome-wide gene association statistics on one cell-type expression covariate while conditioning on the source matrix's overall `Average` expression and MAGMA's internal gene-size, density and inverse-MAC covariates. Tests were one-sided for positive association. Per model, 14,155–19,015 genes contributed. BH correction was applied across all 102 cell-type variables from the six matrices for this trait; these are overlapping, correlated tests and the exploratory selection was not preregistered. A result would indicate an expression–gene-association relationship, not proof of a causal cell type or a specific variant–gene mechanism.

## Output metadata correction and verification

The original MAGMA output reported an incorrect `MEAN_SAMPLE_SIZE` header for four matrices, and omitted it for two. Source inspection found that `mean_sampsize()` summed per-gene N into a 32-bit integer; the expected sum exceeds its range. The resulting signed overflow reproduces the observed headers exactly. In the available source, that function is called to write output metadata, not to run the regression. The gene-result file itself records N = 386,565 for each gene.

To check this on the actual data, I built a workspace-local variant changing only the accumulator to a 64-bit integer, reran all six gene-property models, and compared complete non-comment result rows: variables, gene counts, betas, standard errors and p-values were identical to the original output, while all headers correctly reported 386,565. An unmodified relinked binary also reproduced the original human-cortex result. The [validation receipt](stage4_magma_sample_sum_validation.json) records hashes and checks. This supports the conclusion that this particular metadata error did not change the observed six regression tables; it does not validate every component, the source GWAS, the constant-N approximation, or the model's biological assumptions. The main results file contains the original model table values and does not use the erroneous header as an input.

The FI and FFS gene analyses use separate study inputs and are still being evaluated; a shared cell-type signal requires additional appropriately controlled trait comparison. In particular, the three FFS q < 0.10 findings should not be interpreted as shared insomnia–frailty biology.
