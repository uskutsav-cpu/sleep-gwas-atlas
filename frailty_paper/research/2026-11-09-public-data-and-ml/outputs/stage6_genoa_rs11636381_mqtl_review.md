# GENOA blood-methylation screen at rs11636381

We scanned the checksum-verified chromosome 15 summary file from the public [GENOA study](https://doi.org/10.5281/zenodo.7697509), which analysed cis-methylation QTLs in whole blood for 961 African American participants. Using GRCh37 position 15:74134883 and the C/T allele pair, we found 38 CpG-association rows for rs11636381. The variants were tested within 50 kb of each CpG. The source README labels C as the minor allele and T as the major allele at this marker, but does not explicitly specify the beta's counted allele, so its direction is not harmonized to our score.

The smallest reported p-value among these 38 rows was for cg03789871, 24,632 bp from the candidate: β = −0.2223, SE = 0.0581, p = 1.379×10⁻⁴. Multiplying by 38 gives a within-this-screen Bonferroni value of 0.00524. This is a post hoc descriptive correction for this one candidate's returned CpGs, not a study-wide or project-wide multiple-testing correction, and does not establish independent replication. The returned p-values, effect scale, imputation quality and allele direction require verification against the full methods before interpretation. The other 37 rows and all study results should not be treated as untested merely because they are not highlighted here.

None of the 38 tested CpGs appeared in either of the selected significant frailty methylation tables from Mak et al. This comparison uses only those tables, not the complete frailty EWAS; absence is not a negative association. The prior site cg12594244 is outside GENOA's tested window for the candidate. Thus this result is a new **blood methylation hypothesis**, not evidence that this CpG is associated with frailty or insomnia, nor proof of a causal gene, shared causal variant, cell type or score performance. It also does not validate the earlier GoDMC HTTP response. Study overlap and population-specific LD require checking before cross-study interpretation.

Follow-up should obtain full frailty EWAS estimates for cg03789871 and an independent mQTL dataset with a confirmed counted allele and ancestry-matched LD. Evaluate probe reliability, additional independent molecular signals and coloc assumptions before asserting a mechanism; a shared gene name or proximity is insufficient.
