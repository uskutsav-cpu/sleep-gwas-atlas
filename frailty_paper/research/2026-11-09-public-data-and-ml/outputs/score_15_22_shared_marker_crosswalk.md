# Shared markers in the 15- and 22-marker research scores

The two existing prototypes share four rsIDs. The [crosswalk](score_15_22_shared_marker_crosswalk.csv) compares the 15-marker weighted file with the **22-marker equal-weight count**, using the existing files' assumed/inferred GRCh37 positions. Two rows have the same counted allele, and two have reversed allele order: rs4886140 and rs12536335. For a verified biallelic diploid genotype, a dosage of one allele can be converted to the other as `2 − dosage`; this must not be assumed for an unresolved multiallelic contrast, strand, build, or ploidy.

The 15-marker file flags rs1909650 and rs4886140 as having multiallelic reference representations. The prior [CHARGE gait review](stage6_charge_gait_full_candidate_review.md) separately found an unexplained frequency discrepancy for rs4886140, so matching letters or rsIDs alone are insufficient to transfer a genotype or effect across sources. The 22-marker *weighted* file is another distinct convention with eight allele reversals relative to the 22-marker count; see the [within-22 crosswalk](shared22_allele_orientation_crosswalk.csv). Do not mix those two 22-marker definitions.

For rs4886140 specifically, the [gait lookup](stage6_charge_gait_full_candidate_lookup.csv) records source `Allele1=a`, `Allele2=g` and a G-aligned frequency of 0.9714; the project's European reference G frequency is 0.672. The downloaded source README defines `Freq1` as the frequency of the coded `Allele1`, so the recorded G value uses `1 − Freq1`. The approximately 0.299 difference is an audit flag, not proof of an error, strand flip or a particular third allele in either cohort. The reference is a small sample, and the gait file lacks positions. An attempted direct re-read of the original row did not complete, so source-specific min/max frequencies and the cause of this discrepancy remain unverified. Use neither this discrepancy nor the summary row to correct the score automatically.

This is a file-consistency check, not source-allele verification or evidence of score performance. For a future approved cohort, harmonize each complete prototype independently against reference build, alleles, genotyping and imputation, then calculate the frozen sums on the same eligible participants. Source confirmation of FFS weight direction and exact multiallelic contrasts remain necessary before interpretation.

## Scorer limitation for multiallelic calls

The current 15- and 22-marker scripts check that the two supplied allele labels match a model pair, but the input contains no third-allele dosage or independent proof that a genotype is biallelic. Therefore the scripts **cannot enforce** their documented biallelic precondition. For example, an actual A/T genotype at an A/G/T site has A dosage 1 and G dosage 0; converting A to G as `2 − 1` incorrectly gives 1. The numerical input checks and reference arithmetic tests do not detect this. For flagged variants, obtain an appropriate per-allele dosage and source representation, establish the modeled contrast and any third-allele handling, and verify them before using either script. A direct G dosage alone does not establish that a GWAS effect estimated for a G-versus-A contrast applies to G-versus-other alleles in a multiallelic cohort.
