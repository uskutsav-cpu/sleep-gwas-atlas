# rs323509-region molecular-gene identifier context

The selected testis splicing QTL is reported using Ensembl gene ID **ENSG00000251574** (GTEx v10 version `.8`). The current [NCBI Gene record](https://www.ncbi.nlm.nih.gov/gene/105379109) cross-references this Ensembl ID to **LOC105379109**, describes it as an uncharacterized noncoding RNA and reports restricted expression toward testis. The [Bgee gene page](https://www.bgee.org/gene/ENSG00000251574) uses the name **AC099520.1**; nomenclature and annotation releases differ. These identifiers are contextual cross-references, not a reason to overwrite the exact source ID or assume every transcript model is identical across releases.

An uncharacterized noncoding RNA does not provide an established biological mechanism linking the rs323509 region to insomnia or frailty. Reported tissue expression likewise does not show that the splice event has a causal effect, and the selected testis evidence may not reflect a relevant tissue. Review the [pairwise colocalization and its prior/coverage limitations](stage3_rs323509_testis_colocalization.md) and the [evidence-informed work order](stage3_evidence_informed_work_order.md). The source trait inputs may overlap, so even two high pairwise H4 values cannot be treated as an independent three-trait result.
