# Public All of Us difficulty-walking follow-up

A subsequent [insomnia–walking max-p screen](stage6_aou_insomnia_walking_eur_conjunction_review.md) found one nominal association with both phenotypes but none passing BH adjustment across 33 postselected candidates.

The All by All [public phenotype catalog](https://allbyall.researchallofus.org/) includes PhecodeX `NS_325.2`, “Difficulty walking,” with 5,748 cases and 279,608 controls reported across the browser's overall sample. Those are not counts for the EUR genetic-similarity subgroup or necessarily for each variant. The same catalog includes `NS_325`, “Abnormality of gait and mobility,” and `NS_350.5`, “Repeated falls,” but did not list an explicitly labeled frailty phenotype in the keyword search. The query is a limited label search, not evidence that the cohort lacks relevant underlying clinical information.

We retrieved **33 of 33** project-variant associations for difficulty walking in the EUR genetic-similarity group using the public Hail-backed genome endpoint. Four had nominal p < 0.05, and **none passed BH 5% across those 33 postselected tests**; the smallest p was 0.00361 for rs12536335 (BH q = 0.119). This is not independent confirmation of a variant, a null finding, or evidence that FOXP2 is causal. Exact coordinates and REF/ALT labels matched existing project mappings, but the full source and target allele contrast, discovery overlap and per-variant participant counts still require verification.

We additionally applied the existing conditional weighted-Z sensitivity to the seven score constructions using a 503-person 1000 Genomes EUR reference LD matrix. Six nominal p values exceeded 0.05; the 22-marker insomnia-weight sum had conditional Z = 2.03, nominal p = 0.0425. **None passed BH 5% across these seven score comparisons** (minimum q = 0.143). This multiple-testing family does not cover the many prior project analyses or the earlier insomnia and weakness tests; it is descriptive, not a prespecified replication. The seven statistics share variants and are correlated; BH's assumptions and the precision of these nominal tests are not guaranteed. A single marginal p value cannot support selecting a winner or stating that the score predicts walking difficulty. The [other outcome results](stage6_aou_eur_weighted_z_sensitivity_review.md) must not be compared by Z value as a formal test of phenotype differences.

A difficulty-walking EHR code is not objective gait speed, the Fried physical-frailty phenotype, a deficit FI, a longitudinal outcome or a joint sleep–frailty measure. The score-level statistic combines marginal associations, not participant-level scores. It assumes the browser beta is ALT-oriented, biallelic diploid reversals are valid, HWE variance and external EUR LD approximate the target data, and variant Z statistics have compatible sample size and covariance. The [pipeline/source-code check](stage6_aou_eur_weighted_z_sensitivity_review.md) supports but does not fully verify the ALT convention, particularly for multiallelic variants; FFS weight orientation is still inferred. The sample and related-person overlap with all discovery sources remains unverified, and All of Us was included in a previously inspected meta-analysis. The input candidates and analysis choices were postselected. These data cannot validate the score, estimate discrimination or calibration, or exclude a smaller association.
