# FinnGen R13 insomnia associations across the queue

The [table](stage5_finngen_insomnia_exact_queue.csv) records the result of an exact chromosome, position, REF and ALT join between all 488 Stage 5 alleles and the frozen FinnGen R13 `F5_INSOMNIA` regional cache. There are 474 exact matches, including 24 indels, and 14 alleles with no exact row in this cache. The cache was generated from a source presumed to be GRCh38 and is limited to windows around project markers. No-match is not a zero effect and may reflect filtering, representation, missingness or location.

FinnGen documents ALT as the effect allele; the reported beta and standard error come from the source and the binary endpoint's beta is on the log-odds scale. For 415 previously retained aligned rows, beta and p-values agree with the exact cache extraction. See the [audit](stage5_finngen_insomnia_exact_queue_audit.json), [frozen cache receipt](stage3_gwas_regional_cache_receipt.json), and [FinnGen field documentation](https://github.com/FINNGEN/finngen-documentation/blob/master/data-download.md). The exact source allele match does not independently reauthenticate the original source build or study eligibility.

For the FOXP2 insertion chr7:114534306 T>TA, the cache contains an exact row with ALT beta 0.0132579, SE 0.00672018 and nominal p 0.0485121. This is an unadjusted, postselected association, not strong evidence after multiple comparisons, a causal assignment, or an AlphaGenome indel score. Compare it in the context of linkage disequilibrium, uncertainty, coverage and appropriate independent replication. These summaries do not establish shared risk with frailty or colocalization with molecular QTLs.

The [variant–gene–tissue atlas](stage5_variant_gene_tissue_evidence_atlas.csv) includes the exact-match status, p-value and ALT beta; values repeat across gene/tissue rows and must not be counted as independent tests. Full AlphaGenome predictions and tissue/event-matched validation remain outstanding.
