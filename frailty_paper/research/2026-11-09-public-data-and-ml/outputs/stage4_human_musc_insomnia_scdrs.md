# Human muscle stem-cell insomnia scDRS analysis

In the public [Kedlian et al. human muscle aging atlas](https://doi.org/10.1038/s43587-024-00613-3) muscle-stem-cell subset, **none of four annotated stem-cell groups showed an insomnia gene-program association after correction across these four groups**. The smallest group-association Monte Carlo p was 0.254 for the broadly labeled MuSC group, BH q = 0.444. The full [group results](stage4_human_musc_insomnia_scdrs_groups.csv) include cell counts and separate within-group heterogeneity tests, adjusted as their own four-test family. This result does not rule out muscle involvement, evaluate other muscle populations, or test shared insomnia–frailty genetics.

The dataset contains 17,528 cells from 12 represented donors: 13,551 MuSC, 1,970 ICAM1+ MuSC, 1,902 TNFRSF12A+ MuSC, and 105 MYOG+ MuSC. This is a subset of the Kedlian atlas, a separate resource from the larger multimodal atlas discussed in the project. One cell passed the scDRS cell-level FDR < 0.10 threshold; that isolated result is not evidence of a subtype or independent biological replication.

The [donor cell-count table](stage4_human_musc_donor_cell_counts.csv) and [donor score contrasts](stage4_human_musc_donor_score_contrasts.csv) show sampling imbalance. The latter are descriptive within-donor differences in mean normalized scDRS score between each group and other cells, requiring at least 10 cells on each side; they are neither independent disease-control comparisons nor a formal donor-level genetic enrichment test. The small MYOG+ group met the threshold in only three donors. Donor indicators in scoring help adjust mean differences, but the scDRS cell-group Monte Carlo tests are not donor-aware inferential tests and do not turn cells into independent donors. The genome-wide insomnia gene set, group definitions, covariate model, reference choice and four-test family were exploratory and require independent replication.

## Methods and provenance

The [downloaded expression file](https://cellgeni.cog.sanger.ac.uk/muscleageingcellatlas/SKM_MuSC_human_2023-06-22.h5ad) opens as an AnnData object. The [input receipt](stage4_human_musc_input_receipt.json) records size, SHA-256, labels and limitations; no provider checksum was independently verified. The matrix was treated as already normalized: in four inspected cells its values were consistent with `log1p` of counts scaled to 10,000 using the source `n_counts` metadata. The full source transformation was not independently verified. No raw count layer is present.

We used the scDRS authors' public human weighted gene set `PASS_Insomnia_Jansen2019` ([data release](https://figshare.com/articles/dataset/scDRS_data_release_030122/19312583)); 691 genes remained after expression filtering. scDRS v1.0.4 development commit `644a5c7900d3c8d84c068725b47dd81e0db22ffb` used 1,000 mean/variance-matched control gene sets, normalized input (`flag_raw_count=False`), and covariates consisting of an intercept, gene-detection count and 11 donor indicators. Gene-set SHA-256: `ac20170a05e6d7411ca48ffad381a1f7ec4c71704da7e7d1c120ccf0eda84c92`; covariate-file SHA-256: `660df1fa5d936a20739f79029694c13516c93002aa9a1f7a42045078db64ea78`.

The first downstream run failed because Scanpy called `getnnz` on a SciPy sparse array. A local wrapper exposed the array's `_getnnz` method as `getnnz`; a small example matched the equivalent `csr_matrix` method. The subsequent run finished all four group tests. This compatibility check does not independently validate the whole pipeline. Group tests used scDRS's control-score-based procedure; BH was applied to four group-association p-values, and separately to four heterogeneity p-values. The tested gene set derives from an insomnia GWAS and is not a gene set for FI, FFS or shared risk.
