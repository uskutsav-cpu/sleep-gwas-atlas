# Expanded AlphaGenome Atlas SNV scores

The indexed public AlphaGenome Variant Impact (AVI) table supplied by the [Genomic Resource Repository](https://grr.iossifovlab.com/hg38/scores/AVI/index.html) yielded exact-allele matches for all 460 single-nucleotide variants in the frozen 488-variant Stage 5 queue. The other 28 variants are insertions or deletions and are not covered by this SNV-only table. Inputs include the 23 exploratory markers, molecular credible-set variants, and 23 matched controls; some entries belong to multiple classes.

The [expanded atlas](stage5_expanded_functional_atlas.csv) adds `atlas_avi_raw_indexed` and `atlas_avi_phred_indexed` to the earlier evidence table. Existing `status` and display-score columns describe the earlier web-interface collection and were retained for provenance; use the new indexed columns for current SNV coverage. The [score-only table](stage5_all_snv_atlas_avi_precise.csv) provides the published decimal scores, exact alleles, input classes and source. Blank scores for indels mean unavailable, not zero.

Scores were obtained by indexed byte-range queries to the public 88 GB bgzip file rather than downloading the full file. The downloaded tabix index MD5 matched the repository's published checksum. The whole data file's MD5 was recorded as reported by its publisher and was not independently verified because only selected ranges were retrieved. Coordinates and alleles were matched against the reference-checked GRCh38 queue. All 69 distinct variants with available rounded web-interface values agreed to within the expected 0.05 rounding tolerance; see [cross-check](stage5_avi_web_index_crosscheck.csv) and [audit](stage5_indexed_avi_audit.json).

AVI is a general predicted molecular impact score, not a measure of insomnia or frailty risk, effect direction, disease causality, a causal probability, gene assignment, or cell-type specificity. It combines model-derived signals with other annotations, including conservation; its magnitude must not be interpreted as an independent biological validation. Molecular credible-set membership comes from molecular QTL fine-mapping rather than disease fine-mapping. Nearby genes are candidate context, not established causal targets. Matched controls are postselected comparisons, not proven neutral variants.

The complete requested analysis still needs tissue-resolved RNA, splice and chromatin predictions, including the 28 indels, followed by carefully matched QTL and independent functional validation. AVI cannot substitute for those outputs. The official AlphaGenome scoring API requires a key; creating one in the signed-in account requires the user's explicit authorization. No key is contained in these files.
