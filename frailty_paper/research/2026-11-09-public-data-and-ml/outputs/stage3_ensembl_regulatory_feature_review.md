# Ensembl regulatory-feature proximity for all candidate markers

Using Ensembl REST **release 116**, I queried each of the 22 shared candidates plus rs323509 at its assumed GRCh38 coordinate and in a ±10 kb window. All 23 exact-position and 23 window requests completed. The exact-position requests returned **no overlapping Ensembl regulatory-feature records**. The window requests returned 58 feature records near 16 markers; the [complete results](stage3_ensembl_regulatory_10kb.csv) list positions, feature IDs, annotations, distances and query URLs. The seven remaining markers had no features returned in the chosen window.

These are limited release-specific queries, not a claim that the variants lack regulatory function or an exhaustive search of all enhancer maps. A nearby feature does not mean the variant overlaps or alters it, that it is active in relevant cells, or that it regulates the nearest gene. The source feature records do not provide a tested enhancer-to-gene link for this analysis.

Examples: rs7734045 is **8 bp outside** an Ensembl feature labeled enhancer `ENSR5_B322S9`; rs12536335 is 2,398 bp from an annotated enhancer `ENSR7_85CS4X`; rs34290943 is 1,228 bp from a CTCF-binding-site annotation. No window feature was returned for rs323509. These proximity observations are not causal, tissue-specific or proof of a physical chromatin interaction. The coordinates themselves depend on the project’s provisional mapping from the Song data to GRCh38 and require source-level allele verification.

[Exact-position query receipts](stage3_ensembl_regulatory_overlap_receipts.json) and [window receipts](stage3_ensembl_regulatory_10kb_receipts.json) preserve full responses and hashes. As a basic service check, a broader independent 100 kb query in the chromosome 7 region did return regulatory features, so the endpoint can return records; this does not establish completeness of the release. A subsequent analysis must use credible variants, tissue-matched accessibility and independently documented enhancer–gene links before asserting a distal regulatory mechanism. The [variant–gene table](stage3_initial_variant_gene_table.csv) includes these features with their noncausal status.
