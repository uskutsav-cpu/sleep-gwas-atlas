# Frailty and insomnia GWAS: reciprocal-build exact-allele matches

The [table](stage5_grch37_gwas_exact_queue.csv) reports the outcome for each of the 488 queue alleles in each of five frozen regional GWAS caches: Atkins FI, Jansen insomnia, Mak FI, Mak physical frailty, and Ye FFS. For 405 non-palindromic SNVs, the GRCh38 position mapped uniquely on the positive strand to GRCh37 and back to the original position using UCSC chain files. We required an exact source A1/A2 allele-pair match and a unique source row. The 28 indels and 55 palindromic SNVs were deliberately not converted here; a missing or excluded result does not mean no association.

The numbers of unique matches are Atkins FI 394, Jansen insomnia 394, Mak FI 403, Mak physical frailty 403 and Ye FFS 404. The [mapping table](stage5_queue_snv_reciprocal_liftover.csv) and [audit](stage5_grch37_gwas_exact_queue_audit.json) preserve exclusions, source-cache and chain checksums, and comparisons. Reverse mapping agrees with all 23 previously audited markers. Of the earlier aligned regional results, 1,472 eligible rows matched the new ALT-oriented beta and p-value without discrepancies.

The source build is inherited as GRCh37 and was not independently authenticated for every file. Reciprocal coordinates and matching allele pairs do not independently verify the reference sequence at every GRCh37 position. Effects are aligned to the GRCh38 ALT using the source A1 coding; the Ye A1 effect convention was inferred in earlier project work and remains an explicit limitation. FI, physical frailty, FFS and insomnia are different outcomes, with different scales and potentially overlapping cohorts. Repeated associations, nominal p-values, and an exact match do not establish disease causality, independent replication, colocalization or shared risk. These are previously selected regions, not a genome-wide discovery analysis.

The [variant–gene–tissue atlas](stage5_variant_gene_tissue_evidence_atlas.csv) links available trait sources per allele; multiple gene/tissue rows repeat the same GWAS result and are not independent tests. Live AlphaGenome prediction and independent functional validation remain outstanding.

A subsequent check queried the UCSC hg19 reference for all 405 mapped SNVs. Every GRCh37 reference base matched the queue's GRCh38 REF; the [variant-level results](stage5_reciprocal_snv_hg19_reference_check.csv), [audit](stage5_reciprocal_snv_hg19_reference_check_audit.json), and [raw responses](stage5_hg19_reference_query_responses.zip) preserve that check. This supersedes the earlier statement that reference sequence was not checked for each mapped SNV. It does not authenticate the GWAS files' build or prove the reported effect-allele convention, and does not apply to the excluded palindromic SNVs or indels.
