# Provisional European-reference locus LD matrix

The [NumPy matrix](stage5_smad5_muscle_eur_reference_ld.npz) contains a 2,345 × 2,345 ALT-dosage correlation matrix: 2,338 SNPs from the existing MAGMA 1000 Genomes European reference and seven exact indels from the publicly indexed Phase 3 VCF. Its `r`, `variant`, and `n_samples` arrays use the explicit [zero-based variant order](stage5_smad5_muscle_eur_ld_variant_order.csv). The [receipt](stage5_smad5_muscle_eur_ld_receipt.json) contains hashes and construction details. The 503 sample IDs are identical in both sources; 10 SNPs sampled across the region agreed at all 5,030 compared genotypes ([spot check](stage5_smad5_ld_reference_genotype_crosscheck.csv)). That spot check does not prove all other genotypes or variants agree.

For the 2,412-variant Mak FI splice-colocalization input, 66 SNPs lacked a unique matching SNP-panel record and one credible-set indel lacked an exact VCF record. The retained matrix covers 38/52 L1 variants (PIP sum 0.650/0.950) and 17/18 L2 variants (PIP sum 0.877/0.956); it is not the full molecular credible-set coverage. The [SNP coverage table](stage5_smad5_splice_snp_ld_reference_coverage.csv) identifies the missing SNPs. Different GWAS comparisons may require different variant intersections and should not reuse this matrix without reindexing and allele checks.

All reference variants are oriented to the Stage 5 alternate allele. Missing genotypes were mean-imputed per variant; the symmetric matrix is a Pearson correlation matrix and has unit diagonal. Its 21 indel-pair correlations agree with the previously calculated pairwise-complete results within 2.3 × 10⁻⁸. With only 503 samples, the centered matrix rank is at most 502 despite having 2,345 variants; rare variants, LD mismatch and numerical singularity can make summary-statistic fine-mapping unstable. The 503 EUR samples include Finnish individuals, but this is not an ancestry-matched Finnish LD matrix for the FinnGen comparison.

**No SuSiE or multi-signal colocalization has been run.** Reliable interpretation requires adequately covered and ancestry-matched QTL and GWAS variants, diagnostics for summary-statistic/LD consistency and sensitivity to sample size, LD and model settings. Prior single-signal estimates remain limited by multiple molecular signals. The [construction script](stage5_smad5_eur_locus_ld_reproduce.py) uses the original local reference files and the included public indel dosages; its paths must be adapted outside this workspace.
