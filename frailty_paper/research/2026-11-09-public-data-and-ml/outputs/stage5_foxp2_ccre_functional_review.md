# FOXP2-region candidate element: experimental evidence

The reference allele span of rs12536335 (chr7:114403104 A>G, GRCh38) overlaps ENCODE candidate element EH38E3794718 (chr7:114402903–114403240, BED-style coordinates). [SCREEN](https://screen.wenglab.org/GRCh38/ccre/EH38E3794718/genes) lists FOXP2 as a closest gene (11,203 bp to a transcription start site) and shows 10 intact Hi-C loop records linking the element to FOXP2, including heart, pancreas, placenta, skin, a cell line and an activated T-helper cell. The [recorded links](stage5_foxp2_ccre_hic_links.csv) retain exact experiment IDs and displayed scores. A displayed p-value of 0 is recorded as the website displays it and must not be interpreted as an exact probability of zero. These are contacts in the stated biosamples, not evidence that rs12536335 changes the contact, that pituitary or sleep-related brain cells have the same contact, or that FOXP2 mediates disease.

SCREEN's [functional-characterization page](https://screen.wenglab.org/GRCh38/ccre/EH38E3794718/functional-characterization) also lists six solo-fragment STARR-seq reporter tests. None has a displayed nominal p-value below 0.05; the SH-SY5Y neuroblastoma cell line result is log₂ fold change 0.28, p 0.58, FDR 1.00. All six, including missing FDR values, are in the [reporter table](stage5_foxp2_ccre_starr_experiments.csv). This is element-level testing in the specified cell lines, not an allele-specific A-versus-G test, and a nonsignificant result does not prove absence of activity in other assays or tissues. It should not be described as validation of the model's predicted allelic effect.

Separately, SCREEN displays a GTEx v8 pituitary FOXP2 eQTL for this same GRCh38 allele (slope 0.235, p 3.82 × 10⁻¹⁵). The project's existing GTEx v10 record is related rather than independent replication; both must be interpreted with sample overlap and model-training overlap in mind. Full-precision tissue- and allele-matched AlphaGenome scoring and a variant-specific functional assay remain necessary for a meaningful directional validation.
