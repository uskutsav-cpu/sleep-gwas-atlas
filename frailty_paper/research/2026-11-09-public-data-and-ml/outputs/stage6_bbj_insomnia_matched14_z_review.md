# BioBank Japan insomnia: matched 14-marker summary sensitivity

Using the same 14 counted alleles previously used for Taiwan insomnia and Japanese knee strength, the conditional reference-LD weighted marginal-Z statistic for Japanese insomnia is **2.89** (nominal two-sided p = **0.0039**) with a 104-person 1000 Genomes Japanese (JPT) reference. This is an exploratory association screen for a postselected subset, **not** a measured score effect or an independently validated prediction. The sample has 389 diagnosed cases and 177,864 controls; ascertainment, unverified sample overlap, small reference LD, allele coding and previous selection and multiple analyses all limit inference. The nominal p-value is not corrected for the broader set of searches and is not a prespecified replication p-value.

| LD reference and marginal input | Z | Nominal p | Leave-one-marker-out Z range |
|---|---:|---:|---:|
| JPT (104), source beta/SE | 2.887 | 0.00389 | 2.456 to 3.302 |
| JPT (104), normal-p-derived Z | 2.887 | 0.00389 | 2.456 to 3.302 |
| JPT (104), saddlepoint-p-derived Z | 2.887 | 0.00389 | 2.456 to 3.302 |
| Pooled EAS (504), source beta/SE | 2.868 | 0.00413 | 2.439 to 3.279 |

The EAS reference includes JPT and is not an independent replication. A leave-one-out range is a descriptive stability check, not a confidence interval or evidence that a shorter score is better. The 14-marker subset excludes rs12524473 because that marker was not available in the knee source; this is a post hoc availability rule, not a prespecified quality filter. Among the selected markers the smallest source minor dosage count is approximately 5,942 across cases and controls; this does not establish adequate counts in cases. These 14 markers have close normal and saddlepoint marginal p-values (maximum absolute log10 ratio ≈ 0.00236), and their beta/SE-derived Z values differ from normal-p-derived Z by at most 0.00217. That observed agreement provides a limited check for this subset; it does **not** turn a linear combination of marginal Z values into a valid saddlepoint test of a score or guarantee well-calibrated aggregate p-values in a highly imbalanced sample. The full 22-marker set includes a very rare variant where the two source p-values differ substantially.

For each SNP the calculation assumes the standard SAIGE Allele2 beta convention and orients it to the prototype's counted allele. Set `a_i = sqrt(2 p_i (1-p_i))` using the BBJ counted-allele frequency and equal per-allele weights. With marginal Z vector `z` and reference within-chromosome genotype-correlation matrix `R` (cross-chromosome correlations zero), compute `aᵀz / sqrt(aᵀRa)`. The reference VCFs were accessed by indexed regions and not full-file checksum verified. This is an approximation to target marginal-Z covariance and relies on genotype coding, frequency scaling, model comparability and reference LD; the target study's actual LD and per-person score were not available. Direction for variants and source sample independence remain unverified.

The prior [matched-set analysis](stage6_cross_population_matched14_review.md) gave Z = 2.27 for Taiwan insomnia and Z = −0.38 for lower Japanese knee strength, using different frequency scaling, references and outcomes. Positive insomnia screens and an uncertain knee estimate are descriptive and do not establish a difference between traits, shared causal risk, or no knee association. They cannot be pooled into a joint-outcome score or compared as predictive performance. FI and FFS are not measured here.

## Marginal-precision sensitivity

The existing frequency-scaled analysis assumes sufficiently comparable target precision across variants. For these 14 available markers, `SE × sqrt(2p(1−p))` ranges from **0.04819 to 0.05005** (median 0.04884; coefficient of variation 0.94%). Replacing the frequency-derived weights in the same fixed-JPT-LD weighted-Z formula with inverse reported marginal standard errors gives **Z = 2.884**, compared with **2.887** originally. This checks sensitivity to this one precision approximation; it does not establish that either statistic is calibrated.

The inverse-SE construction interprets marginal association statistics as score-statistic contributions and assumes their covariance is approximated by external LD. Differences in case/control information, imputation, covariates, sample sets and residual dependence can violate that assumption. The test is postselected, the discovery and target sample independence remains unverified, and the target contains only 389 cases. No patient-level score was computed. Reproduce with `python3 work/bbj_score_precision_sensitivity.py`; [aggregate receipt](stage6_bbj_14_precision_sensitivity.json) and [component table](stage6_bbj_14_precision_components.csv). Remote reference files are not fully checksum verified.

A [case-specific dosage audit](stage6_bbj_insomnia_candidate_review.md) estimates that the smallest minor-allele dosage sum among cases in this 14-marker set is about 18, with two markers below 50, assuming all 389 cases contributed at each variant. Imputed dosage sums are not hard-called allele counts. This adds case-level information to the total-sample minor-dosage check above; it does not verify score-level calibration.
