# Disease GWAS evidence for queued alternatives

The [evidence table](stage5_credible_variants_gwas_aligned_evidence.csv) joins the frozen Stage 3–4 regional harmonized extracts to the Stage 5 queue by exact GRCh38 chromosome, position, reference and alternate allele. It contains 1,887 source rows for 227 distinct queued variants and 1,195 variant–trait-source pairs; 692 rows are repeated across regional analyses of the same GWAS. All repeated pairs have the same displayed beta, SE and p-value in these extracts. The [audit](stage5_credible_variants_gwas_evidence_audit.json) records source file hashes and coverage. The original aligned files are preserved in the Stage 5 frozen archive.

As an example, rs60271 (chr5:104742532 A>C), a testis sQTL credible-set alternative in the rs323509 region, has Jansen insomnia p = 5.159 × 10⁻⁹ and Atkins FI p = 2.96 × 10⁻⁶ in these source extracts. The associations do not establish that the molecular QTL and either trait share a causal variant. The testis sQTL is not evidence of a sleep-relevant tissue by itself.

These files include distinct FI, physical frailty, FFS and insomnia sources, whose measurement scales and cohorts differ and can overlap. GWAS effects are inherited from the original harmonization and its build, allele and filtering assumptions; check each Stage 3–4 receipt before directional analysis. Ye effect coding has an explicit source-inference limitation in earlier reports. Data were filtered for regional and molecular-QTL eligibility, so a variant without a record may have been untested or excluded rather than lacking an association. Indels, palindromic variants and low-frequency variants can be missing. This is not independent replication, a multiple-testing-adjusted discovery, GWAS fine-mapping or a colocalization analysis.

The [long-format atlas](stage5_variant_gene_tissue_evidence_atlas.csv) now lists available exact-variant GWAS sources for each row. Its original direct-marker context remains separate; see the evidence table for the additional alternatives and their source files.
