# Preliminary MEIS1-AS3 cerebellum multi-signal sensitivity

Using existing public data, this postselected sensitivity compared a single 180-kb window (GRCh38 chr2:66,400,000–66,580,000) of eQTL Catalogue GTEx cerebellum MEIS1-AS3 associations against Atkins FI, Ye FFS and Jansen insomnia summaries. Across all four traits, 275 non-palindromic variants had unique matching source alleles and biallelic 1000 Genomes phase-3 EUR genotypes, with eQTL versus reference ALT-frequency difference ≤0.2. Source matches were lifted to GRCh37 for the GWAS sources and aligned to eQTL ALT; Jansen log odds were calculated from reported ORs. The 503-person reference dosage LD matrix had rank 129; the maximum eQTL–reference frequency difference was 0.073. GWAS-to-reference frequencies and exact source handling of multiallelic sites were not checked. Full source cis and conditional-signal coverage are not guaranteed.

SuSiE-RSS converged for all four models using working sample sizes of 209 (cerebellum), 175,226 (FI), 386,565 (FFS), and 313,750 (effective N for insomnia). It reported one credible set for the eQTL and one for insomnia, but **zero credible sets for FI and FFS** in this window and under these model settings. Zero credible sets are not proof that frailty has no regional association. `estimate_s_rss` values were 0.045 for the eQTL, 0.0048 for FI, 0.0056 for FFS and 0.0084 for insomnia, indicating nonzero potential z–LD inconsistency; no universal pass cutoff is asserted. This is an external, rank-deficient reference rather than study-specific LD.

The single reported eQTL–insomnia credible-set pair favored **distinct signals** (H3 approximately 1 and H4 near zero across the three tested shared priors 10⁻⁶, 10⁻⁵ and 5×10⁻⁵). These are model-conditional posterior values, not probabilities that biological sharing is impossible. The eQTL set's highest-PIP variant was rs6738144; the insomnia set's was rs11693221. Critically, **three of the ten smallest-p eQTL rows in the retrieved wider region were excluded** by matching/allele/reference filters, and the 180-kb selection can miss other signals. This incomplete support, external LD, uncertain source variant semantics, overlapping cohorts and possible multiple variants prevent a definitive negative colocalization claim. The analysis supplies no FI/FFS colocalization result and no patient-level score validation.

## Pair-specific sensitivity

A follow-up removed the requirement that variants also be available in the FI and FFS files, retaining 299 non-palindromic eQTL–Jansen matches with 1000 Genomes EUR genotypes (24 more than the four-trait intersection). The LD matrix rank is 139, and estimated z–LD inconsistency parameters increased to 0.082 for the eQTL and 0.015 for Jansen. Both models converged and each returned one credible set. Their top variants were unchanged, and the H3-favoring posterior persisted across the same three prior settings. However, the same three of the ten strongest wider-region eQTL rows remain excluded and the inconsistency diagnostics are worse, so this sensitivity **does not resolve the main reliability concerns** or exclude secondary shared signals. GWAS-to-reference frequency and source multiallelic coding remain unverified; the comparison still uses overlapping or potentially overlapping samples, a narrow region and external reference LD.

## Sensitivity to two excluded palindromic variants

The three absent top-ten eQTL variants all have A/T or C/G allele pairs. Two (rs12621789 and rs6546230) occur in the Jansen file; rs6546232 did not match the Jansen source in the preceding scan. **Correction:** an earlier version incorrectly stated that the GRCh37 and GRCh38 reference bases differ for rs12621789. Direct UCSC reference-sequence queries give T at both hg19 chr2:66,654,097 and hg38 chr2:66,426,965; the 1000 Genomes GRCh37 VCF and gnomAD index both show T/A. The Jansen source identifier `A_T` is not evidence that A is the reference allele. This correction does not independently establish the discovery GWAS strand and full multiallelic coding.

Reference-sequence checks: [UCSC hg19](https://api.genome.ucsc.edu/getData/sequence?genome=hg19&chrom=chr2&start=66654096&end=66654097) and [UCSC hg38](https://api.genome.ucsc.edu/getData/sequence?genome=hg38&chrom=chr2&start=66426964&end=66426965), with zero-based half-open coordinates in those URLs. The [1000 Genomes VCF](https://hgdownload.soe.ucsc.edu/gbdb/hg19/1000Genomes/phase3/ALL.chr2.phase3_shapeit2_mvncall_integrated_v5a.20130502.genotypes.vcf.gz) gives T/A at the hg19 site; the local liftover and allele selection code explicitly counts A. These source observations correct the interpretation of the bases, not the already calculated model outputs.

A **conditional sensitivity**, assuming the reported alleles are correctly oriented on the forward strand, included those two variants and explicitly counted the GRCh38 ALT allele in the reference VCF. The checked 1000 Genomes records list rs12621789 as T/A and rs6546230 as C/G, matching the eQTL REF/ALT pairs; the preparation code chooses the allele index from the VCF rather than assuming a reference swap. It included 301 variants and nine of the ten strongest eQTL rows from the wider extract; two of the original three exclusions were recovered. The two per-variant eQTL versus EUR-reference ALT frequencies differed by about 0.032 and 0.018. Both models converged with one credible set each; the fitted eQTL/insomnia pair still favored H3 over H4 across the same three priors. Adding rs12621789 changed the top eQTL variant's PIP from 0.658 to 0.409, while rs12621789 obtained PIP 0.373; this shows that fine-mapped variant allocation is sensitive to the excluded high-LD candidates. These are posterior quantities conditional on this model, not validation of either variant.

The eQTL z–LD inconsistency estimate remained about 0.081, the LD matrix rank was 139, one top-ten variant remained absent from the insomnia match and the window remains limited. This sensitivity cannot establish allele orientation, exclude other signals or turn the result into proof of no shared cause. ## Comparison with the source's published molecular credible set

The [eQTL Catalogue release-7 QTD000166 fine-mapping file](https://ftp.ebi.ac.uk/pub/databases/spot/eQTL/susie/QTS000015/QTD000166/QTD000166.credible_sets.tsv.gz) lists one MEIS1-AS3 credible set with three distinct variants: rs6738144 (PIP 0.434), rs12621789 (0.421), and rs62143990 (0.0969). Their reported PIPs total 0.9514. The non-palindromic pair-specific analysis retained two of the three, accounting for 0.5308 of this published set's PIP sum; it excluded rs12621789. The conditional palindromic sensitivity retained **all three** (the full 0.9514 PIP sum), subject to its unverified allele-orientation assumption. This is a direct variant-coverage check, not proof that the entire gene's association space was retained or that the variant effect directions are correct.

The source credible set uses the same underlying QTL dataset, so it is **not an independent replication**. Its variant PIPs and this project's PIPs arise from different model inputs and should not be combined or interpreted as joint probabilities. Full variant/LD and imputation differences, unresolved palindromic orientation, the narrow window and z–LD inconsistency continue to limit the disease–expression comparison. This does not validate a score or establish absence of secondary shared signals. ## Matched-variant reference-LD sensitivity

The conditional 301-variant set was matched to the public gnomAD v2.1.1 non-Finnish European LD index; 287 variants matched and all passed a ≤0.2 eQTL-versus-reference ALT-frequency difference (maximum 0.0794). This index uses GRCh37, and the matched ALT contrasts were oriented to the GRCh38 eQTL allele. The retained set includes all three variants in the published eQTL credible set, including the strand-ambiguous rs12621789 under the same forward-strand assumption. The follow-up below checks GWAS-to-reference minor allele frequency, but effect-allele frequency, source strand and multiallelic handling remain unverified.

Using the **same 287 variants** in each reference, both SuSiE fits converged and returned one eQTL and one insomnia set. The gnomAD NFE matrix had numerical rank 287; its eQTL and insomnia `estimate_s_rss` values were 0.0156 and 0.000316, compared with 0.0478 and 0.00831 using 1000 Genomes EUR (rank 135). These are diagnostics, not formal proof of correct LD or causal models. Both reference-based runs favored distinct signals over sharing across the three tested priors. The top eQTL variant switched between rs12621789 (gnomAD) and rs6738144 (1000 Genomes); the insomnia lead remained rs11693221. Thus the result is relatively stable at the level of this conditional signal-pair comparison but **the individual eQTL variant allocation is reference-sensitive**. This does not rule out secondary shared signals or validate a score.

Both references are external, the locus was selected and restricted, gnomAD and GTEx sampling may overlap, source variant strands require verification, and the reference variant-index and block-matrix decoders were not independently validated with Hail. No correction for source sample overlap or unmodeled signals is implied. ## Insomnia–reference frequency audit

A complete scan of the Jansen source matched all 287 gnomAD-reference variants by chromosome, GRCh37 position and unordered allele pair. Comparing the source's reported **minor allele frequency** with the gnomAD NFE minor frequency gave a maximum absolute difference of 0.0492; none exceeded the previously used 0.2 discrepancy threshold. This is an additional consistency check only: minor-allele frequencies do not identify strand or effect-allele orientation, and allele-pair matching does not resolve multiallelic coding. It does not make external LD study-matched, establish independent samples, or validate scores. ## Wider-window gnomAD sensitivity

A follow-up widened the analysis to GRCh38 chr2:66,350,000–66,750,000. After non-palindromic filtering, the same two explicitly assumed forward-strand palindromic variants, gnomAD NFE index matching, and eQTL–reference ALT-frequency difference ≤0.2, **801 variants** remained. All three members of the source's published MEIS1-AS3 credible set were present. The external gnomAD LD matrix had numerical rank 801 and minimum eigenvalue 4.68×10⁻⁶. A subsequent audit checked insomnia–reference minor allele frequencies for all 801 variants, as documented below.

Both models converged with one reported credible set each. The eQTL and insomnia lead variants were rs6738144 and rs11693221, respectively; the pair again favored distinct signals across all three selected priors. The eQTL `estimate_s_rss` rose from 0.0156 in the 287-variant gnomAD analysis to 0.0317 in the 801-variant model, while the insomnia value was 0.00208. Different windows and variant sets can change diagnostics and fine mapping; the wider model has not independently resolved LD mismatch or demonstrated full cis coverage. The LD index and block decoders remain custom and not independently validated using Hail. Results are conditional on source allele orientation, the two palindromic-variant assumptions, the chosen window, reference LD, sample size and prior. No credible set for FI/FFS or clinical score validation follows from this two-trait analysis.
