# Larger Finnish LD reference: FOXP2 follow-up

The public [FinnGen LD service](https://docs.finngen.fi/working-outside-the-sandbox/ld-browser) provides pairwise r² from the SISu 4.2 Finnish panel. FinnGen's [LD documentation](https://finngen.gitbook.io/documentation/methods/genotype-imputation/ld-estimation) describes a 3,775-sample panel for its SISu 4.2 LD files, substantially larger than the 99 Finnish 1000 Genomes donors used in the earlier sensitivity analysis. The service reports r² and D-prime, not the signed correlation matrix required by the current SuSiE workflow. It is an external reference and does not replace in-sample GWAS LD.

We queried four postselected FOXP2-region markers with a 2-Mb window and zero r² threshold. The SISu pairwise r² for the earlier candidate rs12536335 and EUR-fit lead rs35624276 is 0.8264, close to 0.8271 in the 503-person 1000 Genomes EUR group and 0.8402 in its 99-person FIN subset. The SISu r² between rs35624276 and the other reported HFRS leads rs62477310 and rs2396682 is 0.0056 and 0.0021, respectively. These are LD measurements between selected markers, not evidence that a trait shares a causal signal or that any SNP causes disease.

To assess reference differences more broadly, each SISu anchor was compared to overlapping variants in the fixed 3,019-SNP analysis set, using exact GRCh38 reference/alternate alleles from the FinnGen R13 release. Depending on the anchor, 1,563–3,007 variants were available in both queried and reference data. Across these overlapping variants, the mean absolute difference in r² from SISu ranged from 0.017–0.036 for EUR503 and 0.017–0.026 for FIN99, varying by anchor. These are correlated variant pairs around four selected anchors, not independent tests or a genome-wide performance benchmark.

For the 16 other variants in the EUR-fit MVP insomnia credible set that appeared in the rs35624276 SISu response, the mean absolute r² difference from SISu was 0.057 for EUR503 and 0.097 for FIN99. The 17th member is the query variant itself, not returned as a separate pair. This small, selected comparison suggests that sampling in FIN99 may contribute to the earlier instability; it does not establish which full signed LD matrix is correct, isolate the cause of the discordant SuSiE fits, or validate the apparent EUR-reference colocalization. FIN99 is a subset of EUR503, and possible sample overlap with SISu is not established.

Source request parameters, endpoint URLs and SHA-256 hashes are saved in `stage6_foxp2_sisu_anchor_receipt.json`. Reproduce retrieval using `stage6_foxp2_sisu_anchor_queries.py`; the per-variant comparison and summary are `stage6_foxp2_sisu_anchor_r2_comparison.csv.gz` and `stage6_foxp2_sisu_anchor_r2_summary.csv`, produced by `stage6_foxp2_sisu_ld_compare.py`. The credible-set membership table is `stage6_foxp2_credible_set_members.csv`, produced by `stage6_foxp2_extract_credible_members.R`. Each API response is archived as `stage6_foxp2_sisu_ld_<rsid>.json`; API window conventions and response completeness were not independently verified. Exact matching does not resolve earlier GWAS selection, study overlap, omitted variants or possible imputation differences.

The next decisive step remains a full, signed, appropriately matched LD matrix for each study and analysis on common variants; phase should not be inferred from r² alone. The original colocalization sensitivity analysis and its limitations are in `stage6_foxp2_independent_cohort_coloc_review.md`.
