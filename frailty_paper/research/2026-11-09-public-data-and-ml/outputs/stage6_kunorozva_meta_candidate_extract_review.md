# Complete clinical-insomnia meta-analysis: project candidate extraction

The public [LocusZoom results file](https://my.locuszoom.org/gwas/922558/?token=fbe996cb953248e49fa54acd9f400da1), linked by Table S1 of the [Kunorozva et al. sleep-disorders preprint](https://doi.org/10.1101/2025.11.21.25340447), provides substantially more variant-level coverage than the selected-lead supplement. We streamed the compressed file and examined all **12,159,859 rows**, without saving the large source file. All **33 distinct variants** from the two project candidate lists had a row matching an existing inferred GRCh38 coordinate and the corresponding unordered allele pair. This is a coordinate-and-pair screen, not full confirmation of source and target representation or strand, and it does not validate a score. The project inputs include multiallelic variants.

Three matched rows have source p < 5 × 10⁻⁸: rs113851554 (−log10 p = 27.68), rs12536335 (12.55), and rs817509 (7.45). These are **postselected associations in a non-independent meta-analysis**: the five discovery cohorts include UK Biobank, FinnGen and MVP, which informed previous project analyses and selection. They should not be called novel signals or independent replications. Others not crossing that threshold are not evidence of no effect. We did not combine variants into a score, evaluate predictive accuracy or measure frailty.

The exported file labels reference and alternate alleles, beta, standard error and alternate frequency. [LocusZoom's own data instructions](https://my.locuszoom.org/about/) specify beta relative to the alternate allele; the matched rs113851554 G/T row's beta of 0.101 agrees with the preprint's selected meta-analysis table, which labels T as ALT/effect. This is a useful consistency check for that row and platform convention, **not independent verification of every variant, especially multiallelic loci**. The selected source estimates and project weights are on different phenotype scales; no cross-score ranking follows.

Clinical insomnia here uses diagnostic codes, not necessarily the same symptom-based definition as the project discovery study. The meta-analysis reports 178,316 cases and 1,414,197 controls in Table S1, but variants can have different cohort contributions and effective sample sizes; these are not individual-level score-validation records. The authors' separate Estonian selected-lead follow-up is described in the [earlier review](stage6_estonian_sleep_replication_selected_variants.md); the later [source audit](stage6_kunorozva_estonian_selected_variant_review.md) covers the same Estonian data and must not be counted as another cohort. The Estonian result is not present in this discovery meta-analysis file.

The [33 matched rows](stage6_kunorozva_meta_candidate_extract.csv) and [receipt](stage6_kunorozva_meta_candidate_extract_receipt.json) include source values, score-list membership and a hash of the extract. The source compressed file was not retained or independently checksum-verified; the scan completed successfully, checked the header and validated one selected-row beta against the supplement. Run `python3 work/kunorozva2025/extract_locuszoom_candidates.py` to repeat the public streamed extraction. The preprint promises publication of summary statistics; the browser file is the specific result actually obtained here. No individual records were obtained.
