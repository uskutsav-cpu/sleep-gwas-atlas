# Ye FFS MAGMA model sensitivity

The same Ye FFS input, Ensembl v92 gene annotation and 1000 Genomes European LD reference were analyzed with MAGMA v1.10's default SNPwise-mean method and its Brown 1-df approximation. Both analyzed the same 19,015 genes. Across each model's separate gene-wide BH family, 854 genes had q < 0.05 under the default model and 1,048 under Brown; all 854 default-significant genes were also Brown-significant, leaving 194 Brown-only genes in this dataset. Full paired gene results are in [the sensitivity table](stage4_ye_ffs_magma_gene_model_sensitivity.csv). This is a meaningful methodological sensitivity, not a validation or a reason to select the model with more hits.

For each model, 102 cell-type properties were tested across the same six exploratory expression matrices, with BH performed separately for each trait/model. Neither FFS model produced a group below q = 0.05. In the source human cortex matrix, neurons and the source-labeled hybrid group have q = 0.0744 under the default model and q = 0.0600 under Brown; the mouse vascular FB1 group has q = 0.0744 and 0.0727 respectively. These are group-level, postselected analyses and do not establish a shared cell or a specific gene mechanism. See [the full cell results](stage4_magma_cell_type_exploratory.csv).

For context, the matched Brown FI run identified three groups at q < 0.05, including the same two cortex labels and mouse hypothalamus Glu3. The FI and FFS inputs differ in phenotype, study and sample characteristics, and this comparison is not a formal test of trait difference or cell-specific causality. See the [standard-model FI–FFS cell review](stage4_standard_fi_ffs_cell_type_comparison.md) and [FI Brown review](stage4_mak_fi_brown_magma_cell_type_review.md). All gene- and cell-family q-values were independently checked with R's `p.adjust`; matrix selection and model sensitivity were not preregistered.
