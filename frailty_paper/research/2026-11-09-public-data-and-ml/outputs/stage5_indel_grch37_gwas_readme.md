# Indel mapping and frailty GWAS lookups

All 28 queue indels were mapped from GRCh38 to GRCh37 using reciprocal positive-strand mapping across the entire reference allele and the following base. Each resulting GRCh37 reference allele was checked against UCSC hg19 sequence, and repeat-aware left normalization was checked for haplotype equivalence within the fetched window. No normalized positions shifted in this set. The [mapping table](stage5_indel_hg19_mapping.csv), [audit](stage5_indel_grch37_gwas_audit.json) and [reference responses](stage5_indel_hg19_reference_responses.zip) preserve the checks.

The [GWAS table](stage5_indel_grch37_gwas_matches.csv) contains one result or explicit non-match for every indel and each of five prior regional caches. Each of Mak FI, Mak physical frailty and Ye FFS has 26 unique exact-coordinate/allele-pair matches. Atkins FI and Jansen insomnia have no exact indel representation in their selected SNP-only regional caches. A non-match can reflect source filtering or alternate representation; it is not a null association. The source files' GRCh37 build and A1 effect convention remain inherited assumptions, and the Ye effect direction remains inferred. Results are not independent across related UK Biobank cohorts.

The FOXP2 insertion chr7:114534306 T>TA has exact matches in Mak FI (p = 8.42 × 10⁻¹⁰), Mak physical frailty (p = 0.00316), and Ye FFS (p = 0.0088), as well as the separately reported FinnGen insomnia record. These are unadjusted, postselected marginal associations; they do not establish a shared causal signal, an effect on FOXP2 expression, or a mechanism. Earlier FOXP2 regional colocalization excluded this indel and must not be represented as an analysis including it. A correctly harmonized updated analysis and AlphaGenome indel scoring remain needed.

The [multi-trait matrix](stage5_variant_multitrait_gwas_matrix.csv) now includes the matched indel records. Its source-specific statuses distinguish missing from excluded alleles.
