# SingleBrain cross-cell coverage check

The SingleBrain full-association files for excitatory neurons, inhibitory neurons and oligodendrocytes were independently queried by HTTP byte range in the chr5:135,000,000–137,300,000 region. In each file, the last returned source position at or before the original rs7734045 marker (chr5:136202653:A>C) was 136164132; the next source position across all genes was 139164641. The same gap therefore affects all three files; its cause is unknown. This observation does not establish that a biological association is absent or explain why the records are missing.

The extracted SMAD5 rows number 4,407, 4,407 and 4,406 in the respective cells. Restricting to positive source fixed-effect standard errors leaves 2,229, 2,229 and 2,227 rows. In each file, the same record at chr5:135756623:A>T reports effect allele G, which matches neither REF nor ALT, and must be excluded from signed analyses pending clarification. These numbers are not independent replicates: cell types arise from the same SingleBrain meta-analysis cohorts.

The region extractor is `stage5_singlebrain_regional_extract_by_cell.py`; per-cell files and detailed byte-range, order and block-integrity receipts are named `stage5_singlebrain_{ext,in,od}_smad5_full_regional.tsv.gz` and `stage5_singlebrain_{ext,in,od}_smad5_regional_receipt.json`. The Ext file and receipt were generated by the equivalent original script. The source's whole-file checksum was not verified because these are targeted byte-range extractions, not whole-file downloads. Source: [SingleBrain release](https://zenodo.org/records/14908182); [study](https://www.nature.com/articles/s41588-026-02541-x).
