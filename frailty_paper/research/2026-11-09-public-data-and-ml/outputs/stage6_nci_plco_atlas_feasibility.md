# NCI PLCO GWAS Explorer: sleep and frailty endpoint check

The NCI's [PLCO GWAS Explorer](https://exploregwas.cancer.gov/) provides public GWAS summary results and documents a phenotype-search API. On October 28, 2026, the `/api/phenotypes` endpoint returned empty lists for the exact queries `sleep`, `insomnia`, `frail`, `fatigue` and `weakness`. In its browser phenotype filter, `sleep`, `insomnia`, `frail` and `fatigue` displayed no matching entries, while the positive-control query `diabetes` displayed an entry. A completed API query for `walk` returned walking frequency (ID 5580), self-reported usual walking pace (ID 5620), and vigorous activity entries. Each returned `import_count: null`; that value is not the documented zero, so the API response alone does not establish whether association results can be downloaded. See [the saved response](stage6_plco_walk_query.json). Self-reported activity frequency and usual pace are not FI, FFS, objectively measured gait speed or insomnia.

These are limited text searches of the atlas catalog, not an exhaustive assessment of PLCO questionnaire variables or other repositories, and do not establish that sleep or frailty data do not exist in PLCO. No linked genotypes or participant outcomes were obtained. A query that returns no matching label cannot support a claim about an absent or nonsignificant genetic association. The atlas is therefore not yet a usable independent insomnia–frailty score evaluation resource.

## Walking-pace endpoint follow-up

On October 28, 2026 the [metadata endpoint for self-reported walking pace, all-sex European stratum](https://exploregwas.cancer.gov/api/metadata?phenotype_id=5620&sex=all&ancestry=european) returned `participant_count: 76183` but null variant count and null genomic-control fields. The [download-link request](https://exploregwas.cancer.gov/api/download?phenotype_id=5620&get_link_only=true) returned HTTP 500 with the message that the phenotype must have an import date. Thus this specific endpoint did not provide a results file at the time checked; it does not establish that PLCO lacks the phenotype or that results do not exist elsewhere. The metadata count is not evidence that 76,183 participants have usable full GWAS records. This is an independently described older US screening cohort but exact participant overlap, the ordinal pace coding and comparison to frailty outcomes would require verification. A self-reported pace GWAS, even if obtained, would be a component-related summary analysis, not validation of FI/FFS score prediction.
