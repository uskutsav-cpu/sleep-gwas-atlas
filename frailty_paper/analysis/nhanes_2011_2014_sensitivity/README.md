# NHANES sleep–frailty observational sensitivity study

This research package reconstructs and audits NHANES 2011–2014 frailty phenotypes in adults aged 60 years or older, analyzes sleep trouble using complex-survey methods, and documents the provenance of two prototype genetic scores. It is a manuscript-ready candidate for investigator review, not a validated diagnostic score, genetic validation, or evidence of a causal effect. Read `methods.md`, `results.md`, and `limitations_and_corrections.md` together before use.

## Main contents

- `finalized_participant_data.csv`: 3,632 age-eligible interview records, raw inputs, recoded items, scores and 2019 vital-status fields. `finalized_variable_dictionary.csv` documents all 205 columns; `raw_variable_dictionary.csv`, `derived_variable_dictionary.csv`, `fi_item_dictionary.csv` and `alternative_score_definitions.csv` give detailed rules and source links.
- `survey_full_design_frame.csv`: all 19,151 participants with positive MEC weights, with outcomes defined for the target domain. This retains the full design when subsetting the target population; it is necessary for correct domain standard errors.
- `supplement_49_item_audit.csv` and `supplement_item_audit_checks.csv`: per-item provenance, missingness and independent reconstruction comparisons. `frailty_construct_audit.md` explains the five Fried-criterion approximations.
- `supplement_survey_models.csv`, `supplement_baseline_table.csv`, `supplement_weighted_descriptives.csv`, `supplement_flow.csv`, `supplement_missingness_by_exposure_cycle.csv`, and `supplement_ipw_diagnostics.csv`: analysis outputs. Model estimates for logistic outcomes are odds ratios; linear models are FI-unit differences. See the model family and analysis labels. Multiple-testing corrections are defined in `methods.md`.
- `figure1_fi_associations` and `figure2_distribution_mortality`: PDF, SVG and PNG with their source-data CSVs and `figure_legends.md`.
- `score_15_variants_standardized.csv` and `score_22_variants_standardized.csv`: project prototype lists and source-preserved weights. `supplement_genetic_reference_audit.csv`, `supplement_gwas_weight_audit.csv` and `genetic_score_provenance.md` explain what was checked and what remains uncertain.
- `source_files/`: CDC public input files, including mortality linkage files; SHA-256 values in `source_checksums.csv` and `mortality_source_checksums.csv`. `prototype_sources/` contains copies of score source artifacts. `reference_grch37/` caches public Ensembl reference responses. `gwas_summary_source_receipts.json` records hashes and original local paths of three large GWAS inputs; the inputs themselves are not redistributed here.

## Reproduce

From this directory, use Python 3 with numpy, pandas, scipy, pyreadstat, beautifulsoup4, certifi, requests and matplotlib, plus R with the CRAN `survey` package. For example, install Python packages in a virtual environment and install the R package with `install.packages('survey')`; package versions used include R survey 4.5 and matplotlib 3.11.2. Run `bash run_pipeline.sh`. Set `R_LIBS_USER` if survey is installed outside R's standard library. The script writes only within this package directory, and verifies source hashes, participant-level mortality linkage, independent item recoding, primary Python/R model agreement, genetic audit artifacts and figure formats. Source download is not needed: CDC inputs and cached reference responses are included.

`audit_gwas_weights.py` is an optional provenance recheck that requires the original three large GWAS files at the paths recorded in the script and receipts; its already-generated per-marker results are provided. `extract_prototypes.py` regenerates score tables from the copied artifacts but its resulting local provenance paths will differ from the retained original project paths. The source files are not genotype data. Do not interpret allele presence in a reference database as proof of the effect-allele definition or genotyping coverage.

## Important interpretation

NHANES samples are cross-sectional; doctor-reported sleep trouble is not an insomnia diagnosis and analyses do not establish temporal direction or causality. The FI is a transparent adaptation, not an exact replication or independently validated instrument. The 2019 public mortality file supplies eligibility and vital status for a same-cohort construct check; no perturbed follow-up time or cause is analyzed. Observed mortality associations are not independent external validation. Public genetic data availability and exact source allele semantics remain unresolved. A stricter missingness-selected FI contains only 28 items and is exploratory. See the limitations for item coding, missing data, residual confounding, model multiplicity and generalizability.
